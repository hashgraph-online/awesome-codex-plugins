# The Uizze UI Pack

Uizze's full AI design pack for agents.

Build and improve UI/UX with the code and assets you already have. Use [Uizze](https://uizze.com/?utm_source=github&utm_medium=skill&utm_campaign=uizze-ui&utm_content=intro) for design systems, real app examples, licensed fonts, icons, motion and interaction details.

## Install

```sh
npx skills add uizze/uizze --skill uizze-ui
```

The skill works with your project's stack, assets and reference images. You don't need a Uizze account or MCP connection for local UI/UX work.

Explore Uizze's [mobile library](https://uizze.com/?platform=Mobile&utm_source=github&utm_medium=skill&utm_campaign=uizze-ui&utm_content=library_mobile#explore) and [web design library](https://uizze.com/?platform=Web&library=design-packs&utm_source=github&utm_medium=skill&utm_campaign=uizze-ui&utm_content=library_web#explore) for UI/UX ideas and design directions.

For connected resources, use your client's Uizze connection at `https://uizze.com/mcp`. Hosted Uizze MCP requires a Uizze account with paid access; local UI/UX work is not blocked on signup.
