# Security Policy (`design-os-svg-animation`)

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `1.x` / `main` | Yes |

## Security Model

- `design-os-svg-animation` executes locally with **zero external telemetry** (see [`PRIVACY.md`](PRIVACY.md)).
- Diagnostic commands (`/doctor` and `python3 scripts/self_check.py`) are strictly read-only verification checks.

## Reporting a Vulnerability

Please report suspected vulnerabilities via [GitHub Security Advisories](https://github.com/jangtrinh/design-os-svg-animation/security/advisories/new) rather than public issues. We acknowledge reports within 48 hours.
