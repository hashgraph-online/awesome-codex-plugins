# Security Policy

## Supported versions

Security fixes are applied to the latest released version.

## Reporting a vulnerability

Please use GitHub private vulnerability reporting for this repository. Do not open a public issue
for vulnerabilities that could close unrelated panes, execute unintended commands, disclose local
rollout content, or cross workspace boundaries.

Include:

- the affected plugin, Codex, Herdr, Python, and operating-system versions;
- a minimal reproduction that does not contain private rollout content;
- the expected and observed pane IDs and lifecycle events;
- any proposed mitigation.

You should receive an acknowledgement within seven days. Please allow time for a coordinated fix
before public disclosure.
