# Security

This repository holds manifests, two skills (Markdown) and a logo. It runs no code on your machine: no
hooks, no scripts, no binaries. The one server it names is `https://agentmart.ciphyr.ai/mcp`, reached over
HTTPS with OAuth sign-in.

## Reporting a problem

Please report a security problem in this plugin or in the AgentMart service as
https://agentmart.ciphyr.ai/.well-known/security.txt says. Do not open a public issue for it.
How to report a problem, and what we promise: https://agentmart.ciphyr.ai/security.

## What we never put here

- No tokens, keys, invite codes or test credentials.
- Nothing here tells the agent to fetch and follow text from a web address. (Like any MCP server,
  ours sends its tool descriptions when your app connects.)
- No files that change your settings, `CLAUDE.md`, `AGENTS.md` or other rules on your machine.
