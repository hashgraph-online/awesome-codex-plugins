# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.3.x   | :white_check_mark: |
| < 1.3   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately:

1. Open a private security advisory on GitHub under the [Security Advisories](https://github.com/goul4rt/lgpd-skills/security/advisories/new) tab, or
2. Contact the maintainer directly via email at aroldogooulart@gmail.com.

Please do not open public GitHub issues for security vulnerabilities.
