# 필요한 만큼만 프로젝트를 파악한다

처음 보는 저장소의 다중 파일 작업에서 읽는다. 기존 계획·AGENTS.md·CLAUDE.md·README와
패키지/빌드/테스트 진입점부터 확인한다. 상위 규약을 하위 문서에 그대로 복사하지 않는다.

관련 모듈의 역할, 실제 진입점/호출자, 프로젝트의 검증 명령, 수정 금지 경계를 짧게 정리한다.
파일명/문자열은 rg, 구조는 code-intel, 이전 결정은 요청이 있을 때 session-history를 사용한다.
많은 파일을 읽기 전에 필요한 질문을 먼저 좁힌다.

하위 AGENTS.md가 필요하면 그 디렉토리에서만 다른 규약/검증법을 적는다. 사용자가 요청하지 않은
대규모 문서 생성·기존 문서 삭제·전역 지침 주입을 하지 않는다. 낡은 문서는 현재 코드로 확인한다.
재개할 때는 저장된 계획 원문과 실제 작업 트리를 대조한다. 요약/완료 보고만으로 현재 상태를 추정하지 않는다.
