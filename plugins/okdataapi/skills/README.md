# okdata Agent Skills

[English](#english) · [中文](#中文)

<a id="english"></a>

Skills that teach an AI agent (Claude Code, Codex, Cursor, OpenClaw and anything else that reads `SKILL.md`)
to do marketing and research jobs with [okdata](https://okdata.online): public data from TikTok, YouTube, Instagram, X,
Reddit and Amazon, plus Douyin, Xiaohongshu (RedNote), WeChat, Bilibili, Weibo, Taobao, 1688 and more (over 230 endpoints on
23 platforms), paid per call.

Each skill says which endpoints it uses and what they cost, and asks the agent to state the cost before it spends.
The files are generated on [okdata.online](https://okdata.online/skills/?src=gh-skills) from the live catalog and mirrored here.

## Install

Any agent, with the [skills CLI](https://github.com/vercel-labs/skills):

```bash
npx skills add okdataapi/skills
```

Claude Code, as a plugin:

```text
/plugin marketplace add okdataapi/skills
/plugin install okdata-skills@okdata
```

Codex reads this repository as a plugin too: `.codex-plugin/plugin.json` bundles the skills and the MCP server.

Or copy a folder from `skills/` into `~/.claude/skills/` (Claude Code), `~/.codex/skills/` (Codex) or your
agent's skills folder.

Then get a key at [okdata.online](https://okdata.online/signup/?src=gh-skills), put it in `OKDATA_API_KEY`, and
ask the agent to "set up okdata" (the `okdata` skill connects the MCP server
`https://api.okdata.online/mcp`).

## Keeping the skills current

The skills are written on okdata.online from the catalog, so prices and endpoint lists stay right; this repo mirrors them.

```bash
node scripts/mirror.mjs           # download every published skill, drop retired ones, refresh the lists here
node scripts/mirror.mjs --check   # exit 1 if the repo differs from the site
```

Publishing to ClawHub goes through `scripts/clawhub-publish.sh "<changelog>" [skill ...]`, which keeps each skill's Chinese display name from `scripts/clawhub-names.tsv`.
