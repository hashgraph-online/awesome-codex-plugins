# Security

## Report a vulnerability

Email **security@sync.so** with what you found, the steps to reproduce it, and what an attacker could do with it. Please don't open a public GitHub issue for a vulnerability, and don't include real user data in the report.

We acknowledge every report and keep you updated until it's resolved. Please give us a reasonable time to fix the issue before you disclose it publicly.

## Scope

This repository holds agent skills, plugin manifests and the docs pages built from them. The skills call the hosted sync. MCP server at `https://mcp.sync.so/mcp` and the sync. API. Report issues in either one, in the [MCP server source](https://github.com/synchronicity-labs/mcp-server), or in [sync.so](https://sync.so) to the same address.

Fixes ship from the `main` branch; there are no older versions to patch.
