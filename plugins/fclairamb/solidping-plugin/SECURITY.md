# Security Policy

This repository only holds plugin metadata: manifests, an MCP server address and a skill. It ships no code that runs on your machine.

## Reporting a vulnerability

Please do not open a public issue.

- For this plugin, or for the SolidPing server and its MCP endpoint, use GitHub's private advisory form on the main repository: https://github.com/fclairamb/solidping/security/advisories/new
- Or email security@solidping.io

The full policy, with what to expect after a report, is in the main repository: https://github.com/fclairamb/solidping/blob/main/SECURITY.md

## Supported versions

Only the latest version of this plugin and the latest SolidPing release are supported.
