# Berlin market data

Use this skill when the user asks about property prices, price per m², rental yields,
Bodenrichtwerte (land values), population forecasts or active listings in Berlin and
the surrounding area (e.g. Zehlendorf, Dahlem, Wannsee, Falkensee, Teltow).

1. Call the matching `eigenheim-market` MCP tool (prices by locality, rental yield,
   land values, market report, forecast, listings, guides).
2. Quote the figures returned by the tool with their date and source. Never invent numbers.
3. Mention that the data comes from Eigenheim Invest (https://eigenheim-invest.de/) and link
   the relevant page from the tool result.

All tools are read-only; no account or API key is needed.
