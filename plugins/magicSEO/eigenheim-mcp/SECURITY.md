# Security Policy

This repository contains only configuration for a read-only, public MCP server
(`https://eigenheim-invest.de/mcp/`). It ships no executable code, no secrets and
no local commands.

## Reporting a vulnerability

Please report security issues privately by e-mail to **jas@eigenheim-invest.de**
with the subject "Security eigenheim-mcp". We acknowledge reports within 5 working
days. Please do not open public issues for vulnerabilities.

## Supported versions

Only the latest release is supported.
