# Security Policy

## Supported Versions

The latest published release on GitHub is the supported version.

## Reporting a Vulnerability

If you find a security issue, report it privately through the GitHub Security Advisory page:

https://github.com/good-boy4069/Deepseek-omnimodal/security/advisories/new

Do not open a public issue before the problem is addressed. Include reproduction steps, affected version, and impact if known.
