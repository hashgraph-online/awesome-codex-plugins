# Security policy

This repository holds plugin manifests and skills for the hosted Revid MCP server
(`https://www.revid.ai/api/mcp`). It contains no server code and no secrets.

## Reporting a vulnerability

Email **hello@revid.ai** with "Security" in the subject, a description of the issue and
the steps to reproduce it. Please do not open a public issue for a vulnerability. We
acknowledge reports within 3 business days and keep you updated until it is fixed.

## Scope

- The skills and manifests in this repository.
- The Revid MCP server and its OAuth endpoints on `www.revid.ai`.
