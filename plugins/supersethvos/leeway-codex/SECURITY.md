# Security

Report a security issue to support@leeway.to. Leeway's policy is at https://leeway.to/support#security, and https://leeway.to/.well-known/security.txt lists the same contacts.

This plugin contains no code that runs on your computer: a manifest, the address of Leeway's server, skills (instructions for Codex) and an icon. Codex signs in to Leeway with OAuth in your browser; the plugin never sees your passkey.
