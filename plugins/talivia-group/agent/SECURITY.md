# Security Policy

## Supported versions

Security fixes are applied to the latest released version of `@talivia/agent`.

## Reporting a vulnerability

Please report vulnerabilities privately through a [GitHub security advisory](https://github.com/talivia-group/agent/security/advisories/new). Do not include sensitive details in a public issue.

Include the affected version, reproduction steps, potential impact, and any suggested mitigation. The Talivia team will acknowledge the report, investigate it, and coordinate disclosure with the reporter.
