# Security policy

This repository contains no code: a plugin manifest, an MCP server declaration that points at `https://tablejourney.com/mcp`, a skill and an icon. Security issues are most likely to concern that hosted server, which is read-only and holds no user accounts.

## Reporting a vulnerability

Email **support@tablejourney.com** with "Security" in the subject, or open a [private security advisory](https://github.com/lewismvaughan/tablejourney-codex-plugin/security/advisories/new) on this repository. Please do not open a public issue for a vulnerability.

Include what you found, how to reproduce it and what it would let an attacker do. We aim to acknowledge reports within 3 business days and will tell you when a fix is deployed.

## Supported versions

Only the latest version of this plugin, and the server currently deployed at `tablejourney.com/mcp`, are supported.
