# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.11.x  | :white_check_mark: |
| < 2.11  | :x:                |

## Reporting a Vulnerability

We take the security of Pixeltable and its agent skills seriously.

If you discover a potential security vulnerability in this repository, please do not report it through public GitHub issues or discussions.

Instead, please report security issues privately by emailing [security@pixeltable.com](mailto:security@pixeltable.com).

Please include:
- A description of the issue and potential impact
- Reproduction steps or a proof of concept
- Any suggested fixes or mitigations

We will review your submission and respond as quickly as possible.
