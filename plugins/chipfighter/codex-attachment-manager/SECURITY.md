# Security Policy

This directory is the plugin bundle of [Context Attachment Manager](https://github.com/chipfighter/context-attachment-manager).

Please don't report security problems in public issues. Use GitHub's private vulnerability reporting instead: [report a vulnerability](https://github.com/chipfighter/context-attachment-manager/security/advisories/new). Only you and the maintainer can see the report.

The full policy, including what is most worth reporting, is in the repository's [SECURITY.md](https://github.com/chipfighter/context-attachment-manager/blob/main/SECURITY.md).
