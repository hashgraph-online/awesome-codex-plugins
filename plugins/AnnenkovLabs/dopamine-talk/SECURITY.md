# Security Policy

## Scope

Dopamine Talk consists of static Markdown skills (`skills/`, `skills-ru/`), plugin metadata manifests, and the interactive installer script (`install.sh`).

## Reporting a Vulnerability

If you discover a security issue in `install.sh`, plugin manifests, CI workflows, or the companion site (`https://dopamine.annenkov.me`), please report it privately via **GitHub Security Advisories** (`Security -> Report a vulnerability`) rather than opening a public issue.

We review reports promptly and publish a fix along with clear release notes.
