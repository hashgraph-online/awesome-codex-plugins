# 덱 서사

spec을 쓰기 전에 이 규칙 파일을 사용합니다. 무엇을 어느 순서로 놓고 무엇을 뺄지를 담습니다.

## 1. 한 슬라이드에 한 주장

슬라이드는 청중이 기억해야 할 문장 하나를 담습니다. 한 문장으로 말할 수 없으면 주장이 둘이고, 슬라이드도 둘이 됩니다.

- 주장은 `title`에 판단이 담긴 문장이나 명사구로 씁니다("결제 실패는 3개 구간에서 발생한다"). 화제만 적은 표제("결제 현황")는 쓰지 않습니다.
- 본문은 제목의 근거입니다. 두 번째 논점이 아닙니다. 제목을 받치지 않는 항목은 옮기지 말고 지웁니다.
- 표나 차트, 이미지에 글머리표 세 줄이 붙어 있으면 슬라이드를 둘로 나눕니다.

## 2. 통하는 순서

| 자리 | 종류 | 하는 일 |
|---|---|---|
| 1 | `title` | 무엇을, 누구에게, 언제 기준으로 |
| 2 | `bullets` 또는 `stats` | 첫 30초 안에 답 |
| 3-6 | 주장마다 종류 하나 | 근거. 슬라이드마다 질문 하나에 답 |
| 끝에서 두 번째 | `section` 또는 `bullets` | 다음에 무엇이 바뀌는가 |
| 마지막 | `quote` 또는 `bullets` | 기억할 한 줄 |

결론은 마지막이 아니라 두 번째에 둡니다. 답을 끝까지 아끼는 덱은 추리물로 읽히고, 결정권자는 반전을 보기 전에 자리를 뜹니다.

`section` 슬라이드는 여덟 장을 넘는 덱에서 장을 나눕니다. 그보다 짧으면 슬라이드 한 장을 쓰고 얻는 것이 없습니다.

## 3. 종류 고르기

| 읽는 사람이 해야 할 일 | 쓸 것 | 피할 것 |
|---|---|---|
| 논증을 따라간다 | `bullets` | 세 줄 이상의 문단 |
| 나란한 선택지를 비교한다 | `columns` | 선택지마다 한 행인 표 |
| 숫자의 크기를 느낀다 | `stats` | 글머리표 속에 묻힌 숫자 |
| 정확한 값을 확인한다 | `table` | 값 다섯 개짜리 차트 |
| 추세나 격차를 본다 | `chart` | 스무 행짜리 표 |
| 실제 사물을 본다 | `image` | 사물을 설명한 글 |
| 한 문장을 기억한다 | `quote` | 그 문장을 글머리표로 |

차트는 모양을, 표는 값을 봅니다. 범주가 여섯을 넘으면 빽빽한 축 대신 표로 바꾸거나 차트 둘로 나눕니다.

## 4. 문장

- 숫자와 단위를 같이 씁니다. `47%`, `12만 건`, `3주`. 기준이 없는 비율("47% 증가")은 사실이 아닙니다.
- 행위자를 적습니다. "47%의 이탈이 발생한다"가 아니라 "카드 인증에서 47%가 끊긴다"입니다.
- 강조 부사를 지웁니다. "매우", "상당히", "혁신적인", "다양한"은 정보가 없고 군더더기로 읽힙니다.
- 개념마다 용어를 하나로 유지합니다. 같은 지표를 "실패율"과 "에러율"로 오가면 읽는 사람이 둘 다 의심합니다.
- 근거와 출처는 발표자 노트에, 주장은 슬라이드에 둡니다. 출처 줄을 슬라이드에 넣을 자리가 있으면 `notes`에 넣습니다.

## 5. 크기 예산

| 요소 | 한도 |
|---|---|
| `bullets` | 0단계 4개, 또는 3개에 각각 하위 2줄 |
| 항목 길이 | 본문 폭에서 18포인트 한 줄, 한국어 약 34자 |
| `columns` | 3개, 각각 제목과 짧은 항목 2~3개 |
| `stats` | 4개, 각각 6자 이내 값과 이름표 |
| `table` | 6열 8행 |
| `chart` | 범주 6개, 계열 3개 |
| `title` | 30포인트 한 줄, 한국어 약 20자 |
| `quote` | 한 문장, 약 60자 이내 |

한도를 넘으면 슬라이드를 나눕니다. 글자를 줄여 맞추는 순간 방 뒤쪽 세 번째 줄부터 읽히지 않는 덱이 됩니다.

## 6. 빼야 할 것

- 목차 슬라이드, "감사합니다" 슬라이드, 파일 이름만 봐도 아는 목차.
- 앞 슬라이드를 다른 말로 반복하는 슬라이드.
- 뜻이 없는 장식. 악수하는 손 사진, 아무것도 가리키지 않는 아이콘 줄.
- "또한", "추가로"로 시작하는 항목. 연결어를 쓴 두 번째 주장일 뿐입니다.
