# Replacement Patterns

Read this reference only when a confirmed `clean` or `restyle` finding needs a structural or presentation alternative. These are options, not visual-direction defaults; a `restyle` takes its direction from `brief.md`.

Every replacement preserves real data, copy, links/actions, semantics, focus order, and responsive behavior. If that cannot be verified, use `ask` or `block`.

| Rule/pattern | Consider | Preserve / do not use when | Verify |
|---|---|---|---|
| Identical feature-card cluster | One primary feature plus a supporting list, a task workflow, or typographic list | Keep genuine peer data and all CTAs; do not replace real comparisons | Desktop/mobile order, keyboard order, actions |
| Decorative New/pulse dot | Dated static release label or removal | Keep recording/live/sync/unread state and accessible text | State semantics, reduced motion |
| Unsupported metric/proof | Local provenance-backed proof or removal | Never invent metrics, testimonials, logos, customers, or promises | Source provenance and localization/legal contracts |
| Fake chrome | Real screenshot with caption, or a contextual asset without fake controls | Keep alt text and product context | Asset meaning, responsive fit |
| Card in card | Retain the one boundary with real grouping/interaction meaning | Do not flatten clickable or form boundaries | Focus ring, hit targets, mobile spacing |
| Gradient headline | Existing confirmed primary ink or solid accent token | Keep documented brand/reference gradient | Rendered hierarchy and contrast when available |
| Side stripe + wide shadow | One meaningful state/accent boundary | Keep documented elevation or state meaning | State distinction, dark mode, focus |
| Grid/radial/glow background | Product-world material or a quiet surface | Keep real map/canvas/blueprint context | Content legibility and asset purpose |
| Decorative monospace | Role-appropriate body/display token or a real icon system | Keep code, IDs, logs, measurements, and system state | Readability, accessible name |
| Generic motion | State-linked transform/opacity plus reduced-motion alternative | Keep genuine feedback and task state change | Hover/focus/state and reduced motion |

Do not use a replacement pattern to create a new brand world, change information architecture, or fabricate proof.
