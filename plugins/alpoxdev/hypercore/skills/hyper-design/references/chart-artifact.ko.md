# 차트 산출물

산출물이 단독 파일로 내보내지는 숫자 차트일 때 읽는다. 보통 하나의 HTML 파일에 묶인 막대·꺾은선·점이다. 전체 방문자 화면을 다루는 화면·대시보드 규칙과 달리, 여기서 파일 자체가 산출물이며 실패는 오프라인에서는 아무것도 그리지 않는 CDN 스크립트, 자바스크립트 뒤에야 오는 첫 렌더링, 값과 높이가 맞지 않는 막대다.

## 1. 오프라인 단독 파일

모든 의존성을 파일 안에 인라인으로 넣는다. 스타일은 `<style>`에, 스크립트는 `src` 없는 `<script>`에, 폰트는 `data:` URI나 시스템 스택으로, 이미지는 `data:` URI로 둔다. 외부 스타일시트·스크립트·폰트·이미지 요청은 하지 않는다. 요청이 아예 없어야 통과한다. 외부에서 가져온 에셋은 대체 경로가 아니라 실패다.

테마 색상은 `light-dark()`를 써서 하나의 파일이 두 테마를 담게 할 수 있으며, 대비 검사는 해석된 두 값으로 한다.

## 2. 비례 기하

막대는 플롯 높이에 대한 `value / axisMax * 100%`로 만들어야 하며(**MUST**), 축 라벨도 같은 상자 기준으로 백분율로 배치해야 합니다(**MUST**). 오프라인 파일은 모든 스크립트·스타일·폰트·이미지를 인라인으로 넣어야 하며(**MUST**), 차트는 자바스크립트 없이 첫 렌더링에서 읽을 수 있어야 합니다(**MUST**).

축 라벨은 같은 플롯 상자 기준으로 백분율로 배치한다. `axisMax` 라벨은 상단에, 0 라벨은 기준선에 닿는다. 픽셀로 추측한 라벨 위치는 플롯 높이가 바뀌면 어긋난다.

## 3. 자바스크립트 없는 첫 렌더링

막대·라벨·값은 일반 마크업이나 인라인 SVG로 렌더링하므로 자바스크립트를 꺼도 차트를 읽을 수 있다. 자바스크립트는 이미 읽을 수 있는 차트를 보강할 수 있으며, 호버 값 읽기나 테마 토글이 여기에 속한다. 차트를 처음 그리는 일은 자바스크립트가 하지 않는다.

## 4. 출처 주석

차트 위에 데이터 출처, 기간, 계산 방식을 적는다. 부분 기간은 부분이라고 밝힌다. 반쪽짜리 월 막대는 전체 월인 척하지 말고 "정산 구간: 1–15일"처럼 적는다. 숫자가 어디에서 왔는지 숨기는 차트는 납품 게이트 H1에 걸린다.

## 5. 빈 상태와 오류 상태

두 상태를 파일 안에 설계한다. 빈 상태는 해당 구간에 데이터가 없고 다음 행동을 말하며("데이터가 아직 도착하지 않았습니다. 정산 파일 업로드 후 다시 확인해 주세요"), 오류 상태는 원인과 다시 시도하는 방법을 말해야 한다. 빈 플롯은 빈 상태가 아니다.
