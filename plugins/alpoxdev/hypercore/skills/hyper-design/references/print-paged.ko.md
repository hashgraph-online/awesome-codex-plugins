# 인쇄와 페이지 나눔

출력이 페이지를 나눠 타야 하는 문서일 때 읽는다. 인쇄 스타일시트, 청구서나 보고서를 PDF로 만든 경우, 영수증, 페이지에 걸쳐 끊기는 레이아웃이 대상이다. 이 패키지의 화면 규칙은 하나의 연속된 캔버스를 설명한다. 여기의 캔버스는 페이지 상자들의 나열이며, 실패는 반쯤 빈 페이지, 갈라진 표 행, 페이지 밑바닥에 고립된 제목이다.

## 1. 페이지 상자와 여백

| 징후 | 이유 | 고치기 |
|---|---|---|
| 인쇄 렌더링이 화면 폭을 그대로 유지 | 페이지는 뷰포트가 아니라 종이다 | `@page` 크기와 여백을 먼저 정한 뒤 내용이 페이지에 맞게 크기를 정한다 |
| 한가운데가 빈 종. 아무도 고르지 않은 큰 여백 | 기본 여백을 그냥 받아들여 내용이 종 가장자리에 붙는다 | 문서가 정말로 필요로 하는 여백을 정하고, 머리글과 페이지 번호는 내용 상자가 아니라 여백 영역에 둔다 |
| 종보다 조금 긴 모든 페이지 | 문서가 울퉁불퉁한 마지막 페이지를 만들었다 | 페이지 수를 확인하고 넘치는 블록을 찾은 뒤 그곳을 고친다. 전부 줄여서 맞추지 않는다 |

## 2. 끊김 조절

| 징후 | 이유 | 고치기 |
|---|---|---|
| 페이지가 문단 중간에서 끝나고 다음 페이지에 한 줄만 남음 | widow 줄은 실수처럼 읽힌다 | 본문에 `orphans: 3`과 `widows: 3`을 둔다. 페이지에서 시작하는 블록은 줄을 함께 들고 간다 |
| 표 행이 두 페이지에 갈라지고 뒷부분에 머리글 없음 | 행을 읽을 수 없다 | 행과 그림에 `break-inside: avoid`를 주고, 표가 갈라져야 하면 머리글 행을 반복한다 |
| 제목만 페이지 밑바닥에 있고 문단은 다음 페이지에 있음 | 끊김에서 구조를 잃는다 | 제목에 `break-after: avoid`를 둔다. 제목이 이끄는 블록과 붙어 간다 |
| 앞페이지를 3분의 1만 채우고 새 페이지에 강제된 절 | 수동 끊기는 내용이 바뀔 때마다 반복된다 | 진짜 시작(챕터, 폼 필드 그룹)에만 `break-before: page`를 쓰고, 나머지는 흐름이 페이지나눔하게 둔다 |

## 3. 통째로 유지할 블록

블록이 페이지보다 길지 않다면 한 페이지에 두도록 유지한다. 길면 쪼개야 하며, 그때는 의도적으로 나눈다.

- 캡션을 단 그림.
- 표 행, 그리고 두 줄 이상의 내용이 들어가는 표 셀.
- 제목과 그 제목이 이끄는 블록의 첫 줄.
- 서명 줄과 그 줄이 서명하는 텍스트, 폼 필드와 라벨·오류 메시지.
- 인용이나 콜아웃 등, 텍스트와 떨어지면 논지가 끊기는 것.

## 4. 끊김 조절의 부작용

`break-inside: avoid`는 공짜가 아니다. 페이지보다 긴 블록에 쓰면 그 블록을 다음 페이지로 밀어내고, 블록만 남은 페이지에 이를 때까지 반복하거나 넘친다. 한 페이지에 들어갈 만큼 짧은 블록에만 쓰고, 긴 블록은 나눠지게 두며 `orphans`와 `widows`로 나누는 방식을 조절한다. 강제 페이지 끊기는 앞페이지를 짧게 만들 수도 있다. 수동 끊김을 쓴 뒤에는 앞페이지를 확인한다.

## 5. 만든 PDF 검토

소스 스타일시트는 페이지 나눔을 증명하지 못한다. 증거는 만든 PDF다.

- 페이지 수를 읽고 문서가 돼야 하는 페이지 수와 비교한다. 예상과 다른 페이지는 설명할 때까지 결함이다.
- 모든 페이지 끊김을 순서대로 본다. 각 페이지의 마지막 블록과 다음 페이지의 첫 블록을 확인해 고아 줄, 갈라진 행, 고립된 제목, 거의 빈 페이지를 찾는다.
- 여백과 머리글·페이지 번호를 페이지마다 확인한다. 첫 페이지와 가로 페이지라 특히 그렇다.
- 페이지 수와 확인한 끊김을 보고서에 적는다. 렌더된 PDF가 없으면 이 항목은 `static_only`다.
