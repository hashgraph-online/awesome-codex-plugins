## 로드 조건

요청이 이미지 제작 범위에 해당한다고 판단한 뒤, 브리프를 작성하기 전에 이 참고 문서를 로드합니다. 새 이미지, 편집, 프롬프트 전용 산출물에 사용합니다. 시각 분석, 프롬프트 모음, 인터페이스 구현, 코드 작업에는 로드하지 않습니다.

이 플레이북은 요청의 목적에서 보이는 결정을 이끕니다. 고정된 하우스 스타일이나 제공자 명령 형식을 지시하지 않습니다. 사용자가 다른 언어를 요청하지 않는 한 사용자 대상 브리프, 인계, 완료 기록은 한국어를 기본값으로 합니다.

## 시각적 약속 정하기

이미지의 용도와 반드시 달성해야 할 한 가지 효과를 명시합니다. 그다음 시청자가 먼저 알아차릴 요소, 이를 뒷받침할 요소, 조용히 남겨 둘 요소를 정합니다. 유용한 브리프는 다음을 구분합니다.

- **목적:** 이미지가 뒷받침할 결정, 감정, 행동입니다.
- **위계:** 첫 번째, 두 번째, 배경의 읽기 순서입니다.
- **주제:** 사람, 물체, 장소, 사건과 결정적인 특성입니다.
- **경계:** 특히 편집에서 바뀌지 않아야 하는 요청 사실입니다.

결정적인 사실이 빠졌을 때 장식적인 가정으로 대신하지 않습니다. 누락이 정체성, 정확한 렌더링 텍스트, 필수 내용, 이미지의 의미를 바꾸면 한 가지에 집중한 질문을 합니다. 그 외에는 목적에 따른 되돌릴 수 있는 선택을 하고 브리프에 밝힙니다.

## 장면을 의도적으로 구성하기

위계가 보이도록 프레이밍, 시점, 주제 크기, 배치, 깊이, 여백, 크롭을 선택합니다. 분위기 라벨보다 관계를 설명합니다. 예를 들어 단순히 세련되었다고 하기보다 제품의 위치, 배경, 시선의 이동을 말합니다.

광원 방향, 부드러움, 대비, 그림자 성질, 분리감을 기준으로 빛을 선택합니다. 색은 역할로 정합니다. 주된 바탕, 보조 범위, 강조색, 읽기에 필요한 대비를 기록합니다. 특정 제공자 레시피를 빌리지 않고 재질과 렌더링 단서로 표면 반응, 모서리 처리, 질감, 매체를 설명합니다.

이미지 안의 텍스트가 필요하면 정확한 문자열을 따옴표로 기록하고 읽기 우선순위, 위치, 대비, 크기, 여백을 지정합니다. 렌더링 텍스트를 몰래 수정, 번역, 축약, 발명하지 않습니다. 결과물을 검사하기 전에는 텍스트 정확성과 가독성을 확인했다고 할 수 없습니다.

## 시리즈 유지하기

여러 이미지를 요청받으면 첫 이미지를 만들기 전에 작은 불변 조건 묶음을 작성합니다. 반복되는 주제 특성, 시점 논리, 조명 성격, 색 역할, 타이포그래피 처리, 재질 언어, 레이아웃 리듬처럼 묶음의 연결성을 만드는 사실만 유지합니다. 변형은 불변 조건을 바꾸지 않도록 각 이미지별로 따로 기록합니다.

편집에서는 제공된 원본을 증거로 이름 붙이고, 보존 영역과 변경 영역을 구분하며, 원본과 별도의 새 결과물을 유지합니다. 요청에 적혔다는 이유만으로 정체성, 연속성, 보존을 주장하지 않습니다.

## 시각적 주장을 하기 전 검사하기

검사가 가능하고 필수일 때 저장된 결과물을 브리프와 대조해 검사합니다. 위계, 주제 사실, 구성, 빛, 색 역할, 재질 단서, 정확한 렌더링 텍스트, 적용되는 각 시리즈 불변 조건을 확인합니다. 프롬프트를 결과처럼 다시 쓰지 말고 관찰된 결함을 기록합니다.

저장 뒤 검사가 선택 사항이지만 불가능하거나 불확실하면 결과물이 존재한다는 사실만 보고하고, 보이는 제약, 렌더링 텍스트, 가독성, 시리즈 일관성에 대한 주장은 명시적으로 보류합니다. 필수 검사가 불가능하거나 실패하거나 중대한 불일치를 보이면 시각적 성공 보고를 중단합니다. 허용되는 경로와 종료 상태는 런타임 기능 지침을 따르며, 무한히 재시도하거나 프롬프트를 검사된 이미지처럼 제시하지 않습니다.

## 어휘집과 죽은 단어

빈 칭찬 단어는 브리프에 들어가기 전에 세 경로 중 하나로 환원합니다.

| 빈 단어 | 숫자화 | 신체 반응 | 구체 예시 |
| --- | --- | --- | --- |
| 멋지게 / stunning | 팔레트 스톱 수, Kelvin, key:fill 비율 | 시선이 먼저 닿는 곳, 프레임이 얼마나 넓게 느껴지는지 | 무광 검정 필드, 단일 방향 광원 |
| 고급스럽게 / beautiful | 재질 수, 여백 비율 | 손이 기대하는 질감 | 브러시드 메탈, 단일 접촉 그림자, 평평한 필드 |

카메라 어휘는 기어명이 아니라 결과를 서술합니다.

| 기어명 | 결과 서술 |
| --- | --- |
| 광각 / 24mm | 가장자리가 늘어나고 배경이 멀어지며 피사체가 넓은 공간에서 작게 느껴짐 |
| 망원 / 85mm | 배경이 피사체 쪽으로 압축되고 층이 평평해짐 |
| 매크로 | 표면 결과 미세 질감이 지배하고 심도가 얕아짐 |
| 탑다운 / 플랫레이 | 사물이 평면 위의 형태로 읽히고 지평선이 없음 |

색은 명명된 오브젝트에 바인딩합니다: 떠 있는 팔레트가 아니라 "의자는 #2F4BFF"처럼 씁니다. 날것의 HEX 목록을 출력하지 않습니다.

디슬롭 축 — AI 기본 루틴을 현실 속성으로 바꿉니다.

| AI 기본 루틴 | 현실 속성 |
| --- | --- |
| 모든 것에 빛나는 림 라이트 | 감쇠 방향이 있는 하나의 동기 있는 광원 |
| 대칭 중앙 배치 피사체 | 한쪽에 여유를 둔 비중심 배치 |
| 불가능할 만큼 깨끗한 표면 | 이음새, 결, 마모, 또는 하나의 흠집 |
| 모든 색이 채색됨 | 하나의 강조색만 있는 절제된 팔레트 |

죽은 단어는 브리프에서 금지하고 위의 세 경로로 환원합니다. canonical 집합은 검증기 상수 `DEADWORD_MAP`이며 이 표는 그 미러입니다.

| 코드 | 표면형 |
| --- | --- |
| W_EMPTY_ADJ | 멋지게, 고급스럽게, beautiful, stunning |
| W_SD_ERA_BOOSTER | masterpiece, 8k, 4k, uhd, trending on artstation |
| W_WEIGHT_SYNTAX | (word:1.3) 및 모든 `(token:number)` 가중치 형태 |
| W_SD_FLAG | --ar, --v 및 기타 꼬리 플래그 문법 |

## 브리프 기록

다음 필드로 작업 브리프를 바로 탐색할 수 있게 유지합니다.

```text
purpose:
hierarchy:
subject:
composition:
light:
color:
material_and_rendering:
rendered_text:
series_invariants:
preserved_or_changed_boundary:
inspection_checks:
assumptions_and_open_question:
```

실제로 적용되지 않는 필드는 자리표시자로 채우지 말고 생략합니다. 이 기록은 의사결정과 검사의 기준이며, 이미지 생성 또는 저장의 증거는 아닙니다.
