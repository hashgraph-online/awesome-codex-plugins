# 프롬프트 작성 레퍼런스

요청에 카테고리, 출력 형식, 텍스트 렌더 규칙이 필요할 때 읽습니다.

요청을 카테고리로 판정하고, 고른 카테고리의 행만 읽어 브리프를 구성합니다. 이 파일은 카테고리 라우팅, 형식 선택, 컷 분할, 텍스트 렌더 규칙을 담습니다. 어휘 선택과 죽은 단어 환원은 `visual-direction.ko.md`를 따릅니다.

## 요청 카테고리

요청의 신호 단어를 읽어 아래 표에서 카테고리 하나를 고릅니다. 두 카테고리가 겹치면 경계 규칙을 따르고, 판정 후에는 그 카테고리의 행만 로드합니다. 표의 기본 캔버스는 비율 서술일 뿐이며, 실제 비율·사이즈는 `canvas` 선택 키로 전달하고 프롬프트 문자열에 쓰지 않습니다.

| 카테고리 | 컷타입 후보 | 기본 캔버스 | 필수 디테일 | 신호 단어 | 경계 |

## 편집 카테고리

제공한 이미지를 편집하는 요청이면 생성 행 대신 편집 카테고리 하나를 고릅니다. 모든 편집 브리프에는 `change only <X>; keep <Y> unchanged`와 `rules/prompt-compilation.ko.md`의 보존 목록을 씁니다.

| 편집 카테고리 | 이것만 바꿈 | 항상 보존 |
| --- | --- | --- |
| 텍스트 현지화 | 이미지 안 문구 | 레이아웃, 서체, 간격, 위계. 새 문구에 필요할 때만 줄을 다시 배치 |
| 신원 보존 | 지정한 옷, 배경, 소품 | 얼굴, 몸, 자세, 머리, 표정. 빛과 그림자를 맞춤 |
| 정밀 객체 편집 | 지정한 요소 하나의 제거나 교체 | 주변 질감과 조명, 나머지 전부 |
| 조명과 날씨 | 시간대, 계절, 분위기, 강수 | 형태, 프레이밍, 대상 신원 |
| 배경 분리 | 배경을 실제 투명으로 잘라냄 | 후광 없는 선명한 실루엣, 라벨 글자 그대로, 스타일 변경 없음 |
| 스타일 전이 | 참고 스타일로 그린 대상이나 장면 | 지정한 스타일 단서(팔레트, 질감, 붓질). 요소 추가 없음 |
| 합성 | 번호 붙인 이미지 사이에서 옮기는 요소 | 바탕 프레이밍. 빛·원근·크기를 맞춤 |
| 스케치를 렌더로 | 선화에서 완성 렌더로 바뀌는 매체 | 레이아웃, 비율, 원근. 새 요소 없음 |

## 형식 선택

- Format A(기본): 단순 요청은 자연스러운 산문 브리프를 씁니다. 라벨을 붙이지 않습니다.
- Format B(선택): 한 화면에 텍스트·도표·오브젝트가 여럿 얹히는 복잡한 구조 요청(카드뉴스, 인포그래픽, 포스터)에만 명명 섹션을 쓸 수 있습니다.
- Format B를 쓸 때의 규칙: 허용 라벨은 `subject`, `context`, `composition`, `lighting`, `style`, `text` 여섯 개뿐입니다. 각 라벨은 브리프 안에서 정확히 한 번만 등장하고, `label:` 형태로 줄을 시작합니다. 라벨 블록 밖이나 브리프 끝에 전달 보고·능력 관측·경로 같은 리포트 문구를 쓰지 않습니다.
- 어느 형식이든 컴파일 결과는 그대로 사용 가능한 브리프 하나입니다.

## 한 행, 한 컷, 한 호출

한 요청 행은 한 컷이고 한 번의 생성 호출입니다. 여러 컷을 하나의 캔버스(그리드·아트보드)에 나눠 그리는 요청은 표준 경로가 아닙니다. 컷이 여러 개 필요하면 각각 별도 브리프로 분할하고, 공통 불변 조건(팔레트·조명·활자 처리·모티프)을 모든 브리프에 반복합니다.

## 캔버스

요청한 형태는 비율 서술로만 적고, 실제 비율과 크기는 런타임의 구조화 필드로만 넘기며 프롬프트 문자열에 넣지 않습니다. 런타임에 크기 필드가 없으면 값을 지어내지 않고 보고에 밝힙니다. 편집은 보통 원본 비율을 유지합니다. 이미지를 여러 장 제공했으면 어느 이미지가 출력 비율을 정하는지 적습니다. 일부 런타임은 마지막 입력을 따르기 때문입니다. 런타임이 요청과 다른 장수나 크기를 돌려줄 수 있으므로 돌아온 그대로 보고합니다.

## 텍스트 렌더링

렌더될 문자는 브리프 안에서 따옴표로 고정합니다. 따옴표 안의 문자열은 정확히 그대로이며 번역·정규화·축약·단어 추가를 하지 않습니다.

- 영역 명명: 캔버스를 3×3 영역(위-가운데-아래 × 좌-중-우)으로 나눠 텍스트 위치를 지정합니다. 예: "제목은 상단 중앙 영역".
- 롤 라벨: 텍스트에는 역할이 있습니다 — `headline`(주제 표제), `subhead`(부제), `callout`(강조 풍선·주석), `caption`(보조 설명). 각 문구에 역할을 붙입니다.
- 자유 작성 존: 따옴표 밖의 장면 서술은 자유 문장입니다. 렌더 텍스트가 아닌 말을 따옴표에 넣지 않습니다.
- 밀도 레버: 텍스트가 많아지면 캔버스 세로 방향을 우선하고, 밀도가 높은 작업은 2048 길이 방향을 고려합니다(canvas 선택 키로 전달).
- 도표 돌파: 복잡한 도표는 좌표 배치(요소마다 3×3 영역 지정), 화살표 문장화("A에서 B로 화살표"), 이중 앵커(위치+역할 모두 지정) 순으로 시도하고, 실패하면 같은 순서로 재시도합니다.
- 생성 후 글자 후처리는 금지입니다. 글자가 틀리면 합성·보정이 아니라 브리프를 고쳐 재생성합니다.
