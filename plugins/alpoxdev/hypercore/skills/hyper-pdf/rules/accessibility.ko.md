# 접근성과 구조

> 태그가 있는 PDF가 접근성 있는 PDF는 아닙니다. 태그는 최소선이고, 화면 낭독기가 실제로 필요한 것은 읽기 순서·언어·대체 텍스트입니다.

## 1. 바이트 검사가 증명할 수 있는 것

`check`는 바이트 단위 검사와 CoreGraphics 조회로 이슈 코드를 보고합니다. 코드마다 보조기술이 잃는 것이 분명히 있습니다.

| 코드 | 의미 | 사용자가 잃는 것 |
|---|---|---|
| `NO_STRUCTURE_TREE` | 카탈로그에 `/StructTreeRoot`가 없음 | 낭독기가 구분 없는 텍스트 덩어리 하나를 받음. 제목·목록·표가 없음 |
| `NO_LANGUAGE_TAG` | 카탈로그에 `/Lang`이 없음 | 낭독기가 발음을 추측. 한국어를 영어 음소로 읽음 |
| `FONT_NOT_EMBEDDED` | 쓰인 글꼴의 `FontFile2`/`FontFile3`가 없음 | 낭독기가 다른 글꼴로 대체해 줄바꿈이 바뀌고, 기호 글꼴이면 읽는 글자 자체가 바뀜 |
| `TYPE3_GLYPHS` | `Type3` 글꼴 객체가 있음 | 글리프가 유니코드 매핑 없는 절차로 그려져 추출과 낭독이 모두 깨질 수 있음 |
| `PAGE_BLANK` | 쪽에 잉크가 거의 없음 | 인도한 문서의 빈 쪽은 읽는 사람이 보는 결함 |
| `PAGE_NEEDS_OCR` | 쪽에 잉크가 있고 텍스트가 없음 | 검색과 화면 낭독기에서 그 쪽이 보이지 않음 |
| `CONTAINS_JAVASCRIPT` | 이름 트리에 `/JS` 또는 `/JavaScript` | 접근성 결함은 아니지만 열기 전에 살펴볼 이유 |
| `CONTAINS_LAUNCH_ACTION` | `/Launch` 또는 `/SubmitForm` 액션 | 클릭으로 외부 프로그램이 실행될 수 있음. 신뢰할 수 없는 문서로 취급 |
| `ENCRYPTED` | 트레일러에 `/Encrypt` | 텍스트 추출과 보조기술에 암호가 먼저 필요 |

## 2. 읽기 순서

구조 트리가 순서를 담습니다. 오른쪽 단을 왼쪽 단보다 먼저 그리는 콘텐츠 스트림으로 만든 PDF는 글자는 맞고 트리가 틀립니다. 그러면 낭독기가 쪽을 거꾸로 읽습니다.

| 출처 | 순서 품질 |
|---|---|
| `--export-tagged-pdf`를 쓴 `html` 경로 | Chromium이 DOM에서 트리를 만들므로 순서가 화면 위치가 아니라 마크업을 따름 |
| `build` 경로 | 구조 트리가 아예 없음. 순서는 스펙의 블록 순서라 구조상 맞지만 낭독기가 볼 수 없음 |
| 스캔 + OCR | OCR 엔진의 줄 검출을 따름. 두 단 쪽에서 확인 필요 |

두 단 문서는 텍스트를 추출해 순서를 시각적 위에서 아래, 왼쪽에서 오른쪽 순서와 비교해 확인합니다. 어긋나면 그 사실을 말합니다. 보이지 않는 독자는 그 순서를 알 다른 방법이 없습니다.

## 3. 언어 태그

CoreGraphics는 `/Info`는 쓰지만 언어 키는 무시합니다. 엔진은 기존 카탈로그를 증분 갱신으로 새 객체로 덧붙여 `/Lang`을 씁니다. 원본 바이트와 오프셋은 그대로 유효합니다.

```
engine.js build --spec <spec.json> --out <out.pdf>   # spec.lang: "ko-KR"
```

규칙:

- 문서 언어는 카탈로그 `/Lang`에, 다른 언어가 섞인 구간은 `Span` `/Lang`에 답니다(한국어 계약서 안의 영어 제품명 같은 경우).
- BCP 47 태그를 씁니다. `korean`도 `ko_KR`도 아닌 `ko-KR`.
- 입력이 아니라 스캔에서 확인합니다. `rawScan.lang`이 의도한 태그와 같아야 합니다. 빌드가 성공한 것이 태그가 들어갔다는 증거는 아닙니다.

## 4. 대체 텍스트

`check`는 대체 텍스트가 뜻이 있는지 증명하지 못하고, 그림에 그것이 없다는 것만 증명합니다. 문서에 차트·서명 이미지·도해가 있으면:

- 스펙의 이미지 블록에 `alt`를, HTML 경로에서는 `<img>`에 `alt`를 넣습니다.
- 대체 텍스트는 픽셀이 아니라 기능을 설명합니다. "chart image"가 아니라 "2026년 매출 추이, 3분기부터 증가".
- 장식용 괘선이나 배경 무늬는 빈 alt로 낭독기가 건너뛰게 합니다.

## 5. 이 스킬이 하지 않는 것

- 임의의 제3자 PDF 구조 트리를 고치지 않습니다. 잘못된 콘텐츠 스트림 위에 트리를 다시 세우면 콘텐츠에 없는 구조를 주장하는 트리가 되어 없는 것보다 나쁩니다.
- 표준 적합성을 인증하지 않습니다. `check`는 기계적 발견을 보고하고, 적합성에는 사람의 읽기 순서·대체 텍스트 판단이 함께 필요합니다.
- 보조기술을 실행하지 않습니다. 그 시험 없이 "화면 낭독기에서 동작한다"고 주장하면 미검증이며 그렇게 보고해야 합니다.
