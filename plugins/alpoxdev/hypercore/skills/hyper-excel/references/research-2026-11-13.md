## Analysis of the top 5

### 1. anthropics/skills `xlsx`

Its `SKILL.md` forces "read → modify → recalculate → verify" in that order, and `scripts/recalc.py` splits writing formula results into the cache out as a separate script. **Taken**: recalc as a required pipeline step, not an option. **Not taken**: requiring LibreOffice as the recalculation engine — this machine has none, and not requiring an install was part of the brief, so an own evaluator replaced it.

### 2. anthropics/financial-services `xlsx-author`

It gathers assumptions into one sheet and makes every calculation reference those cells. **Taken**: the design instruction to keep assumptions in one sheet and reference them from calculations (reflected in this skill's design-first workflow and in the `hyper-excel-workflow-design-first-ko` case).

### 3. haris-musa/excel-mcp-server

It exposes tools such as `create_workbook`, `apply_formula`, `validate_formula_syntax`, `create_chart`, and `create_pivot_table` from one server. The README advertises "PivotTables, slicers". **Taken**: splitting the tool surface by user intent. **Not taken**: native pivot generation — this skill works on OOXML directly, and hand-writing a pivot cache is a risk it declines; it writes computed rows instead and says so.

### 4. iOfficeAI/OfficeCLI

One binary handles Word, Excel, and PowerPoint, with subcommands split into `read/edit/automate`. **Taken**: naming subcommands after user verbs (read, verify, create, edit). This skill's `inspect/verify/build/patch/recalc/profile` is the result.

### 5. BayramAnnakov/excel-hygiene

It implements the 13-item Panko–Halverson spreadsheet error taxonomy as deterministic checks in `check_excel.py`. **Taken**: pinning error types as codes and reporting by code. The 12 items in `rules/failure-modes.md` and the 8 finding codes in `verify_formulas.py` started here.

## How this skill differs

| Axis | Typical Excel skill | hyper-excel |
|---|---|---|
| Dependencies | openpyxl/pandas required | standard library only; openpyxl is an optional read-back check |
| Editing | re-save the whole file | part-level patch with a SHA-256 proof for untouched parts |
| Recalculation | requires LibreOffice/Excel | own evaluator; unsupported functions are reported as unevaluated, never guessed |
| Pivot | attempts a native pivot | computed rows plus an autofilter range, and states that it is not native |
| Korean | mentioned generally | cp949, BOM, `2026. 1. 31.`, and `#,##0"원"` backed by measurements |
