# 테마

테마는 토큰 파일이다. 색, 활자, 여백을 바꾸고, 구조는 바꾸지 않으며 어떤 블록이 존재하는지도 바꾸지 않는다.

## 1. 고르기

| 테마 | 모양 | 쓰는 곳 |
|---|---|---|
| `civic`(기본) | 산세리프, 차가운 회색, 파란 강조색, 17mm 여백, 10.2pt | 비즈니스, 공공 부문, 현황 보고, 전달될 문서 |
| `editorial` | 세리프 본문, 따뜻한 중성색, 옥스블러드 강조색, 19mm 여백, 10.4pt | 리서치 노트, 분기 리뷰, 길게 읽히려는 문서 |

테마 둘이 적당한 수다. 세 번째 테마는 정당화를 요구하는 부탁이다.

## 2. 설정하기

원본 frontmatter에서:

```yaml
theme: "editorial"
```

또는 렌더링 시점에. 이쪽이 frontmatter를 이긴다:

```bash
--theme editorial
```

`--list-themes`가 설치된 테마를 출력한다.

## 3. 토큰 집합

모든 테마가 이것들을 정의하며, 새 테마도 전부 정의해야 한다. 빠지면 기준 스타일시트의 대체값이 대신 들어간다.

| 토큰 | 의미 |
|---|---|
| `--paper` | 페이지 배경 |
| `--ink` | 본문 텍스트 |
| `--muted` | 캡션, 바닥글, 보조 라벨 |
| `--muted-strong` | 강조된 보조 텍스트, 인용 본문 |
| `--rule` | 가는 선: 표 행, 바닥글 선, 제목 선 |
| `--rule-strong` | 표 머리글 밑줄과 표 아래쪽 경계 |
| `--accent` | 유일한 강조색: 선, 인용 표시, 링크, 콜아웃 테두리 |
| `--surface` | 콜아웃과 인용 배경 |
| `--code-bg` | 인라인 코드와 코드 블록 배경 |
| `--font-body`, `--font-heading`, `--font-mono` | 글꼴 스택 |
| `--font-size`, `--line-height` | 본문 크기 체계 |
| `--page-margin-x`, `--page-margin-top` | 여백 |

## 4. 테마가 깨면 안 되는 규칙

- **강조색 하나.** 두 번째 강조색은 강조를 장식으로 만들고, 그러면 아무것도 강조되지 않는다.
- **대비.** 종이 위 본문은 크림색 위 회색이 아니라 흰색에 가까운 바탕 위 검정에 가깝다. 강조색은 선과 표시에 쓰고, 작은 크기의 본문에는 쓰지 않는다.
- **인쇄 안전 크기.** 본문은 10pt에서 11pt 사이. 9pt가 필요한 테마는 더 작은 문서가 아니라 더 빽빽한 문서를 위한 테마다.
- **한국어 글꼴 우선.** 모든 글꼴 스택은 라틴 대체 글꼴보다 한국어 글꼴을 먼저 나열한다. 그러지 않으면 한국어 텍스트가 치수가 다른 대체 글꼴로 조용히 렌더링되고 페이지 나눔이 밀린다.
- **인쇄에 배경 이미지, 그라디언트, 그림자 없음.** 잉크만 쓰고 페이지에서는 아무것도 얻지 못한다.

## 5. 새 테마 만들기

가장 가까운 기존 테마를 복사하고 토큰을 바꾼 뒤 페이지 세 장을 확인한다. 빽빽한 표 페이지, 그림 페이지, 표지다. 표의 머리글 선과 바닥글 선을 구별할 수 없다면 선 토큰이 너무 가깝다.

그다음 파일을 `assets/runtime/themes/`에 넣으면 `--list-themes` 출력에 추가된다. 목록은 디렉터리에서 읽는다.
