# 레이아웃 규칙

페이지는 크기가 고정된 상자다. 내용이 거기 맞거나 맞지 않거나 둘 중 하나이며, 페이지 나눔기는 친절하려고 페이지를 늘리지 않는다.

## 1. 페이지 지오메트리

| 토큰 | A4 값 | 효과 |
|---|---|---|
| `--page-width` | 210mm | 페이지 상자 |
| `--page-height` | 297mm | 페이지 상자 |
| `--page-margin-x` | 17–19mm | 좌우 본문 여백. 바닥글 안쪽 여백이기도 하다 |
| `--page-margin-top` | 18–20mm | 위 여백. 아래쪽은 바닥글 선을 위해 20mm를 비워 둔다 |
| 본문 열 | 페이지 폭 − 2 × 여백 | 여백 19mm의 A4에서 약 172mm |

흐름 영역은 `페이지 높이 − 위 여백 − 아래 예약 20mm`다. 위 여백 18mm의 A4에서 쓸 수 있는 높이는 259mm이며, 활자 크기 10.4pt에 행간 1.62에서 약 62행이다.

바닥글은 절대 위치에 놓이고 흐름에 들어가지 않으므로, 긴 내용이 바닥글을 페이지 밖으로 밀어낼 수 없다.

## 2. 활자 크기 체계

| 요소 | 크기 | 행간 | 비고 |
|---|---|---|---|
| 본문 | 10.2–10.4pt | 1.6–1.68 | 두 테마가 여기서 갈린다. 둘 다 인쇄 안전 범위 안이다 |
| `h1` | 1.78em | 1.24 | 절의 시작 |
| `h2` | 1.3em | 1.24 | 하위 절. 아래에 선이 붙는다 |
| `h3` | 1.08em | 1.24 | 보고서에서는 드물다. 세 단계는 대개 하나가 과하다 |
| 표 | 0.94em | 상속 | 다섯 열 표가 들어갈 만큼 작고, 읽을 만큼 크다 |
| 캡션 | 0.86em | 상속 | 흐린 색, 가운데 정렬 |
| 바닥글 | 8pt | — | 작고 흐리며 위에 선이 있다 |

인쇄 보고서의 본문은 9pt 아래로 내려가지 않는다. 8pt가 필요한 페이지는 기본값이 작은 것이 아니라 내용이 많은 것이다.

## 3. 페이지를 깨뜨리는 것

페이지 나눔기는 블록을 하나씩 놓고, 블록이 들어가지 않으면 새 페이지를 연다. 이 단순한 규칙에서 세 가지 실패가 남는다.

**넘침.** 흐름 영역 전체보다 높은 블록 하나는 빈 페이지로 옮겨도 들어가지 않으므로 잘린다. 점검이 `PAGE_OVERFLOW`를 보고한다. 고치는 방법은 블록을 나누는 것이다. 이만큼 긴 문단은 문단 여러 개이고, 이만큼 높은 표는 표 두 개다.

**열보다 넓은 블록.** 열이 많은 표나 본문 열보다 넓은 이미지는 가로 넘침을 만들고 페이지가 그것을 자른다. 점검이 태그와 함께 `BLOCK_TOO_WIDE`를 보고한다. 선호 순서대로 고치면 열 빼기, 머리글 줄이기, 표 나누기, 이미지 축소다.

**고립된 제목.** 페이지의 마지막 요소가 된 제목은 제목으로 끝나는 페이지처럼 읽힌다. 페이지 나눔기는 제목을 다음 페이지로 끌어당기고 그 페이지를 `page-short`로 표시한다. 남은 빈 공간은 버그가 아니라 의도된 것이다.

## 4. 표

- 여백 17mm의 A4에서 다섯 열이 편안한 최대치다. 값이 짧으면 여섯 열도 들어간다.
- 긴 텍스트 셀은 줄바꿈된다. 문단이 들어간 셀은 표가 아니라 산문에 속한다.
- 숫자 열은 `---:`로 오른쪽 정렬하고 표 형식 숫자를 써서, 행마다 자릿수가 맞는다.
- 표는 페이지를 넘어 나뉘지 않는다. 나뉠 상황이면 통째로 다음 페이지로 옮겨가며, 페이지보다 높은 표가 막는 발견인 이유가 여기 있다.
- 머리글 행은 표가 나뉠 때만 반복되는데 표가 나뉘지 않으므로, 반복 규칙이 필요 없다.

## 5. 그림

- 이미지는 열 폭에 맞춰 줄어들고 그 폭을 넘지 않는다. 높이는 가로세로 비를 따른다.
- 세로로 긴 그림(세로 스크린샷, 긴 차트)은 가장 흔한 넘침 원인이다. 이미지를 잘라내거나, 짧은 캡션과 함께 한 페이지에 단독으로 놓아 높이를 억제한다.
- 캡션은 그림 아래에 가운데 정렬로 놓이고 그림을 해석한다.
- 그림과 캡션은 함께 움직인다. 그림이 블록 하나이므로 둘은 떨어질 수 없다.

## 6. 표지

표지는 Markdown 제목이 아니라 HTML 블록이다.

```html
<div class="cover">
  <div>
    <div class="cover-rule"></div>
    <div class="cover-eyebrow">내부 검토용</div>
    <h1>시장 진입 분석</h1>
    <p class="cover-sub">2026년 4분기 후보 3안 비교</p>
  </div>
  <div class="cover-meta">
    <span><b>작성</b> 양민열</span>
    <span><b>일자</b> 2026-11-13</span>
    <span><b>대상</b> 경영진</span>
  </div>
</div>
```

표지는 자기 페이지를 채운다. 표지가 흐름 높이 전체이므로 다음 블록이 자동으로 새 페이지를 연다.

## 7. 점검이 실패했을 때 조정하기

| 증상 | 첫 번째 고치기 | 두 번째 고치기 |
|---|---|---|
| 문단 하나가 넘친다 | 문단을 나눈다 | 마지막 문장을 다음 절로 옮긴다 |
| 표가 너무 넓다 | 열을 뺀다 | 머리글 문구를 줄인다 |
| 그림이 넘친다 | 이미지를 잘라낸다 | 한 페이지에 단독으로 놓는다 |
| 보고서가 한 줄 넘게 길다 | 2절에서 문장을 하나 뺀다 | 행간을 0.04pt 좁힌다 |
| 마지막 페이지가 거의 비었다 | 내용을 줄여 페이지를 없앤다 | 짧은 절 둘을 합친다 |

지오메트리를 바꾸기 전에 내용을 바꾼다. 페이지에 맞추려고 활자를 줄인 보고서는 자기 분량에 대해 거짓말한 보고서다.
