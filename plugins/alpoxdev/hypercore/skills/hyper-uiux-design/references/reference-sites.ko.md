# 레퍼런스 사이트

UIBowl이나 Mobbin을 읽는 실행에서 이 참조를 읽습니다. 아래 날짜에 각 사이트가 계정 없는 브라우저에 무엇을 보여 줬는지, 각 사이트의 공개 페이지가 자료 사용을 어떻게 말하는지를 기록합니다. 여기 적힌 모든 서술은 날짜가 붙은 관찰이고 고정된 사실이 아닙니다.

## 1. 이 파일을 쓰는 방법

- 표를 보고 어떤 페이지를 열 만한지, 어디서 읽기가 멈출지를 정합니다.
- 읽기 규칙 자체는 [../rules/reference-use.ko.md](../rules/reference-use.ko.md)에 있습니다. 이 파일은 권한을 더하지 않습니다.
- 메모에 행을 인용할 때는 읽은 날짜를 함께 적습니다. 눈앞의 페이지가 행과 다르면 페이지가 맞습니다. 본 것을 기록하고 그 행은 낡은 것으로 봅니다.
- `not read`로 표시한 행은 그 페이지를 읽지 않았다는 뜻이므로 그 페이지에 관해 아무것도 주장하지 않습니다.

## 2. UIBowl

출시된 앱과 웹사이트의 화면을 모은 한국어 라이브러리이고 주소는 <https://uibowl.io/>입니다.

| 페이지 | 2026-11-15에 계정 없이 본 것 |
|---|---|
| 홈 `https://uibowl.io/` | 열립니다. 메뉴, 월간 활성 사용자 구간 필터, 패턴별 개수가 붙은 UI 패턴 분류가 보입니다. |
| 탐색 `https://uibowl.io/explore` | 열립니다. 패턴, 컴포넌트, 카테고리를 나열합니다. |
| 패턴 필터 `https://uibowl.io/?patterns=<패턴 이름>` | 필터가 적용된 채로 열립니다. |
| 앱 페이지 `https://uibowl.io/name/<앱 이름>` | 앱의 월간 사용자 수, 수집한 달, 패턴별 개수와 함께 열립니다. 로그인 모달이 떴고, 무료 버전은 최신 패턴 세 개만 볼 수 있다고 적혀 있었습니다. |
| 멤버십 `https://uibowl.io/membership` | 열립니다. 무료 요금제는 최신 앱과 웹사이트 세 개 탐색을, 유료 요금제는 모든 앱과 웹사이트 탐색과 사이트 커넥터 무제한 사용을 내세웁니다. |

같은 날짜에 읽은 공개 서술은 다음과 같습니다.

| 주제 | 페이지에 적힌 내용 |
|---|---|
| 소유권 | 서비스 정책 페이지는 수집한 콘텐츠의 저작권이 원래 앱과 웹사이트의 소유자에게 있고, 서비스가 교육과 레퍼런스 목적이며, 로고와 일러스트 같은 브랜드 자산을 재사용하지 않는다고 적습니다. |
| 하단 안내 | 사이트 하단은 콘텐츠의 저작권이 저작권자나 제공처에 있고 무단 사용은 저작권법에 따라 법적 책임을 질 수 있다고 적습니다. |
| 커넥터 | 커넥터 안내는 가입이 필요한 조회 전용 검색 커넥터를 설명하고, 무료 회원은 검색마다 최신 결과 세 개를 본다고 적습니다. |
| `robots.txt` | `/`를 허용하고 `/admin`, `/api-doc`, `/oauth/`, `/payments/`, `/membership/payment`, `/user/`, `/signin`, `/layout/`을 허용하지 않습니다. |
| 이용약관 | `not read`: 일반 조항 페이지에서 제한 조항을 읽어 내지 못했으므로 여기에 어떤 조항도 적지 않습니다. |

## 3. Mobbin

출시된 앱과 사이트의 화면과 흐름을 모은 영어 라이브러리이고 주소는 <https://mobbin.com/>입니다.

| 페이지 | 2026-11-15에 계정 없이 본 것 |
|---|---|
| 탐색 `https://mobbin.com/explore` | `/explore/mobile`로 이동해 열립니다. Mobile, Web, Sites 탭, 분류별 둘러보기(카테고리, 화면, UI 요소, 흐름), 인기 컬렉션, 요소와 흐름 태그가 붙은 인기 카드가 보입니다. |
| 디스커버 `https://mobbin.com/discover` | 돌아갈 주소 매개변수를 붙여 홈으로 되돌립니다. 로그인이 필요합니다. |
| 가격 `https://mobbin.com/pricing` | 열립니다. 무료 요금제는 제한된 앱 접근을, 유료 요금제는 모든 앱과 사이트, 흐름, 사이트 커넥터를 내세웁니다. |
| 용어집 `https://mobbin.com/glossary` | 열립니다. UI 컴포넌트 용어를 정의합니다. |
| 색 `https://mobbin.com/colors` | 열립니다. 브랜드 색을 HEX 값, 색의 의미와 함께 나열합니다. |
| 약관 `https://mobbin.com/terms`, 저작권 `https://mobbin.com/copyright` | 열립니다. |

같은 날짜에 약관(시행 2026-05-16)에서 읽은 조항은 다음과 같습니다.

| 주제 | 약관에 적힌 내용 |
|---|---|
| 복사 | 자료를 수정, 복사하거나 2차적 저작물을 만드는 일은 허용되지 않습니다. |
| 자동화 | 스크레이퍼, 봇, 크롤러 같은 자동 수단을 허가 없이 쓰는 일은 허용되지 않습니다. |
| 재호스팅 | 자료를 다른 사이트나 서버에 미러, 캐시, 재호스팅하는 일은 허용되지 않습니다. |
| AI 사용 | 사용자는 약관이나 서면 동의가 허용하는 범위 밖에서 AI나 머신러닝 도구로 자료의 2차적 저작물을 만들지 않고, 자료로 모델을 학습, 시험, 색인하지 않는다고 보증합니다. |
| 계정 | 계정 공유는 엄격히 금지됩니다. |
| 소유권 | 수록 화면의 권리는 각 지식재산권 보유자에게 남습니다. 다른 곳에서 인용하거나 보여 주는 일은 제한되고 보유자를 표기해야 합니다. |
| 커넥터와 API | 개인용이나 내부 업무용, 또는 구독자 자신의 제품에 통합하는 용도입니다. |
| `robots.txt` | 모든 에이전트에 `/`를 허용합니다. 이름이 지정된 AI 크롤러 하나는 사이트의 Markdown 문서 경로로 제한됩니다. |

## 4. 실행에서 뜻하는 것

- UIBowl: 홈, 탐색, 패턴 페이지만으로 어떤 패턴이 있고 각각 얼마나 흔한지 볼 수 있습니다. 앱 페이지는 로그인 모달에서 멈출 수 있습니다. 그러면 거기서 멈추고 기록합니다.
- Mobbin: 공개 탐색 페이지는 어떤 종류의 화면과 흐름이 있는지와 그 태그를 보여 줍니다. 개별 화면과 흐름은 대부분 계정이 필요합니다. 사용자가 공유한 것을 쓰고, 컴포넌트 용어는 용어집을 씁니다.
- 두 곳 모두: 페이지 몇 개를 읽고, 패턴을 자신의 말로 쓰고, 이미지 대신 링크를 남기고, 어느 사이트의 화면도 이미지 도구에 넣지 않습니다. 위 약관은 추상화 규칙이 엄격한 이유이지 두 사이트가 금지하는 것의 전체 목록이 아닙니다.
- 이 스킬은 어느 사이트의 커넥터도 설정하거나 로그인하지 않습니다. 사용자가 자기 계정으로 이미 쓰고 있는 커넥터가 돌려준 내용은 사용자가 준 자료입니다.

## 5. 이 사실이 낡는 때

접근 제한, 요금제 내용, 약관은 예고 없이 바뀝니다. 모든 행은 90일이 지나면, 또는 페이지가 달라 보이면 그보다 일찍 낡은 것으로 봅니다. 낡은 행은 그 실행의 메모에서 다시 읽고 날짜를 다시 적으며, 이 파일에서 옮겨 적지 않습니다. 이 파일의 갱신은 스킬 유지보수 편집이고 새로 읽은 날짜와 함께 합니다.

`PRIMARY`이고, 행마다 로그인 없는 브라우저에서 날짜를 붙여 한 번 관찰했습니다. 조항은 인용이 아니라 풀어 쓴 것이고 두 사이트 약관의 완전한 요약이 아닙니다. 90일 기준은 `LOCAL`입니다. 이 문서의 어떤 내용도 법률 자문이 아닙니다.
