## Electron Versions and Support

- A new major ships every 8 weeks, following even Chromium majors, after a 4-week alpha and a 4-week beta. The 45 → 46 gap is about 11 weeks.
- The latest three stable majors are supported, each only at its latest minor; the oldest gets security fixes only. Breaking changes normally stay working for at least two majors before removal.

| Line | Stable | End of life |
|---|---|---|
| 43 | 2026-06-30 | 2027-01-05 |
| 44 | 2026-08-24 | 2027-03-02 |
| 45 | 2026-10-21 | 2027-04-27 |
| 46 (planned) | 2027-01-05 | 2027-06-22 |

Long-standing defaults: `nodeIntegration` false since 5, `contextIsolation` true since 12, renderer sandbox on since 20, `remote` removed in 14, `ipcRenderer` sent over `contextBridge` arrives as `{}` since 29, `File.path` removed in 32 (`webUtils.getPathForFile`), `BrowserView` deprecated in 30 (`WebContentsView`).

## Breaking Changes That Shape Architecture

- 44: macOS 13 or later; no 32-bit builds; `clipboard` removed from the renderer (`navigator.clipboard` or a preload wrapper).
- 45: sandboxed preloads lose `events`, `timers`, `url`, `Buffer`, `setImmediate` — `require` loads only `electron`; screen capture is requested as `display-capture`, not `media`; `window.open` children of an unsandboxed opener get their own sandboxed process; ASAR file descriptors work only through `fs`; synchronous `safeStorage` APIs deprecated.
- 46 (unreleased): synchronous `safeStorage` removed; `utilityProcess` `child.kill()` no longer force-kills.

## Process Model and IPC

- Main: Node, all Electron main APIs, owns the UI thread. Renderer: Chromium, no Node, sandboxed. Preload: sandboxed context with `require('electron')` only (`contextBridge`, `ipcRenderer`, `webFrame`, `webUtils`, `nativeImage`, `crashReporter`). Utility process: Node, forked after `ready`, can use the app `session`.
- `child_process.fork` fails when the `RunAsNode` fuse is off; `utilityProcess.fork` is the documented replacement.
- IPC patterns: `invoke`/`handle` (recommended), `send`/`on`, `webContents.send` to the renderer, `MessagePort` between renderers or processes. `sendSync` is discouraged.
- Payloads use structured clone: DOM objects, `process.env`, streams, Electron objects, and class prototypes do not cross; `Error` loses custom properties.
- `contextBridge` copies and freezes values, proxies functions, drops `Symbol`. A listener wrapper must not pass `IpcRendererEvent` to the page.
- ESM (since 28): main via `.mjs` or `"type": "module"` with explicit awaits before `ready`; sandboxed preloads cannot use ESM and must be CommonJS; unsandboxed ESM preloads need `.mjs`.
- Lifecycle: `requestSingleInstanceLock` plus `second-instance`; `window-all-closed` quits except on macOS; `activate` recreates a window on macOS; `open-url` and `open-file` must be registered before `ready`; macOS URL schemes must be declared in `Info.plist` at build time.

## Security Checklist and Fuses

The security tutorial lists 20 items: secure content; no Node for remote content; context isolation; sandbox; permission request handlers (Electron grants everything by default); keep `webSecurity`; CSP; no `allowRunningInsecureContent`; no experimental features; no `enableBlinkFeatures`; `<webview>` without `allowpopups` and with verified options; limit navigation by parsed origin; limit new windows; no untrusted input to `shell.openExternal`; current Electron; validate every IPC sender; avoid `file://` in favour of a custom protocol; review fuses; do not expose Electron APIs to untrusted content.

- `protocol.registerSchemesAsPrivileged` runs once before `ready`; `protocol.handle` serves after `ready` and must reject path escapes. The `register*Protocol`/`intercept*Protocol` family is deprecated.
- Fuses (defaults): `RunAsNode` on, `EnableCookieEncryption` off, `EnableNodeOptionsEnvironmentVariable` on, `EnableNodeCliInspectArguments` on, `EnableEmbeddedAsarIntegrityValidation` off, `OnlyLoadAppFromAsar` off, `LoadBrowserProcessSpecificV8Snapshot` off, `GrantFileProtocolExtraPrivileges` on, `WasmTrapHandlers` on. They are flipped at package time before signing.
- ASAR integrity: macOS from 16, Windows from 30; mismatch terminates the app.
- `safeStorage`: main only; async API from 45; Keychain, DPAPI, Secret Service or KWallet; `basic_text` on Linux is no protection; macOS needs a stable signature.

## Build Tools

- electron-vite: `electron.vite.config.*` with `main`, `preload`, `renderer` blocks; default entries `src/main/index.ts`, `src/preload/index.ts`, `src/renderer/index.html`; renderer `base: './'` in production; dev URL in `ELECTRON_RENDERER_URL`; env prefixes `MAIN_VITE_`, `PRELOAD_VITE_`, `RENDERER_VITE_`, `VITE_`; `.env` files are not loaded into the config by default (`loadEnv`). Version 6 integrates Rolldown and accepts `rollupOptions` and `rolldownOptions`. `build.externalizeDeps` (default on for main and preload) and `build.bytecode` replaced the deprecated plugins in 5. Isolated build (`build.isolatedEntries` with `externalizeDeps: false`) yields a sandbox-compatible single-bundle preload. `electron-vite dev -w` rebuilds and restarts main and reloads on preload changes. Some docs pages still describe version 5.
- Electron Forge 8: Vite plugin stable, targets Vite 8, isolated builds, opt-in `hotRestart`; `publish` renamed `release`; injected `MAIN_WINDOW_VITE_DEV_SERVER_URL` and `MAIN_WINDOW_VITE_NAME`; template `vite` (TypeScript) with three `vite.*.config.mts` files and a `FusesPlugin` flipping six fuses.
- Official electron-vite `react-ts` template: `sandbox: false`, exposes `@electron-toolkit/preload` `electronAPI`, loads production with `loadFile`, ships `tsconfig.node.json` and `tsconfig.web.json`, no router, no Tailwind, no tests.

## Packaging and Updates

- electron-builder 26: `electron-builder.yml`, `asarUnpack`, `electronFuses`, `npmRebuild`; `mac.notarize` with hardened runtime and `allow-jit` entitlement; default docs URLs show v27, stable docs live under `/v26/`; implicit CI publishing deprecated.
- `electron-updater`: app dependency, `publish` config, no `setFeedURL`; macOS needs the `zip` target; Squirrel.Windows unsupported.
- Built-in `autoUpdater`: macOS (Squirrel.Mac, signed app required) and Windows (MSIX or Squirrel.Windows); no Linux. `update.electronjs.org` needs a public GitHub repository and checks every 10 minutes through `update-electron-app`.

## Renderer Stack

- TanStack Router: browser history is the default; hash history fits environments without a server; memory history keeps location in memory. The Vite plugin runs before `@vitejs/plugin-react`; `routesDirectory` and `generatedRouteTree` resolve from the working directory, so electron-vite renderers pass absolute paths. Exclude `routeTree.gen.ts` from lint and format.
- TanStack Query: stale by default, refetch on mount, focus (via `visibilitychange`), and reconnect; `focusManager.setEventListener` and `onlineManager.setEventListener` replace the web listeners; `networkMode: 'always'` suits a `queryFn` that does not need the network.
- Tailwind CSS v4: `@tailwindcss/vite` plus `@import "tailwindcss"`; CSS-first `@theme`, `@source`, `@plugin`, `@custom-variant`; scanning skips `.gitignore`d paths, `node_modules`, binaries, CSS, and lockfiles; baseline Safari 16.4, Chrome 111, Firefox 128; `npx @tailwindcss/upgrade` migrates from v3; `prettier-plugin-tailwindcss` must be last and needs `tailwindStylesheet` for v4.

## Testing

- Electron ships no runner; documented options are WebdriverIO, Selenium, and Playwright (experimental, through CDP, Electron 21+).
- Playwright `_electron.launch` times out when the inspect fuse is off; native dialogs must be stubbed through `evaluate`.
- Vitest environments: `node`, `jsdom`, `happy-dom`, `edge-runtime`; Browser Mode is a project.
