# Security

Codex Quota Optimizer is intentionally local and does not require account credentials.

Please do not add or request:
- API keys or GitHub/OpenAI credentials,
- private account usage-page scraping,
- mechanisms intended to bypass platform usage limits,
- telemetry that transmits repository contents by default.

If you discover a security-sensitive issue, avoid posting secrets, proprietary code, or credentials in a public issue. Share only the minimum reproducible information needed to describe the problem.
