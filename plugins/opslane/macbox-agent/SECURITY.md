# Security

## Reporting a vulnerability

Email abhishek@macbox.build with the details and steps to reproduce. Please don't open a public issue for a security problem.

## What's in scope

- This repository: the macbox skill, the Claude Code, Codex and Cursor plugin manifests, the MCP server config and the `macbox` npm package.
- The macbox service at macbox.build and api.macbox.build, and the macbox CLI it serves.
