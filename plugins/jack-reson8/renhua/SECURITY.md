# Security Policy

## Supported versions

Only the latest commit on `main` is supported.

## What this project does

renhua is a Claude Code skill made only of Markdown instructions and reference text. It contains no executable code, needs no credentials and sends no data anywhere.

## Reporting a vulnerability

Please open a [private security advisory](https://github.com/jack-reson8/renhua/security/advisories/new) instead of a public issue. Expect a first reply within a few days.
