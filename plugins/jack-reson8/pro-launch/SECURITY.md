# Security Policy

## Supported versions

Only the latest commit on `main` is supported.

## What this project does

pro-launch is a Claude Code skill: Markdown instructions and local helper scripts. It needs no credentials and sends no data anywhere unless you run a step that fetches a URL you choose.

## Reporting a vulnerability

Please open a [private security advisory](https://github.com/jack-reson8/pro-launch/security/advisories/new) instead of a public issue. Expect a first reply within a few days.
