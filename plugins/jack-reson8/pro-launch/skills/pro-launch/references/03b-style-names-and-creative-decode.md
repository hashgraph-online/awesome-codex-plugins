读完产出两个文件：`refs/style-names.md`（风格名词库）和每张参考卡里的"创意算子 + 3 个衍生变体"（`refs/style-refs/INDEX.md`）。

## A. 先建风格名词库，再用名词搜作品（禁止先搜"趋势"）
`refs/style-names.md` 一张表，列：词（原语言）/ 一句话是什么 / 社区检索词（中日韩越英）/ 可检索平台 / 证据等级 / 是否撞项目红线。
- 证据等级必须标：【V】本次检索拿到具体页面或平台数据；【W】领域公认术语但没查到目标人群在用；【?】听说过未验证。**【W】【?】不得写成"流行"。**
- 来源顺序：创作者社区的真实标签（Pixiv 百科、itch.io 标签、Shadertoy/Codrops、CapCut 模板名、小红书话题）→ 艺术/技法史词 → 厂商页（最低可信度，单一来源要标"存疑"）。
- 词库建好，再逐词去搜作品：每个词至少找到 2 个具体作品（不是文章）进 INDEX。
- **封闭社区**（小红书、B 站、Pixiv 站内、抖音、Instagram 站内）搜索引擎搜不到。不要反复换关键词硬搜、不要拿二手文章冒充：一次性写进 `docs/manual-tasks.md`——"请在 X 平台搜这 N 个词，各截 5 张图丢进 refs/inbox/"，附好检索词清单，然后继续做其余部分。拿到截图后派看图员（Haiku/Codex）只回文字，反推进卡片。

## B0. 强制门槛：创意卡（D27，2026-10-24 升级；没有卡不许实现）
**每个新模板 / UI 方案 / 动效 / 交互 / 玩法，写代码前先在 `docs/creative-cards.md` 写一张卡**；`phase_gate.py <项目> cards` 不过就不实现（`ui` 阶段也会检查）。
为什么：Jack 第 4 次强调"不是抄参考图像，而是解析意图、玩法、创意算子和风格，推断作者意图，据此衍生 100/1000 种玩法"；抄图只得一个成品，卡才是"成百上千模板"的来源。
卡片模板（字段名不要改，脚本按它检查）：
```
### <玩法名>
- 来源: <参考卡编号 / Jack 喂图编号 / 发布片关键帧>
- 意图: <作者想让人感到什么，一句话，不写形容词；标【推演】>
- 算子: <动词 + 对象 + 约束>（换掉对象仍成立才算）
- 参数轴: 轴1 / 轴2 / 轴3 …（≥3，用 / 分隔；标出哪 1–2 个上手势）
- 衍生: 衍生1；衍生2；衍生3（≥3，用 ；分隔，彼此至少 2 个轴不同）
- 融合: × <另一个创意或风格>：谁管形状、谁管表现，冲突怎么让
- 变异: <同一风格内局部变异一条，可选>
```
三种衍生都要想到：**创意 A × 创意 B**（两个算子叠，主事件只留一个）、**风格 A × 风格 B**（同一算子换表现）、**同一风格内局部变异**（只改一个轴的档位或局部区域）。
Tutti 实例（已装机的"线织回声"）：
```
### 线织回声
- 来源: 发布片 P4 关键帧
- 意图: 人的存在感向外扩散，像回声留在纸上【推演】
- 算子: 沿人像距离场等距复刻轮廓，不碰脸手
- 参数轴: 线距 / 线宽 / 衰减 / 颜色 / 动效流向（左右滑=颜色，上下滑=线距）
- 衍生: 纸上回声（等距线变层叠纸片）；字沿等值线排成一句话；等值线变等高地形配高程色
- 融合: × 规格书字符场：算子管形状（等值线位置），字符场管表现（线由等宽字符组成）；字符不得进脸部保护区
```
反例（会被脚本打回）：`算子: 赛博风`、`衍生: 换个颜色`、只有 1–2 个参数轴。

## B. 创意解码（不抄图像，抄不了也不该抄）
对每张参考卡按顺序填，缺一项不算完成：
1. **设计意图**：作者想让看的人产生什么感受或做什么（一句话，不写形容词）。
2. **创意算子**：`动词 + 对象 + 约束`。例：把〔文字〕〔下落并堆积在人体轮廓外〕、不遮脸；把〔半个身体〕〔替换为字符网格〕。能换掉对象还成立才算算子；写成"赛博风"是失败。
3. **参数轴**：算子里能连续调的量（密度、尺寸、方向、随机度、颜色数、速度），至少 3 个；其中 1–2 个能映射到手势（上下滑、捏合）。
4. **融合规则**：这个算子能和哪个别的算子/风格叠加，叠加时谁管形状、谁管颜色（A 的算子 × B 的风格）。
5. **7 个衍生问题**（逐个回答，答不出就说明没解码完）：①换对象会怎样 ②反向（出现变消失）会怎样 ③换尺度（极大/极小）④换触发（时间/手势/内容）⑤叠两层 ⑥去掉约束的失败样子 ⑦换媒介（静图→实况→动效→UI→声音）。
6. **3 个衍生变体**：从第 5 步选 3 个，各一句话可实现的描述，3 个之间至少 2 个轴不同。
一个参考能衍生几十个变体的证明：参数轴 3 个 × 档位 3 = 27，写出轴和档位即可，不必全画。
同一套用于动效、UI、交互、模板、玩法，不限于静态图。
