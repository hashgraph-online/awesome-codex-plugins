# Security Policy

## Supported versions

Only the latest commit on `main` is supported.

## What this project does

skill-skill is a set of Markdown instructions plus two Python scripts (`skill_audit.py`, `skill_report.py`) that read `SKILL.md` files locally. `skill_report.py` runs `git clone` on public repositories you name. Neither script sends data anywhere, needs credentials, or runs code from the repositories it audits.

## Reporting a vulnerability

Please open a [private security advisory](https://github.com/jack-reson8/skill-skill/security/advisories/new) instead of a public issue. Expect a first reply within a few days.
