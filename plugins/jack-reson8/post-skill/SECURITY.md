# Security Policy

## Supported versions

Only the latest commit on `main` is supported.

## What this project does

post is a Claude Code skill: Markdown instructions, HTML templates and small local scripts that render images on your machine with a headless browser. It needs no credentials and sends no data anywhere.

## Reporting a vulnerability

Please open a [private security advisory](https://github.com/jack-reson8/post-skill/security/advisories/new) instead of a public issue. Expect a first reply within a few days.
