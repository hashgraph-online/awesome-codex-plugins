# Security Policy

## Supported versions

Only the latest commit on `main` is supported.

## What this project does

pro-motion is a Claude Code skill: Markdown instructions, a canvas/HTML film template, and local scripts (Node/Python/ffmpeg) that render video files on your machine. It needs no credentials and sends no data anywhere; reference downloads only fetch URLs you choose.

## Reporting a vulnerability

Please open a [private security advisory](https://github.com/jack-reson8/pro-motion/security/advisories/new) instead of a public issue. Expect a first reply within a few days.
