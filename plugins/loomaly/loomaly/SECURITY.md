# Security policy

This plugin contains skills (Markdown instructions) and a reference to Loomaly's remote MCP server at `https://loomaly.com/mcp`. It runs no local code.

## Reporting a vulnerability

Email **support@loomaly.com** with "Security" in the subject. Include what you found, how to reproduce it, and which version of the plugin or which MCP tool is affected. Please don't open a public issue for a security problem.

We reply within 3 business days and let you know when a fix ships.

## Supported versions

Only the latest version of the plugin and the live MCP server are supported.
