# Security policy

This repository holds the plugin manifests, skills and commands that connect an agent to the hosted Mnemoverse MCP server at `https://mcp.mnemoverse.com/mcp`.

## Reporting a vulnerability

Please do not open a public issue. Report a vulnerability in this plugin or in the hosted service privately, in either of these ways:

- email security@mnemoverse.com
- open a private security advisory at https://github.com/mnemoverse/mcp-memory-server/security/advisories/new

The same contacts are published in https://mnemoverse.com/.well-known/security.txt, and the security policy is at https://mnemoverse.com/docs/api/security.
