# Security policy

## Report a security issue

If you find a security issue in these skills, in the ASOScan API, or in the ASOScan plugin or connector, email khalil@asoscan.com. Do not open a public GitHub issue for it.

Include:

- what you found and where (file, endpoint or skill name)
- the steps to reproduce it
- what an attacker can do with it
- your name or handle, if you want credit

Never send a real API key in the report. If your own key was exposed, revoke it in ASOScan under Settings, API access, and create a new one.

## What happens next

ASOScan is run by one developer. You get a reply within 5 working days. We tell you what we will do and keep you updated until the issue is fixed.

## Scope

This repository holds Markdown instructions and one shell script (`scripts/asoscan-check.sh`). It has no server code. Issues in the ASOScan service itself are also welcome at the same address.
