# Security policy

To report a vulnerability, use GitHub private vulnerability reporting on this repository. If it is not available, open an issue that asks for a private contact channel, and do not put vulnerability details in that issue.

The skills in this repository are instructions and small scripts that agents run. The only bundled script, `skills/image-optimization/scripts/audit-images.mjs`, has no dependencies and only reads the HTML or URL you give it. Review skill content before you install it, as you would any third-party code.
