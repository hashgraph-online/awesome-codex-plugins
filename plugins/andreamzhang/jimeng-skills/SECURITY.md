# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately using GitHub's Private Vulnerability Reporting for this repository:

https://github.com/andreamzhang/jimeng-skills/security/advisories/new

Please include:

- A description of the issue and how it can be triggered
- Steps to reproduce (a minimal script or prompt is ideal)
- The affected version, commit, or file path

We will acknowledge reports within a few business days and coordinate a fix before any public disclosure. Do not open public issues with exploit details.

## Scope

This plugin ships local skills, agent definitions, and workflow scripts used in the user's workspace. Reports about the plugin manifest, skills, or bundled scripts are in scope. Issues in third-party services invoked by the user are out of scope.
