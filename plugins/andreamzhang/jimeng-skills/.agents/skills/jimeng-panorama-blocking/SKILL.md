# 全景站位分镜技能

> **工作区根**：Codex 项目根（AGENTS.md 所在目录；下文所有 `scripts/…`、`tools/…`、`config/…` 相对该根，可用环境变量 `JIMENG_ROOT` 显式指定）。

[技能说明]
    基于整集剧本原文和本集资产清单，输出整集的全景人物站位分镜。
    本技能只表现人物的空间调度关系（谁、在什么位置、从哪移动到哪、与谁的距离/方位变化），
    是分镜编写的站位调度前置依据。

    核心理念：
    - 整集调度关系用【一个母镜头】凝缩展示，母镜头总时长 ≤ 15 秒，禁止拆分多个母镜头
    - 子镜头（镜头）= 调度瞬间的时间切片，带时间轴（0-3、3-6……）
    - 只写调度，不写台词、不写心理、不写面部细节

[输入]
    - 剧本：scripts/[剧本名]/script/epXX.txt 或 .md
    - 本集资产清单：scripts/[剧本名]/outputs/epXX/epXX-asset-list.md（人物/场景/道具的 @引用名唯一来源）
    - 全局风格配置：scripts/[剧本名]/config/global-style.md（可选，供参考）

[输出]
    - 全景站位分镜：scripts/[剧本名]/outputs/epXX/00-panorama-blocking.md
      （在 01-director-analysis.md 之前或与分镜编写同级，作为阶段六 分镜编写的站位输入）

---

[资产清单产出规范]（阶段四 第一步，产出 epXX-asset-list.md；责任归位：storyboard-artist）
    在生成全景站位分镜前，先产出本集资产清单，作为全景与分镜的 @引用名唯一权威。
    - 从 assets/character-prompts.md、prop-prompts.md、scene-prompts.md 提取本集实际出现的人物/场景/道具
    - 每条记录：@引用名（与资产文件命名一致，唯一权威）+ 中文名 + 本集出场剧情点/母镜头
    - 仅列本集实际出现的素材；未在本集出现的不得列入
    - @引用名 是下游全景站位、即梦分镜、素材清单表的唯一权威来源，一律以此为准，不得自造
    - 群演、一次性配角不进资产清单，在提示词中用纯文字描述，不带 @ 前缀
    - 质量控制：逐集遍历剧本核对，确保无遗漏、无自造名、无本集未出现素材

---

[执行流程]

    第一步：读取输入
        - 读取整集剧本原文
        - 读取本集资产清单（epXX-asset-list.md），提取人物/场景/道具的 @引用名
        - （可选）读取全局风格配置

    第二步：提炼整集调度主线
        从剧本推导整集的人物调度链，例如：
        陈峰独坐吃鸡 → 刘萍进门 → 隔桌对峙 → 刘萍转身进里屋 → 取出红布包 → 递钱 → 陈峰接钱握手
        调度链必须严格来自剧本，不得编造剧本中不存在的人物、空间、动作。

    第三步：划分镜头（时间轴切片）
        - 将调度主线切分为若干镜头（子镜头），每个镜头 = 一个调度瞬间/站位状态
        - 镜头时长按调度复杂度分配：
          | 镜头内容 | 时长 |
          |----------|------|
          | 单一站位状态 | 2-3秒 |
          | 动作链（转身→走向→取出→递出→接住） | 3-5秒 |
          | 环境交代 | 2-3秒 |
        - 所有镜头时长之和 = 母镜头总时长（≤15秒）
        - 镜头可以跨场景：场景切换时直接更换"所属场景"，不额外解释转场

    第四步：输出唯一母镜头
        按以下格式输出（严格逐字遵守）：

        ```
        全景人物站位分镜（X秒）

        基础信息
        场景：@场景引用名（编号）、@场景引用名（编号）
        出场人物：@角色A、@角色B
        总时长：X秒

        镜头1（0-3秒）
        所属场景：@场景引用名
        景别：全景
        人物站位：@角色A在画面X位置，@角色B在画面X位置
        画面描述：全景镜头展示……（谁在什么位置→从哪移动到哪→与谁的距离/方位变化→动作幅度）
        时长：⏱3.0s

        镜头2（3-6秒）
        [同上格式，直到演完整集调度]
        ```

[格式细则]
    - 标题行：`全景人物站位分镜（X秒）`，X = 母镜头总时长（≤15秒）
    - 基础信息：
      - `场景`：本母镜头涉及的所有场景，用 @引用名（资产清单名），多个用顿号分隔，括号内标注场景编号（按剧本出场顺序，如（1）、（2））
      - `出场人物`：本母镜头出场的所有人物，用 @引用名，顿号分隔
      - `总时长`：母镜头总秒数（≤15秒）
    - 镜头行：`镜头N（起-止秒）`，N 从1开始，起止秒为时间轴位置（0-3、3-6、6-9……），相邻镜头无缝衔接，最后止点 = 总时长
    - 所属场景：本镜头所在场景的 @引用名（与资产清单一字不差）
    - 景别：一律写 `全景`
    - 人物站位：用 @引用名 + 画面方位描述（画面中央/画面左侧/画面右侧/门口处/床边等），标注所有在场人物，位置随调度变化而更新
    - 画面描述：只写人物调度，不写心理、不写面部细节、不写台词、不写过渡衔接词（承接/接着/然后等）
    - 时长：`⏱Xs`，与本镜头时间轴跨度一致

[质量检查]
    - 全文件只有一个母镜头，禁止出现"母镜头2""母镜头3"
    - 母镜头总时长 ≤ 15秒
    - 所有镜头时长之和 = 母镜头总时长
    - 每个镜头都标注了所有在场人物的站位
    - 所有 @引用名 与资产清单一致，无自造名
    - 画面描述零台词、零心理、零过渡衔接词
    - 动作链完整（递出→接住→握手在一个镜头内完成），不得拆碎
    - 日常陈设（桌、椅、床、电风扇等）不在资产清单中的，用纯文字描述，不带 @ 前缀

[禁忌规则]
    - 禁止拆分多个母镜头（整集只能一个母镜头，≤15秒）
    - 禁止在画面描述中出现台词内容
    - 禁止编造资产清单中不存在的人物/场景/道具 @引用名
    - 禁止写特写、近景、中景（本技能只用全景）
    - 禁止写心理活动、面部细节
    - 禁止写过渡衔接词（承接、接着、然后等）
