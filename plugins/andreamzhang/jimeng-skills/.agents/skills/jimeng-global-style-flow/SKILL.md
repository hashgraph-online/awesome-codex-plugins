# 全局风格与制片批注流程（阶段零，Codex 版）

> **工作区根**：Codex 项目根（AGENTS.md 所在目录；下文所有 `scripts/…`、`tools/…`、`config/…` 相对该根，可用环境变量 `JIMENG_ROOT` 显式指定）。
> config/global-style.md 是**剧级唯一档案**：上半部分（风格类型/通用设定/成片文案）是分镜视觉基准，下半部分（制片批注）是核心卖点/主线/梗概/人物/制作要求。骨架见 `templates/global-style-template.md`，各小节标题跨剧保持一致，便于子代理与外部模型提示词按节引用。

[铁律：与用户共同敲定]
config/global-style.md 是分镜的基础设定，必须与用户共同修改、等用户敲定后才算定稿。
- 用户只给出题材方向（如「海外剧」）不算定稿令。
- 正确顺序：① 读旧剧的 global-style.md 找可继承的结构（固定头+光线从句+角色强化句）② 给用户出成片文案预览（每个可改字段给 2-4 个候选，横竖屏/人物面孔/画内文字处理等问清）③ 用户拍板后写入④用户逐字微调再定稿。
- 严禁用户未确认就落盘 config/global-style.md——这是给用户的一项"先给我选"的工作流，不是先append后补。已违反过的情景：直接按海外题材写入欧美黑帮暗黑写实，被用户要求改成「欧美」并去选项编号。

[写入内容（四段式）]
1. 成片文案固定头（每个母镜头一字不改地复用）：`画面风格为原生无字幕短视频,无信息条,无字幕条。全局风格：XXX——…;`
2. 光线从句（按日/夜×内/外选一，每集替换）：从旧剧.config 目录看，通常是四段固定模板（日戏内景/日戏外景/夜戏内景/夜戏外景）
3. 角色/文学强化子句（仅在特殊剧需求时如海外剧）：面孔/服化道/画内文字规则
4. 制片批注（剧级信息，由主 agent 通读剧本后生成并维护，不派子代理）：
   - 固定小节：核心卖点 / 故事主线 / 故事梗概 / 故事人物 / 制作特别要求（节奏把控 + 主角人设锚点）
   - 内容由主 agent 通读全剧剧本后撰写（不得仅凭用户提供摘要照抄）；成稿先给用户预览，用户确认后才落盘
   - 与成片文案同属「用户敲定后才写入 config」的范围：批注有改动也要先给用户预览再落盘

[常见 wished 字段——不要从旧剧照抄]
- 画面比例：短剧默认 9:16 竖屏（不要写成16:9；新剧必须先问用户）
- 「选项编号」不进成片文案:：阶段零的 A-E 选项值如「E.自定义」只是选题标记，写入config顶部文档区可以，但成片文案段落里禁止出现E.
- 字眼具体化：题材前缀用可读词（如「欧美黑帮暗黑写实」而非「E.海外…」）；用户明确纠正过，留着字母编号会被模型当成画面元素

[与资产报告/服化道技能的衔接]
- HTML 资产分析报告走 `jimeng-asset-report` 技能（输出到 assets/ 四份 HTML）
- 人物/道具/场景提示词走 `jimeng-art-design`（assets/*-prompts.md 是分镜引用名唯一来源）
- global-style.md 定稿后要与这些资产的视觉基准一致；冲突时以 global-style.md 为准

[已定稿参照（可直接复制改编）]
`scripts/<任意已入库海外剧>/config/global-style.md`（示例：欧美黑帮暗黑写实+9:16竖屏+画内文字全英文（立牌「LA FOSSA」）+西方面孔强化子句——海外剧类的成片文案模板。年代剧参照 `scripts/<任意年代剧>/config/global-style.md`（暖黄胶片+夜戏局部光源规范）。

[与用户共同敲定的工作流纠错记录]
本次场景：用户说「这是海外剧，全局提示词要写上类似提示词」，我直接落盘了欧美黑帮暗黑写实全稿——应当先给用户候选预览。用户后续两次微调（E.海外→欧美、16:9→9:16）都应发生在成稿预览阶段而非写入后再改。下次同类任务必须先预览再落盘，即使一度判断用户「想要现成的」。
