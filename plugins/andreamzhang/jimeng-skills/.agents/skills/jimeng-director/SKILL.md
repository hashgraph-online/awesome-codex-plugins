## 输入

## 一、拆解剧情点（核心：聚合，勿拆散）

**一个剧情点 = 一段完整叙事 = 一次即梦生成任务**，段落内可含多组镜头（蒙太奇/连续场景/单镜头）。**剧情点时长 4-15s，最佳 8-12s**。

**最小叙事单元 = 一个完整动作链 = 1 个剧情点**（不是每个动作一个镜头）：
- "接近→碰撞→反应" = 1 个剧情点（不拆3个）
- "拽住衣领→炫耀身份→对方反应" = 1 个剧情点
- "夺走手机→查看屏幕→惊讶" = 1 个剧情点

**时长驱动的合并硬规则**：相邻剧情点合计 ≤15s 且满足以下任一条件 → **必须合并**：
- a. 服务于同一叙事目的（"接近→碰撞→拉扯"都是相遇场景的一部分）
- b. 发生在同一时空（同场景同时间段）
- c. 情绪基调无明显转折（都是"紧张对峙"）
相邻剧情点合计 >15s 保持拆分；有明显情绪转折（对峙→妥协）即使可合也分开。

**反向检查**：两个相邻段落服务于同一叙事目的→合并；一段内含两个独立叙事目的→拆分；合并后≤15s且满足条件→必须合并。**合并后剧情点 8-12s 为佳，4-7s 偏短需确认是否有可合并的相邻段落。**

**时长分布（硬性）**：
- 避免连续多个 ≤5s 的剧情点（说明拆太碎）
- 理想：70% 剧情点在 8-15s，30% 在 4-7s
- **检测到连续 3 个剧情点 ≤6s → 必须回溯检查合并**

**拆分依据（叙事自然断点）**：情绪转折 / 时空跳转 / 叙事功能转换（铺垫→冲突、回忆→现实）。**单条台词超约 75 字才必须按情感轮次拆。**

**场景拆分合并铁律**：同一场景编号出现两次=两个不同场景，分别判定内外光线，不得合并；不同编号场景永不合并。

**剧情点边界定稿（责任归位导演）**：P01…Pn 编号与顺序一经定稿即下游唯一权威；分镜师 1:1 映射母镜头，不重拆/不合并。后续实测某点>15s 由制片人阶段七 按时长拆分，导演不重复判断。

## 二、确定时长（每剧情点）
参照剧本台词本参考时长 + 动作/反应余量；台词时长必须能让台词完整朗读（有效语速≤11字/秒）。
母镜头总时长 = 该剧情点预算 4-15s；**各剧情点预算之和应 ≥ 台词本全片合计**（制片人用 check_budget.py 校验——仅校验台词塞得下，非锁定总时长）。

时长参考：4-5s 极简单动作（仅限无台词过渡）/ 6-8s 单镜头连贯动作+情绪 / 9-11s 多镜头对话+反应+动作 / 13-15s 多镜头完整叙事（蒙太奇）。

## 三、写讲戏本（v2 精简模板）
每 P = 元数据(人物/场景/镜头组/时长/情绪/目的) + 关键动作 + 台词清单 + 分镜建议 + 关键问题点；末尾人物清单、场景清单（含素材状态 复用/新增/变体）、关键问题点汇总。
- **台词清单**：逐字引用剧本原句（含语气词标点），标注角色/情绪/语速/语调；OS 旁白不论长短必须逐条列出；无台词标"本段无台词"
- **时长并非台词 = 预算**：导演的台词参考时长是权威；反应/动作/总时长为参考，交由分镜师在 4-15s 内自控（分镜师需给反应≥1s）
- @引用名必须用资产库标准名（剧本"土砖房"→资产库 @石砖房），避免阶段三误判

## 四、输出格式模板
见 `${SKILL_DIR}/templates/director-analysis-template.md`（v2 精简：集头信息 + 每 P 5 个决策级字段 + 关键问题点汇总 + 移除字段说明）。

返回一行摘要：剧情点数=N（含分布：X 个 8-15s / Y 个 4-7s）| 人物=N | 场景=N | 关键问题=...
