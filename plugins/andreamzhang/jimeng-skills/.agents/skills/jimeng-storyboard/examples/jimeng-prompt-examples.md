# 即梦分镜提示词参考示例

> 以下示例展示了即梦平台分镜提示词的标准格式和写法。
> 采用母镜头 + 子镜头结构，子镜头在每个母镜头内独立编号。
> 每个母镜头包含分镜过渡（定调 + 连接）和全局风格设定。
> 每个子镜头包含7个字段：【景别】【运镜】【机位】【画面】【微表情】【台词】【音效】

## 写法要点总结

1. 分镜过渡必须定调 + 连接前后视频
2. 母镜头 4-15秒，子镜头时长之和 = 母镜头总时长
3. 子镜头独立编号：每个母镜头内从1开始
4. 全局风格设定在每个母镜头的分镜过渡之后声明
5. 母镜头资产声明行：全局风格后、子镜头1前声明，格式 `@人物 | @场景 | @道具`
6. 7字段顺序：景别→运镜→机位→画面→微表情→台词→音效
7. 运镜必须有变化：同一母镜头内不能全部固定机位（固定≤30%）
8. 景别必须有变化：不能全部中景/近景，要有梯度对比
9. 机位角度必须有变化：平视≤50%，适当使用仰拍/俯拍/荷兰角
10. 运镜提示词格式：中文描述 + 英文术语括注，如「缓慢推近（push in）」
11. 焦段与景别匹配：135mm配大特写，85mm配近景/特写，50mm配中景，35mm配全景，24mm配远景
12. 微表情：至少两个面部细节 + 情绪标签 + 百分比
13. 台词四要素：情绪 + 语速 + 语调 + 强度%
14. 情绪一致性：微表情百分比 = 台词情绪强度
15. 音效三类：环境音（持续）+ 拟音（动作）+ 人物发声（非台词）
16. 最终输出纯文本版，无 Markdown 符号

## 【画面】字段正反对照（关键！核心原则：画面≠叙事）

画面字段只写"摄像机拍到的一帧视觉内容"，不写"这段戏的剧情"。

### 四条铁律

| 铁律 | 说明 |
|------|------|
| 画面≠叙事 | 不写心理判断、不写情节总结、不写角色"为什么" |
| 画面≠声音 | 画外音在【台词】，画面不重复描述声音事件 |
| 画面≠时间线 | 不写"前X秒/后X秒"，不写"接着"、"随后"、"然后" |
| 画面≤2句 | 超过2句说明在写叙事，压缩到2句内 |

### 禁写词

心理词：满足感、沉浸、感到、觉得、内心
因果词：所以、于是、但他、但、却、因为
时间词：前X秒、后X秒、接着、随后、然后
画外词：窗外传来骂声、画外响起、突然炸响
同义反复词：同一画面内"腮帮子"不超过1次、"眼睛"不超过1次

### 正反对照

✗ 叙事式（错误）：
`@陈峰家屋内-内 @陈峰 坐在老木桌前，他正大口吃肉——右手拿筷子不停往盘里伸，夹起一块又一块油亮鸡腿肉往嘴里塞，腮帮子始终鼓得高高的用力咀嚼，眼睛一直眯成两道缝，脸上满是极度原始的口腹满足感，完全沉浸在吃鸡的快乐中；窗外突然传来骂声——但他没停`

✓ 视觉式（正确）：
`@陈峰家屋内-内 @陈峰 位于画面中心，坐在老木桌前，右手拿筷子夹起油亮鸡腿肉往嘴里送，腮帮子鼓着咀嚼，眼睛眯成缝，嘴角沾油光，桌面白瓷盘里@炖鸡汤 剩残骨`

核心区别：✓ 只写"能看到什么"，不写"这意味什么"。
