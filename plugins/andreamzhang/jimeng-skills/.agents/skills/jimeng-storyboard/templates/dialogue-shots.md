# 对话型子镜头模板 v1

> 2026-08-15 起启用。优化 storyboard-artist 子代理在对话场景的子镜头生成效率。
> 使用方式: 子代理先识别对话场景的子镜头类型,选对应模板,只填变量(角色/台词/情绪/景别等)。
> 优先匹配模板,场景特殊时可自创。

---

## T1: 对话-说者中近景(常用)

**触发条件**:
- 角色 A 说话
- 需要展示 A 的表情+动作+台词
- 典型场景: 日常对话、感慨、询问、欢迎、回应
- **ep53 实例**: 1.2(石翠感慨)、2.2(赵峰招呼)、5.3(赵峰讲商机)

**模板**:

```
【景别】中近景,三分法构图
【运镜】缓慢推近(push in),从半身推到面部
【机位】平视,焦段50mm,摄影机位于@X 左前侧
【画面】@场景-内 @X 站着/坐着 看着@Y 说话,场景环境与光影
【微表情】@X 眼嘴神态描写(情绪标签:XX%)
【台词】@X 说：「[台词逐字]」(情绪描述,语速XX,语调XX,情绪强度:XX%)
【音效】环境音: [场景音], 拟音: [动作音], 人物发声: @X 说话的语气
```

**自定义 slots**:
- `@X` 角色名(必填)
- 角色姿态(站着/坐着/蹲着,默认站着)
- 台词(逐字,必填)
- 情绪(从 moods.json 选:喜悦/紧张/惊讶/愤怒/悲伤/温柔)
- 运镜速度(快/中/慢,默认中)
- 摄影机位置(左前侧/右前侧,默认左前侧)

**不适用**:
- 极重要关键台词(用 T2 更聚焦)
- 远距离对话(用中景/全景)

---

## T2: 对话-说者特写过肩(关键台词)

**触发条件**:
- 关键对话(报价/告白/决定/重要信息)
- 需要比 T1 更聚焦,突出说者表情与台词
- 典型场景: 重要决定、关键报价、情势转折
- **ep53 实例**: 5.4 附近(赵峰压价关键句)

**模板**:

```
【景别】特写,过肩构图
【运镜】固定机位(fixed shot)
【机位】平视,焦段85mm,摄影机位于@Y 肩后过肩看@X
【画面】@场景-内 @Y 肩头前景虚化,@X 正面特写说话
【微表情】@X 眼神+嘴部精细描述(情绪强度:XX%)
【台词】@X 说：「[台词逐字]」(情绪,语速XX,语调XX,情绪强度:XX%)
【音效】环境音: [场景低音量], 拟音: [轻微动作音], 人物发声: @X 语气加重
```

**自定义 slots**:
- `@X` 说者(必填)
- `@Y` 听者(前景,必填)
- 台词(必填)
- 情绪(必填)
- 摄影机位置(@Y 肩后)

**不适用**:
- 普通对话(T1 即可)
- 需要展示环境(用过肩构图不展示环境)

---

## T3: 对话-反应近景(无台词)

**触发条件**:
- 角色 A 听完后有反应
- 无台词(纯微表情/动作)
- 典型场景: 惊讶反应、思考、压抑、感动
- **ep53 实例**: 3.4(李大哥紧张)、4.4(赵峰目送)、5.4(蒋倩惊讶)

**模板**:

```
【景别】近景,中心构图
【运镜】固定机位(fixed shot)
【机位】平视,焦段85mm,摄影机位于@X 正面
【画面】@场景-内 @X 站着/坐着 看着@Y 方向,微表情变化
【微表情】@X 眼/嘴/眉 反应(情绪标签:XX%)
【台词】无
【音效】环境音: [场景持续音], 拟音: [场景音], 人物发声: 无
```

**自定义 slots**:
- `@X` 反应者(必填)
- 表情类型(惊讶/思考/压抑/感动/愤怒)
- 表情强度(50-90%)
- 摄影机位置(默认正面)

**不适用**:
- 角色在说话(用 T1)
- 需要展示反应的动作(用 T4 越肩看说者)

---

## T4: 对话-听者特写过肩看说者

**触发条件**:
- 镜头从听者肩后看说者
- 重点是听者视角接收信息
- 典型场景: 信息接收、反应触发、关键时刻
- **ep53 实例**: 1.3(赵峰回应)

**模板**:

```
【景别】特写,过肩构图
【运镜】固定机位(fixed shot)
【机位】平视,焦段85mm,摄影机位于@X 肩后过肩看@Y
【画面】@场景-内 @X 肩头前景(虚化),@Y 面部清晰在说话
【微表情】@X 背影/侧脸(前景),@Y 说话神态(主体)
【台词】@Y 说：「[台词逐字]」(情绪,语速XX,语调XX,情绪强度:XX%)
【音效】环境音: [低音量], 拟音: [轻微], 人物发声: @Y 语气
```

**自定义 slots**:
- `@X` 听者(前景,必填)
- `@Y` 说者(主体,必填)
- 台词(必填)
- 情绪(必填)

**不适用**:
- 需要展示听者反应(T3)
- 普通对话(T1 即可)

---

## T5: 对话-群演反应(3+人,各自独立镜头)

**触发条件**:
- 场景有 3+ 群演
- 每个群演独立评价/反应
- 典型场景: 围观评价、群体反应、多人独立感叹
- **ep53 实例**: 无(本集无群演场景)

**模板(每群演独立子镜头)**:

```
【景别】特写,过肩构图
【运镜】固定机位(fixed shot)
【机位】平视,焦段85mm,摄影机位于@群演 肩后过肩看@主角
【画面】@场景-内 @群演 面部特写,视线看向@主角方向,@主角 在景深外(虚化)
【微表情】@群演 表情变化(佩服/惊讶/认同/羡慕/崇拜)
【台词】@群演 说：「[评价台词]」/无台词(纯反应)
【音效】环境音: [场景音], 拟音: [轻微], 人物发声: @群演 (如有)
```

**自定义 slots**:
- `@群演` 角色名(必填,每群演独立子镜头)
- 群演数量(3+)
- 表情类型(佩服/惊讶/认同/羡慕/崇拜)
- 评价台词(每群演独立一句)
- `@主角` 主体(景深外)

**不适用**:
- 群演之间互相对话(那是正反打,不是群演反应)
- 1-2 个群演(那是 T1/T3)

---

## 使用流程

1. 子代理识别子镜头类型(对话/动作/反应/...)
2. 对话型 → 选最匹配模板(T1/T2/T3/T4/T5)
3. 填变量(角色/台词/情绪/景别/姿态)
4. 如有特殊需求,微调模板字段
5. 如场景特殊无法匹配,自创(记录原因供后续模板扩展参考)

## 模板质量保证

- 严格遵循 AGENTS.md 硬约束:
  - 【画面】不超 150 字符,不超 2 句
  - 出现人物必含身体姿态(站着/坐着/蹲着)
  - 7 字段完整
- 引用 `knowledge/prompt-kb/shot_sizes.json` 的景别定义
- 引用 `knowledge/prompt-kb/moods.json` 的情绪类型
- 引用 `knowledge/prompt-kb/camera_angles.json` 的机位定义
- 引用 `knowledge/short-drama-ultra-reusable-kb/atoms/lighting_atoms.json` 的灯光描述
