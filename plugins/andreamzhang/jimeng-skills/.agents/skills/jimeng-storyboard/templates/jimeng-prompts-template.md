## 输出规范

- 双文件输出：含格式版（.md）+ 纯文本最终版（.txt）
- 纯文本版不含任何 Markdown 符号（无 #、*、|、--- 等）
- 母镜头总时长 4-15秒
- 子镜头每个母镜头内独立从1开始编号
- 全局风格设定在每个母镜头的分镜过渡之后、子镜头之前声明
- 每个子镜头严格包含7个字段：【景别】【运镜】【机位】【画面】【微表情】【台词】【音效】
- 字段顺序按权重排列（景别→运镜→机位→画面→微表情→台词→音效）
- 无台词子镜头的【台词】字段写"无"
- @引用使用语义化名称（@角色名、@场景名、@道具名），不用编号
- 台词用「」标注
- 情绪百分比在【微表情】和【台词】中保持一致
- 子镜头时长之和 = 母镜头总时长
- 同一母镜头内运镜、景别、机位角度必须有变化
- 运镜提示词格式：中文描述 + 英文术语括注

## 【画面】字段正反对照（关键！）

画面字段是"摄像机拍到的一帧视觉内容"，不是"这段戏讲了什么"。

### 画面字段铁律

| 铁律 | 说明 |
|------|------|
| 画面≠叙事 | 不写心理判断、不写情节总结、不写角色"为什么"做 |
| 画面≠声音 | 画外音已在【台词】字段，画面不重复描述 |
| 画面≠时间线 | 不写"前X秒/后X秒"，画面描述的是镜头呈现的视觉内容 |
| 画面≤2句 | 超过2句说明在写叙事而非视觉描述 |
| 画面必有姿态 | 出现人物的画面必须写清其身体状态：站着/坐着/蹲着/躺着/跪着/弯腰/倚靠等，禁止只写动作不写姿态（如"@林年 抹了把脸"缺姿态 → 应写"@林年 站在原地抹了把脸"） |

### 姿态描写要求

画面中每出现一个@人物引用，其身体状态必须可被识别：

| 姿态 | 写法示例 |
|------|----------|
| 站立 | 站在原地 / 站着 / 立在檐下 / 直起身 / 站定 |
| 坐 | 坐在板凳上 / 坐在石阶上 / 盘腿坐 |
| 蹲 | 蹲在石阶上 / 半蹲 |
| 躺/趴/跪 | 躺在炕上 / 趴在桌上 / 跪在地上 |
| 倚靠 | 靠墙站着 / 倚着门框 |
| 弯腰/俯身 | 弯腰刨沙 / 俯身捡拾 / 前倾 |
| 动态（隐含姿态） | 走、跑、奔、冲、踱、迈、爬、转身、倒退、跳、跨 |

自检：每个含人物的【画面】字段，至少命中一个姿态词，否则视为违规。

### 禁写词清单

禁止在【画面】中使用以下词汇：
心理词：满足感、沉浸、感到、觉得、内心、情绪
因果词：所以、于是、但他、但、却、因为
时间词：前X秒、后X秒、接着、随后、然后
画外词：窗外传来骂声、画外响起、突然炸响（画外音已在【台词】）

### 正反对照

✗ 叙事式（错误）：
「硬切入昏暗草房内——@陈峰 坐在老木桌前，他正大口吃肉——右手拿筷子不停往盘里伸，夹起一块又一块油亮鸡腿肉往嘴里塞，腮帮子始终鼓得高高的用力咀嚼，眼睛一直眯成两道缝，嘴角沾着亮晶晶的鸡油，脸上满是极度原始的口腹满足感，完全沉浸在吃鸡的快乐中；窗外突然传来王大婶尖锐叫骂声——但他没停，筷子照样往盘里夹肉，腮帮子照样嚼着，眼睛照样眯着」

✓ 视觉式（正确）：
「@陈峰家屋内-陈锋家卧室-内 @陈峰 位于画面中心，坐在老木桌前，右手拿筷子夹起一块油亮鸡腿肉往嘴里送，腮帮子鼓着咀嚼，眼睛眯成缝，嘴角沾着鸡油，桌面白瓷盘里@炖鸡汤 油花凝固只剩残骨」

核心区别：✓ 只写"能看到什么"，不写"这意味着什么"。
