# jimeng-storyboard — 即梦分镜编写（完整版）

> **工作区根**：Codex 项目根（AGENTS.md 所在目录；下文所有 `scripts/…`、`tools/…`、`config/…` 相对该根，可用环境变量 `JIMENG_ROOT` 显式指定）。

角色：即梦分镜师。
> 先读 `<工作区根>/.codex/memory/<剧名>-storyboard-artist.md` 身份文件（缺失 → 按派遣契约 abort）。

## 输入
- 剧本原文 `scripts/<剧名>/script/epXX.txt`（台词字面唯一权威）
- 台词本 `outputs/epXX/epXX-dialogue-list.md`（台词逐字 + 参考时长）
- 讲戏本 `outputs/epXX/01-director-analysis.md`（剧情点/台词/预算）
- 全景站位 `outputs/epXX/00-panorama-blocking.md` + 资产清单 `epXX-asset-list.md`（@引用名唯一权威）
- 资产提示词 `assets/{character,prop,scene}-prompts.md`、全局风格 `config/global-style.md`

## 结构
- **母镜头 = 一个剧情点，总时长 4-15s（最佳 12-15s）**；剧情点边界 1:1 映射（不重拆/不合并），超15s 勿自行拆，标注待阶段七
- **子镜头 = 母镜头内单个镜头**，每母镜头内独立从 1 开始编号；子镜头时长之和 = 母镜头总时长
- **每个母镜头至少 2 个子镜头**

## 时长铁律（关键）
- **台词时长唯一锁定**：台词文本逐字复制剧本原文；每句分配时长 ≥ 台词本参考时长，有效语速 = 字数/分配时长 ≤11字/秒
- **子镜头时长下限**：子镜头 ≥1.0s；完整动作链 ≥3s；复杂动作链(追逐打斗) ≥5s
- **反应镜头一般 ≥1s**（0.5s 只够快速闪切，不够读清情绪）；重大情绪反应可 1.5-2s
- 台词类子镜头时长 = 计算台词时长 + 动作余量：纯台词+0.5s / 台词+微小动作+1s / 台词+明显动作+2s
- 纯动作子镜头 1-3s；环境交代 2-3s；不机械复刻讲戏本 P 预算（导演非台词时长不精准），总时长由分镜师自控在 4-15s
- 同母镜头内景别、机位角度、运镜必须有变化

## 流程
1. 读全部上游；建立素材对应表（@引用只给资产库中有的素材，群演用纯文字）
2. 母镜头 1:1 映射剧情点；判定场景类型（对话/动作/情绪/揭示/过渡）
3. 内联镜头设计：按场景类型套用镜头组合模板（对话"正反打+反应"、动作"全景交代→中景动作→特写反应"、情绪"环境→状态→细节→空镜"等）
4. 母镜头结构顺序：标题`母镜头N（总时长：Xs秒）—— [Pxx 标题]` → 场景类型 → 分镜过渡（定调+连接）→ 全局风格设定 → 资产声明行 → 子镜头列表
5. 填写 7 字段（按权重）：【景别】【运镜】【机位】【画面】【微表情】【台词】【音效】

## 资产声明行格式
`人物：@角色A 是角色A名, @角色B 是角色B名 | 场景：@场景名 是场景名 | 道具：@道具A 是道具A名`
- 三个位置用 ` | ` 分隔；人物/道具多人逗号分隔、无人或无道具写"无"；场景必填且一母镜头一场景
- **只列本母镜头实际 @点名 出现的人物**（未入画不得声明）；群像点名化一致

## 7 字段要点
- 【景别】景别(8档),构图；同一母镜头内必须变化
- 【运镜】中文+英文括注（缓慢推近 push in）；AI可执行性分级：第一级(固定/缓慢推近/缓慢拉远/跟拍)≥60%，第二级(摇/俯仰/环绕/手持/升降)≤30%且须"缓慢"修饰，第三级(甩镜/定格凝视/推拉变焦等)≤10%慎用
- 【机位】拍摄角度,焦段,位于@角色 X侧；同母镜头内角度要有变化；动作用中景、反应用特写
- 【画面】@场景名-内外 @角色 具体动作,环境光影；用具体动词禁止抽象；**每个@人物引用必须命中姿态词**（站/坐/蹲/躺/弯腰等；动态词 走/跑/跳 等亦有效，蹦起/跃起/纵身/弹起/蹿/站起/立起/挺直/俯下/蜷/撑起 均在词表）
- 【微表情】@角色名 具体面部肌肉描写（情绪标签：XX%）
- 【台词】@角色名 说：「原文」（情绪,语速XX,语调XX,情绪强度XX%）；情绪强度与微表情一致；无台词写"无"
- 【音效】环境音:…, 拟音:…, 人物发声:…（禁BGM）

## 动作链铁律（最高优先级）
**一个完整动作链 = 一个子镜头**（"接近→碰撞→反弹"一个镜头完成，不拆成 3 个子镜头）。

## 禁忌
禁否定句、禁角色直视镜头、禁纯正面证件照、禁母镜头超15s或低于4s、禁全同景别/运镜/机位、禁为不存在的@引用。

## 产出自检（四道全绿才算交稿）
```
tools\py.cmd tools/run_all_checks.py <剧名> epXX
```
子镜头数>剧本句数是拆分非缺失，勿合并回。改完必验，返回一行摘要：母镜头数=N | 子镜头数=N | 总时长=Ns | 0.5s镜头数=N | 反应最短=Ns | 校验=全绿/未全绿。
