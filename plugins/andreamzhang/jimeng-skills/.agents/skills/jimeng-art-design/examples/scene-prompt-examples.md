# 场景环境提示词示例

> **2026-09-30 用户指令：场景不再按宫格设计。** 一个场景 = 一条独立提示词（单图出图），
> 一条提示词只描述一个场景，不再把多个场景拼进同一张宫格图。
> 本文件已按新规范重写，任何「宫格 / 格子 / 3×3 / 4×4 / 留空」的旧写法均已废弃。

**结构约定**：`## @场景名（新增·epXX）` → 定位行 → 【正向提示词】 → 【负面提示词】。
**通用负面基线**（每条都带，示例中只额外列该场景专属项）：人物、人影、肢体、活动痕迹、使用痕迹、
脏乱污渍、文字水印、logo、多余边框、拼图分格、画面分割、低清模糊、变形透视。
**视角铁律**：全景高机位俯拍——机位高于场景主体，向下约 45° 拍摄，呈现完整空间布局。
**门位铁律**：室内场景必须写明门在画面中的位置，以及门的材质、颜色、状态。
**无人铁律**：场景内不得出现任何人物；家具整洁、物件归位，呈现"事件发生前"的初始状态。

## 示例1：都市情感短剧

**全局视觉规范（写在文件头说明处，全剧贯穿）**
整体风格：真人写实，电影感构图，16:9 宽银幕质感
色彩基调：冷暖对比为主——工作场景偏冷蓝灰，私人空间偏暖黄橙
材质质感：现代都市的玻璃、金属、混凝土质感，夜景有湿润的路面反光

### @深夜写字楼办公室（新增·ep01）

定位：办公空间｜内｜夜（光线区分：仅台灯与屏保，走廊安全出口灯）｜出场集数：ep01–ep03

【正向提示词】
现代都市写字楼的开放式办公区，深夜十一点，全景高机位俯拍——机位高于办公区隔断，向下约 45° 俯视，呈现整个楼层的完整布局。空间横向展开，一侧是成排的工位，另一侧是整面落地玻璃幕墙。大部分工位已经空了，椅子被推开，桌面上散落着文件和未合上的笔记本电脑，屏保的微光在黑暗中闪烁；只有最靠窗的一排还亮着台灯，暖黄色的光在桌面上画出一个个孤独的圆。天花板的荧光灯已关，只有走廊尽头安全出口标志发出暗绿色的光。落地窗外是城市夜景，远处高楼灯光如星，玻璃上映着室内倒影。东南角是通顶的玻璃门，双扇、磨砂边框、处于关闭状态，门缝下漏出走廊的冷白光；安全通道的木门位于画面右下角，深灰色、金属推杆、虚掩。整体色调是冷蓝灰与暖黄的对比。

【负面提示词】加班的人影、电脑屏幕上的可读文字、窗外过亮的城市灯光

### @老旧居民楼楼道（新增·ep01）

定位：住宅公共空间｜内｜傍晚（光线区分：声控灯惨白光 vs 住户门缝暖光）｜出场集数：ep02–ep05

【正向提示词】
九十年代南方城市的老式六层居民楼楼道内部，傍晚时分，全景高机位俯拍——机位在楼梯转角上方，向下约 45° 俯视，能看到楼道纵深与两侧住户门。水泥墙面泛黄，贴着褪色的社区通知和小广告；楼梯扶手是铁质的，漆面斑驳露出底下的锈色。每层转角处有一盏声控灯，发出惨白的荧光，照亮窄小的空间。各家门口堆着杂物——折叠自行车、纸箱、旧鞋架。其中一户的门半开着，暖黄色灯光和炒菜的油烟从门缝里漏出来；户门沿楼道两侧依次排列，深绿色铁门、表面有磕碰掉漆、多为关闭状态，画面右下角那扇是半开的。楼梯向上延伸消失在暗处，形成明显的纵深。

【负面提示词】楼道里的行人、地面垃圾成堆、夸张的城市夜景窗景

### @街边便利店（新增·ep01）

定位：商业服务空间｜内｜夜（光线区分：店内日光灯通亮 vs 店外漆黑街道）｜出场集数：ep01–ep02

【正向提示词】
城市街角的 24 小时便利店，深夜两点，全景高机位俯拍——机位在货架上方，向下约 45° 俯视，完整呈现店内格局。店内日光灯管把整个空间照得通亮刺眼，与外面漆黑的街道形成强烈反差。货架排列整齐，零食、泡面、饮料分区陈列；收银台旁的关东煮锅冒着热气，玻璃罩里的包子已经干瘪；靠窗的高脚吧台区有两把红色塑料高凳，台面上放着吃了一半的便当和一罐啤酒。玻璃门位于画面正下方，双扇推拉、磨砂条贴面、处于半开状态，门外人行道被店内灯光染成一片暖白。

【负面提示词】店员与顾客、货架商品的可读标签文字、店内过曝的高光斑

### @城中村出租屋（新增·ep01）

定位：私人居住空间｜内｜夜（光线区分：唯一光源为笔记本屏幕冷蓝光）｜出场集数：ep02–ep06

【正向提示词】
城中村的小单间出租屋，夜晚，全景高机位俯拍——机位靠近天花板的角落，向下约 45° 俯视，完整呈现这个不到十五平米的空间。单人床靠墙放着，床上堆着没叠的被子和几件衣服；床头是一张折叠小桌当书桌用，上面摞着书和一台旧笔记本电脑，屏幕的蓝光是房间里唯一的光源，把墙面照出一小块冷色区域。墙上贴着几张打印的照片和一张城市地图，窗户很小、挂着薄窗帘。角落有简易衣架，挂着几件衬衫和一件外套。房门位于画面左侧，窄木门、浅棕色、关闭，门缝透进楼道的一线暖光。

【负面提示词】床上的人、屏幕上的可读内容、窗外开阔景致

### @老式居民楼天台（新增·ep02）

定位：建筑顶部开放空间｜外｜凌晨（光线区分：天光将亮，城中村自有灯光）｜出场集数：ep02–ep06

【正向提示词】
老式居民楼的天台，凌晨，全景高机位俯拍——机位在天台上方略高处，向下约 45° 俯视天台地面轮廓与矮墙边界。水泥地面上散落着几个废弃的花盆和一根生锈的晾衣杆；天台边缘是一米高的水泥矮墙，墙面有水渍和青苔；越过矮墙可以看到整个城中村的屋顶——密密麻麻的铁皮顶和水塔，远处是城市 CBD 的高楼群，灯火辉煌。天空是深蓝偏紫的，最亮的几颗星勉强可见；凌晨的风把矮墙上晾着的一条毛巾吹得微微飘动。

【负面提示词】天台上的人、晾晒的整排衣物过密、过曝的日出霞光

### @文艺咖啡馆（新增·ep03）

定位：商业服务空间｜内｜下午（光线区分：落地窗斜射阳光）｜出场集数：ep03–ep05

【正向提示词】
文艺风格的独立咖啡馆，下午三点，全景高机位俯拍——机位在吧台上方，向下约 45° 俯视，完整呈现店内布局。阳光从落地窗斜射进来，在木质地板上投下窗框的影子；吧台是深色木质的，上面摆着一台铜制手冲壶和几个陶瓷杯；墙面是暖灰色的水泥质感，挂着几幅黑白摄影作品；角落的书架摆满了书，旁边是一把旧皮沙发；靠窗的位置有一张双人小桌，桌上放着一杯拿铁，咖啡表面的拉花还没散。入口玻璃门位于画面右下角，木框 + 磨砂玻璃、挂着铜制铃铛、处于半开状态，门外的街道光比店内更亮。

【负面提示词】顾客与店员、书脊上的可读书名、咖啡杯上方的热气过重

### @雨夜城市街头（新增·ep04）

定位：城市道路与人行道｜外｜夜（光线区分：霓虹与车灯，湿地反光）｜出场集数：ep04–ep08

【正向提示词】
城市主干道旁的人行道，秋天的雨夜，全景高机位俯拍——机位在行道树冠上方略高处，向下约 45° 俯视人行道与车道的关系。路面被雨水打湿，积水中映着红绿灯、车灯和商铺霓虹的倒影，色彩斑斓地铺在黑色柏油路上；人行道旁的梧桐树落了一地黄叶，湿漉漉地贴在地砖上；路边停着一排共享单车，车座上积着雨水；远处的十字路口，红灯在雨幕中晕开一团红色光晕；一个公交站台的广告灯箱还亮着，白色光照亮了站台下一小片避雨的空间。

【负面提示词】行人、车辆过多、广告灯箱上的可读文字、过亮的霓虹

## 示例2：古装悬疑

**全局视觉规范（写在文件头说明处，全剧贯穿）**
整体风格：国漫水墨与写实结合，电影感构图，色彩饱和度偏低
色彩基调：以墨色、灰白、青绿为主，点缀暗红作为视觉锚点
材质质感：水墨渲染的山石树木，木质建筑有年代感的肌理

### @官府大堂（新增·ep01）

定位：官署建筑｜内｜日（光线区分：正门进光，越往里越暗）｜出场集数：ep01–ep04

【正向提示词】
唐代县衙的审判大堂，白天，全景高机位俯拍——机位在屋梁下方，向下约 45° 俯视，呈现整个大堂的进深与布局。高大的木质立柱撑起沉重的梁架结构，柱身刷着暗红色漆，漆面已有细密的龟裂；堂上高悬"明镜高悬"牌匾，金字在阴影中若隐若现；公案桌上摆着惊堂木、笔架和一摞卷宗；堂下是青石板地面，两侧各列一排水火棍。光线从大堂正门射入，在地面投下方形的光区，越往里越暗，形成明显的明暗纵深。正门位于画面正下方，三开间木框朱漆门、处于敞开状态，门扇贴金钉铜环；后堂侧门在画面右后方，单扇、暗褐色、关闭。

【负面提示词】衙役与官员、匾额与卷宗上的可读文字、过饱和的红色

### @密室书房（新增·ep01）

定位：宅邸密室｜内｜夜（光线区分：单盏青铜油灯烛光）｜出场集数：ep02–ep07

【正向提示词】
隐藏在宅邸深处的密室书房，夜间烛光，全景高机位俯拍——机位贴近低矮的房梁，向下约 45° 俯视，把狭小空间的四面书墙收进画面。四面都是木质书架，塞满竹简和线装书册；中央一张矮案，案上摊开一幅地图，旁边一盏青铜油灯，灯焰微微摇晃，在墙面和书架上投下摇曳的影子；案角压着一枚玉印和几封密信；地面铺草席，角落一个铜炉，炉中熏香已燃尽，只剩一缕青烟。整个空间被烛光染成暖黄色调，四周暗角透着不安。暗门位于画面左侧书架的第三列，与书架同色、无把手、处于闭合状态，仅门缝比别处略深一线。

【负面提示词】读书或写字的人、地图与密信上的可读文字、现代光源

### @山间驿道（新增·ep01）

定位：野外道路｜外｜黄昏（光线区分：云隙金色光柱）｜出场集数：ep01–ep03

【正向提示词】
秦岭山间的石板驿道，黄昏，全景高机位俯拍——机位在山腰高处，向下约 45° 俯视蜿蜒的石板路与两侧地形。窄窄的石板路沿山腰蜿蜒，一侧是长满青苔的岩壁，另一侧是深不见底的山谷，谷中白雾翻涌；路旁有一座破旧的石亭，亭柱上刻着模糊的文字，亭内石凳上有旅人留下的干粮碎屑；远处山峦层叠，夕阳从云层缝隙射出几道金色光柱，照亮山坡上一片金黄的银杏林；石板路面湿滑，有马蹄踏过的痕迹。

【负面提示词】行人、马匹、可读的亭柱刻字、鲜艳的现代色彩

### @小镇酒肆（新增·ep02）

定位：市井餐饮空间｜内｜日（光线区分：正午阳光从大门与二楼窗进光）｜出场集数：ep02–ep06

【正向提示词】
小镇上的二层木质酒肆，正午，全景高机位俯拍——机位在一楼大堂上方，向下约 45° 俯视，完整呈现大堂格局与楼梯位置。一楼大堂摆着七八张方桌，桌面磨得发亮，上面有酒渍和刀痕；柜台后面是一排酒坛，坛口用红布封着，墙上挂着酒旗和价目木牌；楼梯是木质的，踏板中间凹陷，被无数脚步磨出了弧度；正午的阳光从敞开的大门和二楼窗户照进来，光线中浮着灰尘；一张靠角落的桌上放着吃了一半的菜和一壶酒，好像客人匆匆离去。正门位于画面正下方，双扇木门、朱红褪色、全开，门槛处被踩出凹痕；后厨布帘门位于画面左后方，蓝灰粗布、半掩。

【负面提示词】酒客与店小二、酒旗与价目牌上的可读文字、油腻的强反光

### @地牢（新增·ep02）

定位：县衙地下牢房｜内｜夜（光线区分：走廊尽头将熄油灯，几乎无光）｜出场集数：ep02–ep05

【正向提示词】
县衙地下的牢房，几乎无光，全景高机位俯拍——机位在牢房顶部靠墙处，向下约 45° 俯视，勉强能看清空间轮廓。粗糙的石壁上渗着水珠，地面是潮湿的泥土，角落铺着发霉的稻草；铁栅栏门锈迹斑斑，锁链垂在两侧；唯一光源是走廊尽头一盏快要熄灭的油灯，微弱的光勉强照出牢房轮廓，铁栅栏在地面投下平行的条状阴影；牢房深处完全没入黑暗，只能隐约看到墙上有被指甲划过的痕迹。牢门位于画面右侧，铁栅栏、锈红褐色、锁闭，门轴处的铁锈堆成小丘。

【负面提示词】囚犯与狱卒、明亮的环境光、可读的墙上刻字
