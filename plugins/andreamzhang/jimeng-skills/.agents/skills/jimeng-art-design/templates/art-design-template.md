# 服化道设计产出模板

输出文件（跨集累积，追加式写入）：
- assets/character-prompts.md — 人物提示词
- assets/prop-prompts.md — 道具提示词
- assets/scene-prompts.md — 场景道具提示词

---

## 人物提示词格式（唯一口径 · 2026-10-09 起）

文件：assets/character-prompts.md

每个角色独立一段，不得多人合并，便于直接复制出图。

```markdown
出图要求：竖屏9:16，纯白背景，上1下3四格排版，分割构图。顶部面板：该角色特写肖像，保持面部特征和发型完全一致。底部面板：三个无头全身人体模特视图并排排列，在颈部截断，没有头部，仅展示服装，从左到右依次为正面、侧面、背面。顶部肖像与底部服装必须是同一角色、同一套服装。
角色信息：<角色名，身份定位，年龄/性别，气质，情节背景>。
面部特征：<脸型，眼型/眉毛/鼻/唇，肤色，发型发色，佩戴物，表情>。
服装细节：上衣为<款式 + 颜色 + 材质 + 细节>；下装为<款式 + 颜色 + 材质 + 细节>；鞋为<款式 + 颜色 + 材质>；配饰为<手表/耳环/眼镜/包/武器挂件，写明位置与左右侧>；颜色以<主色调>为主；材质为<面料/材质>；图案为<有无文字/logo/花纹>；标志性元素为<一眼识别的关键物品>。
画质要求：真人实拍质感，高清真人摄影画质，8K超高清，专业影棚柔和无影柔光，均匀漫射光，无强烈硬阴影。画面不能出现3D建模感、CG渲染感、二次元动漫感、手绘插画感、油画感、雕塑感、塑料假肤感；真人实拍必须有真实皮肤次表面散射纹理，可看清毛孔、细小绒毛、轻微肤色不均，但不磨皮不加磨皮滤镜，也不能有肿胀填充面部的网红整容脸。干净商业角色设定图，纯白背景，无文字，无水印，无logo，无杂乱背景。
避免：多余头部、错误人体结构、多手多脚、服装不一致。
```

状态变体在同条目下注明关联与差异，不另起 @名。

## 道具提示词格式

文件：assets/prop-prompts.md

```markdown
## [道具名]（ep01 新增）

**出图要求**：一张图，白色背景，道具正视图、45度视角图、关键细节放大图或激活状态图同画面展示

**提示词**：
[整体形态与比例、材质/颜色/纹理、结构分层、发光或特效状态、在镜头中的可见方式、世界观兼容性、整体气质]
```

## 场景环境提示词格式

文件：assets/scene-prompts.md

**一个场景 = 一条独立提示词（单图出图）**，禁止宫格/拼图/多场景合图。

**核心规则**：
- 场景内不得出现任何人物
- 场景应呈现“事件发生前”的空场景状态
- 同一场景的日/夜/光线差异写在同一条目里

**开头先给场景清单表**：

| @引用名 | 定位 | 内外 | 时间 | 出场集数 | 新增/复用 |
|---|---|---|---|---|---|

```markdown
# 场景环境提示词

## @[场景名]（新增·ep01）

定位：[地点类型]｜[内/外]｜[日/夜]（光线区分：[同场景不同光线的处理]）｜出场集数：[epXX–epXX]

【正向提示词】
[完整叙事描述：地点类型与空间布局 → 视角（全景高机位俯拍，约45°俯角） → 门的位置（室内必写） → 时间 → 光源类型与方向 → 整体色调 → 关键家具/物件静态摆放 → 空间纵深与层次 → 氛围/情绪 → 风格]

【负面提示词】
[该场景专属负面；通用基线对齐 config/global-style.md]
```

**追加规则**：后续集数的新增场景，按同样结构追加到文件末尾。

## 输出规范

- 中文提示词
- 叙事描述式，不要关键词堆叠
- 直接输出完整提示词，不要逐条解释设计理由
- 每个提示词必须完整可用，用户可直接复制到文生图工具生成图片
- 每个条目标注创建集数（如 ep01 新增）
- 如果是变体设计，需在提示词中注明与原版的关联和差异
- 复用项不重复写入，只为“新增”和“变体”项编写提示词
