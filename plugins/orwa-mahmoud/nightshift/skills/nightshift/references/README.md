# References

One file answers one question for one moment. A skill points at a file at the step that needs it,
with the condition that makes it needed in the same sentence — never in a list of things to read
first. Nothing here is loaded because it might come up.

- `compose/` — read while composing a shift or its contract: Hunt, Quality, and Setup proposing
  gates. A shift already running one has no reason to open any of it. `compose/shifts/` holds the
  catalog entries; `ns catalog-index` lists them without reading them.
- `shift/` — read by the shift that is working: direct-mode decisions, the cited-research contract,
  and the state map.
- `receipts/` — one receipt kind per file. The file names are the index; open the one you are
  writing.
- `hosts/` — read only when a Start verdict names that host. Every verdict-tied paragraph already
  travels on the helper's own `explain` and `repair` lines, so what is left here is genuinely
  per-host.
- `templates/` — copied into `$NS/` by `ns scaffold`, never read into context. Copying a file does
  not require its text.
- `nightshift-rules-template.json`, `nightshift-rules.schema.json`, `schemas/`, `profiles/` — the
  published contract paths. An owner's `rules.json` carries a `$schema` pointer to them, so they
  stay where they are.
