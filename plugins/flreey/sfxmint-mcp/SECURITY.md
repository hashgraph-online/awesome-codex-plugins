# Security

This repository holds configuration only: it points clients at the hosted SFXMint MCP server (`https://sfxmint.com/mcp`) and ships a skill file. It runs no local code and needs no secrets.

To report a vulnerability in the server, the website or these files, email hello@sfxmint.com, or open a private advisory at https://github.com/sfxmint/sfxmint-mcp/security/advisories/new. Please do not open a public issue for security reports. We aim to reply within five working days.
