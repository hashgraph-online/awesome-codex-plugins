# Security

SteinWall runs locally as hooks inside Claude Code and Codex. It does not send prompts, code, file paths or keys anywhere. The only network calls are the optional license refresh (Pro) and the opt-in daily savings number (off by default).

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: **Security → Report a vulnerability** on this repository. Do not open a public issue for security problems.

Especially welcome: ways to get a blocked action past the action guard, extensions that slip past the scanner, and anything that makes SteinWall itself read or send data it should not.

You will get an answer within a few days. Fixes are released as a new plugin version.
