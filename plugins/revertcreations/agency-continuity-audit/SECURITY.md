# Security policy

Please report suspected vulnerabilities privately through GitHub Security
Advisories for this repository. Do not include secrets, customer data, or a
private agent workspace in a public issue.

Supported releases are the latest tagged release and the current `main` branch.
Revert Creations will acknowledge a reproducible report as soon as practical,
evaluate its effect on local confidentiality and audit integrity, and publish a
coordinated fix when warranted.

The plugin is intentionally local, read-only, dependency-free, and network-free.
Its output can contain local paths and compact evidence, so reports should be
reviewed before sharing.
