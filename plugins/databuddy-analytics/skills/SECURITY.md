# Security

## Reporting a vulnerability

If you find a security problem in this plugin, its skills, or the Databuddy MCP server at `https://api.databuddy.cc/v1/mcp`, email security@databuddy.cc with the details and steps to reproduce. Please don't open a public issue. We'll reply as quickly as we can.

## What this plugin does

The plugin contains instructions (skills) and a pointer to Databuddy's hosted MCP server. It runs no install scripts or hooks and stores no credentials. You sign in to Databuddy with OAuth the first time your agent needs your data, and you choose which organization, websites and permissions it gets.
