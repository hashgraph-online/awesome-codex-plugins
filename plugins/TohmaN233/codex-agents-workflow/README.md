# Codex Agents Workflow

A local Codex workbench for reusable agent Workflows, Roles, Providers, and recoverable Runs. The Host schedules steps, validates declared dependencies and permissions, records exact recovery state, and leaves verification and acceptance with Main.

Requires Node.js 20 or newer and a Codex host with plugin and MCP support. Runtime browser assets and their licenses are bundled; users do not need to install development dependencies.

Install from the author's repo marketplace or a compatible curated marketplace. The MCP startup identifies the launching installation's marketplace and uses that source's current installed version.

Open the Workflow workbench, choose an existing Workflow, or turn a Skill into a reusable Workflow. External Providers are disabled by default and require deliberate configuration.
