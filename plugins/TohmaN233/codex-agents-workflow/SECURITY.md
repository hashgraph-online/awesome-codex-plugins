# Security policy

Report vulnerabilities privately at https://github.com/TohmaN233/codex-agents-workflow/security/advisories/new.

Provide the installed version, platform, reproduction steps, and sanitized startup or Run diagnostics. Never publish provider credentials, console tokens, task capabilities, or private workspace contents.

The current release receives security fixes. The complete policy and execution boundaries are maintained at https://github.com/TohmaN233/codex-agents-workflow/blob/main/SECURITY.md.
