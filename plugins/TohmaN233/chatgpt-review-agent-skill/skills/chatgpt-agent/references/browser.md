# ZIP browser workflow

Reuse the current ChatGPT tab in the Codex in-app browser. Do not open a second
ChatGPT page or switch to Chrome.

Attach the generated ZIP and confirm its attachment chip before sending the
task goal and output contract. Do not capture a response while generation is
still active.

When the result must be saved locally, capture only the newest complete
assistant response after the latest packet prompt. Prefer its copy control;
otherwise select that final assistant message. Do not save the user prompt, an
older response, an interim fragment, or a tool-status label.

Codex saves any requested report or patch and reads it back before use. ZIP mode
must not use MCP for local writes.
