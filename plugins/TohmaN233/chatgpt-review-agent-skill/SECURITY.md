# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities through [GitHub Private Vulnerability Reporting](https://github.com/TohmaN233/chatgpt-review-agent-skill/security/advisories/new). Reports submitted there are visible only to the repository maintainers until they are disclosed.

Please include the affected version or commit, a clear description of the impact, and steps to reproduce. Do not open a public issue for an unpatched vulnerability.

## Supported Versions

Security fixes are made on the latest version of the project.
