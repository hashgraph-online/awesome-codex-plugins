# Security Policy

## Reporting a vulnerability

Email **hello@getclera.com** with a description of the issue, steps to reproduce, and the affected endpoint or file. Please do not open a public GitHub issue for security reports.

We acknowledge reports within 3 business days and keep you updated until the issue is resolved.

## Scope

- The remote MCP server at `https://mcp.getclera.com` and its OAuth flow
- The manifests and skills in this repository

This repository contains no executable server code; the server is operated by Clera Labs, Inc.
