# Security policy

This repository holds connection settings and agent instructions for the hosted ComputeFirst service at https://computefirst.net. It contains no server code and no credentials.

## Reporting a vulnerability

Report vulnerabilities in this repository or in the hosted service privately to the contact listed at https://computefirst.net/.well-known/security.txt. Please do not open a public issue for a vulnerability. Include what you found, how to reproduce it, and what it affects.

## Using the service safely

Tool inputs are sent to computefirst.net for execution. Do not send secrets, and use local code when data must stay on your machine. See https://computefirst.net/privacy.
