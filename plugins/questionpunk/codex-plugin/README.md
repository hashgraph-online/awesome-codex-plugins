# QuestionPunk plugin

Create saved survey drafts, refine questions, review studies and analyze authorized research results from Codex. The plugin connects to QuestionPunk's hosted MCP endpoint (https://app.questionpunk.com/api/v1) with OAuth and bundles four skills: `create-study`, `manage-study`, `review-study` and `analyze-results`.

Install instructions, permissions and support are in the [repository README](https://github.com/questionpunk/codex-plugin#readme).
