# Security Policy

Agent Retro reads local agent session logs, so privacy and security reports matter to us.

## Reporting a vulnerability

Report vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/summationai/agent-retro/security/advisories/new).
Do not open a public issue, pull request, or discussion for a security problem.

Include what you found, how to reproduce it, and the impact you expect, such as prompt or
metadata content escaping redaction. We aim to acknowledge reports within a few business days.

## Supported versions

Only the latest commit on `main` of [summationai/agent-retro](https://github.com/summationai/agent-retro)
is supported. The plugin installs from `main`, so fixes ship there. The repository's root
[SECURITY.md](../../SECURITY.md) is the canonical policy.
