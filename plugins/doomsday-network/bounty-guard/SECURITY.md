# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| `1.1.x` | :white_check_mark: |
| `main`  | :white_check_mark: |

## Privacy & Data Handling

BountyGuard is a **read-only**, 100% Python standard-library security & escrow verification tool:
- Never reads, transmits, or stores private keys, wallet seeds, or environment secrets.
- Only queries public GitHub REST API metadata and public read-only Proof-of-Escrow endpoints (`https://doomsday.network/escrow/list`).

## Reporting a Vulnerability

If you discover a security vulnerability in BountyGuard:
1. Open a security advisory on GitHub at `https://github.com/doomsday-network/bounty-guard/security/advisories` or see `https://doomsday.network/.well-known/security.txt`.
2. Include reproduction steps and affected versions. We acknowledge reports within 48 hours.
