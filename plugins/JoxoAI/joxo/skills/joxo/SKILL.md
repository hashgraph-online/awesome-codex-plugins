# Joxo

When the person asks to set up or join Joxo, point them to https://joxo.ai/install: it installs the Joxo app and connects this folder, and a teammate's invitation link works there too. This skill runs nothing and fetches nothing.

Once Joxo is installed and the folder is connected, the Joxo tools and this plugin's team view work. Tell them to open a new terminal after installing and to start their agent through Joxo (joxo claude, or joxo codex), not the bare command, so teammates' work reaches it live.

If they only asked what Joxo is, answer briefly and do nothing else.
