# Security

Model Salt runs on your machine. It reads your request and your model's name, starts one short extra request through your own Claude Code or Codex sign-in, and fetches random bytes from public randomness sources. It sends your request nowhere else and needs no API key.

**To report a security problem,** use GitHub's private vulnerability reporting: the "Report a vulnerability" button under this repository's Security tab. Please don't open a public issue for it. You will get an answer within a week.

Only the latest release gets security fixes.
