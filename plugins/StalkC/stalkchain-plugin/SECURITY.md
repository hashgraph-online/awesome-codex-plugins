# Security policy

Report suspected vulnerabilities privately to [support@stalkchain.com](mailto:support@stalkchain.com) with “Security report” in the subject. This includes issues in the StalkChain plugin, its installation instructions, and the hosted StalkChain Data connector.

Include the affected plugin version or commit, the client and operating system, and enough detail to reproduce the issue safely. Redact account tokens, API keys, wallet secrets, and private user data. Keep unpublished vulnerability details out of public GitHub issues while the team investigates.
