# Infrastructure

Inspect environment/IaC ownership, pipelines, secrets, runtime limits, and
health/rollback mechanisms. Decide resource ownership, rollout/config migration,
bounded retries/degradation, useful signals, rollback, and cleanup. Reuse platform
facilities; require demonstrated need for new resources.

Verify config, changed retry behavior, dependency health, and practical rollback.
Keep plan, apply, readback, and operational completion distinct; CI success does
not authorize cloud mutation.
