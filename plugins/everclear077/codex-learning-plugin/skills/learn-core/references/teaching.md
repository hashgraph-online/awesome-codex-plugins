# 课程设计与验收

## 核心选择

先反推验收需要什么，再以概念的任务覆盖、前置依赖、常见失败影响与学习成本做定性排序。不要凭空生成百分比收益或伪精确评分。每个核心块说明「它解锁哪一步」「最小验证是什么」。必要依赖不得因低频而删掉；优先删除当前交付物不需要的细枝末节。

使用一张小地图：核心概念→必要前置→它支撑的行动→待验证误区→可信来源。参考Superlearn的证据与结构化展示，但只为当前学习决策做图；不先堆一整座资料库。初始检索找到能支撑第一块练习和目标框架的资料即可开始，争议/高风险/最新问题再加深。完整专题调研按用户明确需求另行展开。

## 预算示例（本插件设计，不是实验测出的最佳比例）

| 工作 | 20小时示例 | 30分钟首课示例 |
|---|---:|---:|
| 目标、诊断与拆解 | 1小时 | 3分钟 |
| 必要前置与首版尝试 | 3小时 | 5分钟 |
| 短循环练习、纠错与提速 | 11小时 | 16分钟 |
| 倒讲与跨会话回忆 | 3小时 | 3分钟倒讲/已有内容回忆 |
| 交付与验收 | 2小时 | 3分钟 |
| 合计 | 20小时 | 30分钟 |

这些是活动累计预算，分散到多个会话；3小时回忆不代表集中复习3小时。新学的30分钟课没有跨天证据，应另给后续复测建议。20小时可以跨多天，不鼓励连续熬夜。准备和基础较强者应提前缩短讲解，基础薄弱者缩小作品而不是取消练习。实际投入由用户确认，未报时间写未知。

首版建议最晚在冲刺约20%预算内出现，验收预留最后约10%；这是默认里程碑，运动、医学等真实约束优先。里程碑未达时找瓶颈、砍非核心范围，保留最终验收条件，不事后把一段空模板当原目标完成。

## 支架与反馈

有一点基础就开始真实小任务；完全无从下手时给一段必要讲解或不同题目的完整示范，解释为什么做每一步，然后逐步撤去支架。不能把「从不讲解」当原则，也不能让AI一口气完成活动题。

将错误分为：概念/前置缺失、题意或条件遗漏、策略选择、步骤执行、记忆提取、粗心与检验缺失。一次修最影响目标的一类，根据下一次表现改变教学策略。交错练习用来辨别相近方法何时用；先建立基本正确性，再混排。不同领域学习效果不能由同一个实验直接推定。

练习分暖身、应用、变化三档，但不一次输出完整题库。练习题的标准和来源先核对；开放题给理由充分且可接受的多种解法，不用措辞匹配评分。若答案有争议就暂停对该点下定论、查证，不把AI自信当判据。

## 成果与通过条件

“没产物=本次目标未完成”是本插件的冲刺验收约定，不是否定过程中的学习。产物可为真实对话、完成的动作、现场推导、可复述图、论证笔记或代码，必须匹配初始目标。

| 状态 | 需要的证据 |
|---|---|
| 提示下完成 | 记录实际帮助及用户修正 |
| 独立完成 | 未见答案、无提示完成相应任务并说明关键理由 |
| 迁移通过 | 在一个新的约束、输入或反例下正确处理 |
| 延迟复测通过 | 稍后另一会话/日期的独立提取，保留时间 |

概念通过要求独立应用+理由；课程收尾要求作品满足2–4条验收标准+用户独立解释/修改或迁移测试。延迟保留单独报告，不能在同一天速成结业时虚构。AI辅助生成可作为脚手架，但用户必须能处理其负责学习的核心部分。

## Transformer示例

目标：在给定小语料与可用算力下，手写causal attention与MLP，训通字符级小GPT；独立解释mask及√dₖ缩放，并通过因果性检查。前置：Python、张量形状、矩阵乘法、基本梯度更新；缺哪项仅补与实现相关的最小部分。

可选7块：字符编码与批次、Q/K/V及张量维度、缩放点积、因果mask、MLP与残差/归一化、下一个字符损失与训练、采样及验证。暂缓大规模分布式、生产部署、模型对齐、复杂分词器、性能内核。具体实现顺序依用户基础调整。

验收可约定：前向形状正确且可反传；给定小批次loss有可复现下降；修改未来token不影响当前及过去位置输出（eval或关闭随机因素）；解释缩放的假设并完成一个维度变化题。生成像样文本不是微小模型训练必然结果，不凭肉眼好看宣布训练成功。此处是课程示例，开课时核对当前框架官方文档与原始论文。

## 跨领域适配

- 数学/科学：推导、解释条件、反例、未见应用题；不能只记结论。
- 编程/工程：尽早跑最小垂直功能，检查边界和复现；AI不能代替学习者提交核心实现。
- 语言：高频情境、真实听说/写作、针对错误反馈；卡片服务表达而非背词数量。
- 人文/社会科学：关键问题、概念区分、不同立场及原文证据；允许有理由的多种解释。
- 动作/艺术：拆到可观察动作或作品细节，练习与反馈依靠真实表现；文本讨论不能证明动作能力。
- 专业执业内容：阶段成果用学习任务定义，不能把短冲刺当执业资质或现实高风险操作授权。
