# 学习

把学习组织成可验收的能力增长：先找到最值得学的少数概念，再通过尝试、提示、再试、倒讲和延迟测验，尽早交付真实作品。

在新任务中选择「学习」，或输入：

```text
用 $learn-core 带我学习 Transformer。我会 Python，预算20小时。
目标是手写 causal attention + MLP，训通字符级小 GPT，讲清 mask 与 √dₖ。
默认一次一题，答错只给提示，等我答完再继续。
```

也可以说「切换倒讲，我来解释」「给我5道提速题，先别给答案」「毒舌评审我的作品」「先考上次学过的内容」。显示名为「学习」；内部插件标识 `core-learning` 和技能调用名 `$learn-core` 保留，便于已有安装继续使用。

## 八条默认原则

1. 用一句话约定能做什么、怎样验收；知道名词不等于达到目标。
2. 第一轮保留5–9个高杠杆概念，列出必要前置和「现在故意不学什么」。很小的目标不硬凑数量。
3. 每次会话自动重申家教规则：一次一个概念、一道题、等作答；错了只提示，再试；能讲清原因才进入下一块。
4. 尽早做出粗糙但可运行、可演示的首版，避免把准备当成果。
5. 大部分主动学习时间用于「试→错→提示→再试」。
6. 由你倒讲，AI指出关键漏洞，等你修正。
7. 新会话先回忆旧内容；长期记忆可用Anki的FSRS安排复习。
8. 20小时冲刺结束前必须有符合目标的交付物；缺少作品或独立表现证据，标记为未完成。

## 五种模式

| 模式 | 何时用 | AI此时的任务 |
|---|---|---|
| 苏格拉底练习（默认） | 学新核心、修复卡点 | 一题一等、分级提示、独立新题验证 |
| 倒讲查漏 | 练完一块后 | 听你讲，只指出模糊、错误、缺条件之处 |
| 刷题提速 | 基础已正确，需要熟练 | 短题、先作答后反馈，逐步交错相近题型 |
| 项目毒舌评审 | 已有作品 | 用验收标准找缺陷、给复现办法、由你修复 |
| 间隔测验 | 每次续学开始 | 先闭卷，记录首次表现，再安排补学与复习 |

每轮只运行一种模式。阶段结束时明确切换，不在同一条待答题下同时给答案、倒讲任务、刷题和评审。短解释或不同例子的示范可作为必要支架；不会把长篇讲解当成默认学习方式。

## 时间与能力边界

20小时是可调整的冲刺预算，不是精通所有领域的保证。可使用30分钟、2小时或更长预算；先按基础缩小成果，再保留练习和验收。AI生成的内容、AI代写的作品、提示下做对，均不自动算作你的独立能力。

进度保存在学习工作区，不写入插件缓存。支持保存待答题、错误类型、提示使用情况、作品证据和续学安排。Anki导出脚本只生成本地文件；导入和FSRS调度由Anki完成，插件本身不在后台提醒，也不内置FSRS算法。
