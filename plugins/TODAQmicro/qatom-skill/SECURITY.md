# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities to **support@todaq.net** rather than opening a public issue.

Include a description of the issue, steps to reproduce, and the affected component (skill, MCP wiring, or CI). We aim to acknowledge reports within 2 business days.

## Scope

This repository is a plugin/skill package that connects to the hosted Qatom MCP server at mcp.m.todaq.net. For vulnerabilities in the MCP server or payment infrastructure itself, report to the same address with "MCP server" in the subject.
