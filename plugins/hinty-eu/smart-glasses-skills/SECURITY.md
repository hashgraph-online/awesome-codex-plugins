# Security

The skills are Markdown files and run no code on install. The examples are small apps you build and run yourself.

If you find a security problem (for example an example that leaks a key, or instructions that would make an agent do
something unsafe), report it privately through GitHub:
[report a vulnerability](https://github.com/hinty-eu/smart-glasses-skills/security/advisories/new). Please do not
open a public issue. We aim to reply within 7 days.

If you cannot use GitHub, email **support@hinty.eu** instead.
