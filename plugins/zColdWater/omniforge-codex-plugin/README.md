# OmniForge Launch Audit — Codex & AI Assistant Plugin

**Read-only pre-launch security, email deliverability, domain/USPTO trademark, and `/llms.txt` audit plugin** bundling 4 `SKILL.md` workflows and a zero-auth Streamable-HTTP MCP connector (`https://brand-checker.appwrite.network/mcp`).

## Capabilities

- **Web & Supabase RLS Security (`vibeshield-security-audit`)**: Unpack Next.js/Vite client bundles for exposed credentials, verify Supabase Row-Level Security & Firebase rules, and audit CSP/HSTS headers ([Free 6-Phase Cloud Scanner](https://vibe-checker.appwrite.network/?ref=gh-codex-plugin) · [$2 Single-App Fix Unlock](https://omnipulse-x402.appwrite.network/go/gumroad/vibeshield)).
- **Email Deliverability & DMARC (`spf-dmarc-deliverability-audit`)**: Count recursive RFC 7208 10-lookup SPF chains, verify DKIM public keys, and enforce DMARC `p=reject` ([Free 6-Phase DNS Trace](https://inbox-checker.appwrite.network/?ref=gh-codex-plugin) · [$2 Flattened SPF/DMARC Unlock](https://omnipulse-x402.appwrite.network/go/gumroad/inboxshield)).
- **78-TLD Domain & USPTO Check (`brand-domain-trademark-audit`)**: Live RDAP, aftermarket NS detection, public dev handles, and USPTO wordmarks ([100% Free Forever](https://brand-checker.appwrite.network/?ref=gh-codex-plugin)).
- **AI Search & `/llms.txt` (`llms-txt-citation-readiness`)**: Validate `/llms.txt`, 10 AI search crawlers in `robots.txt`, and Schema.org JSON-LD ([Free Side-by-Side PK](https://citeready-checker.appwrite.network/?ref=gh-codex-plugin) · [$2 Fix Kit](https://omnipulse-x402.appwrite.network/go/gumroad/citeready)).

## Security & Privacy

Strictly read-only public DNS, RDAP, and HTTP header/bundle checks. Zero API keys required. See [SECURITY.md](./SECURITY.md).
