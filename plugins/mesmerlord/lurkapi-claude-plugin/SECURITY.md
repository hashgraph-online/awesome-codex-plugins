# Security

To report a security issue in this plugin or in LurkAPI's hosted MCP server, email support@lurkapi.com with the details and the steps to reproduce. Please don't open a public issue for it.

The plugin has no code and holds no credentials. It connects to `https://api.lurkapi.com/mcp`, and you sign in through LurkAPI in the browser (OAuth). The key that creates is scoped to your account, and you can revoke it in your [dashboard](https://lurkapi.com/dashboard).
