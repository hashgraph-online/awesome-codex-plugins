# Security

Off the Wall reads your local Claude Code and Codex history and stores your corrections in `~/.otw`. It sends
nothing anywhere itself: the only outbound call is the judge, run through your own `claude` or `codex` CLI.

Please report a security problem privately through
[GitHub security advisories](https://github.com/toranalytics/off-the-wall/security/advisories/new),
not in a public issue.
