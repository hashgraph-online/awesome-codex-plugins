# Worked contract: Suede AI Content Strategy Skills

This is an illustrative application, not a claim of measured customer results.

## Input

A B2B service can produce two articles per month. Support tickets repeatedly ask about setup and migration; analytics show existing setup traffic but weak activation.

## Expected output

Prioritize a setup guide refresh and a migration decision guide before opening a new topic pillar. Map each to the buyer question, funnel stage, evidence owner, distribution route and KPI. Use qualified activation from guide readers, with a defined attribution window, as the setup objective.

## Failure and validation

If analytics cannot connect readers to activation, make instrumentation an explicit dependency. Do not invent keyword volume or promise traffic. Keep proposed output within two articles per month and name what is deferred.
