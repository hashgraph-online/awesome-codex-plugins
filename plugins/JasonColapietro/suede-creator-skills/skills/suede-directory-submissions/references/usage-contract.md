# Worked contract: Suede AI Directory Submissions Skills

This is an illustrative application, not a claim of measured customer results.

## Input

Plan distribution for a live invoicing app. The brief includes canonical name, URL, logo and two customer-approved descriptions. No submission destination has been authorized.

## Expected output

Return a ranked directory shortlist and tracker rows containing destination, fit, proposed copy, cost, status, evidence URL and next check. Research terms and eligibility before proposing a destination. Leave each row planned until its specific submission is authorized.

## Failure and validation

An accepted form response is submission evidence, not proof that a public backlink exists. Verify the live listing and link target before marking published. A changed fee or copy requirement needs a fresh destination decision; do not silently create an account.
