# Directory Research Queue

This is a discovery queue, not a current directory database or endorsement.
Platforms, submission URLs, categories, terms, pricing, moderation, link
attributes, ownership, traffic, and availability change. Never use a candidate
below as a recommendation or submission target until it passes the verification
workflow at the end of this file.

Do not assign an authority score, traffic estimate, `dofollow` label, expected
conversion, ranking effect, citation effect, or cost from memory. Capture each
fact from a current authoritative source with its URL and check date.

Research when the user has a real launch milestone. Verify product eligibility,

## Startup and Software Directory Candidates

- AlternativeTo
- SaaSHub
- G2
- Capterra
- GetApp
- Software Advice
- SourceForge
- F6S

Research audience fit, category fit, listing requirements, review rules, exact

Ownership changes too: G2 announced in January 2026 that it agreed to buy
Capterra, GetApp, and Software Advice from Gartner. Do not describe any of the
three as a Gartner property, and check whether listings still sync between them
in your category before treating them as separate submissions.

## No-Code Directory Candidates

- No Code Founders

## Integration Marketplace Candidates

Research the official marketplace run by each integration owner only after the
integration is live. Examples may include CRM, automation, collaboration, CMS,
commerce, or developer-platform marketplaces.

Verify partner eligibility, app review, security requirements, support
obligations, listing fields, trademark rules, fees, and whether the user is
authorized to accept partner terms.

Worked example, last checked October 2026 (re-verify against Notion's developer
docs before building):

- **Notion Marketplace** requires a working public Notion connection. Its
  installation scope must be set to "Any workspace" when the connection is
  created. The scope cannot be changed later, and other scopes are not eligible
  for listing, so a connection created with the wrong scope means starting a new
  one. Notion reviews each listing submission, including a security review, and
  an approved listing gets a page at notion.com/connections/<name>.
- A simple, genuine use case is enough to qualify, for example sending the
  app's data into a Notion database. Build it because customers will use it;
  the listing link is a side effect, not the reason.

Source: https://developers.notion.com/guides/get-started/marketplace-listing

## Local and Vertical Directory Candidates

Research only where the business has a real local presence, license, service

- Local business profiles
- Legal
- Home and construction
- Hospitality
- Design and creative
- Health and fitness
- Real estate
- Education

Verify jurisdiction, business identity, license requirements, address/privacy

## Editorial Outreach Candidates

Relevant comparison articles, resource pages, newsletters, and trade publications
may be better fits than directories. Treat them as outreach, not guaranteed
placements. Verify editorial contact, disclosure rules, sponsorship cost,
audience fit, and the article's current status. Do not buy undisclosed links.

## Verification Workflow

For every candidate:

1. Open the current official site and submission or partner documentation using a
   callable, authorized research surface. If none is available, give the user a
   manual research checklist and label the candidate unverified.
2. Record:
   - canonical home and submission URLs
   - source URL and retrieval date
   - current product/category eligibility
   - required account, assets, claims, and approvals
   - moderation and expected maintenance process
   - exact free and paid options, currency, taxes, and maximum cost
   - review, incentive, solicitation, privacy, and disclosure policies
   - whether a live listing exists and its canonical URL
3. Inspect the rendered listing link and redirects. Record observed `rel`
   attributes and destination behavior. Absence of `rel` in response headers is
   not proof of a followable link.
4. Check first-party analytics after launch for referral sessions, qualified
   actions, and cost. Do not infer outcomes from an authority metric.
5. Recheck volatile facts before submission and quarterly for maintained
   listings.
