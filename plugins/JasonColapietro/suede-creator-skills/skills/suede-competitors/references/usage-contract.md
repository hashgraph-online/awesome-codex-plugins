# Worked contract: Suede AI Competitor Comparison Skills

This is an illustrative application, not a claim of measured customer results.

## Input

Write a versus page from profiles captured this week. Product A bills per editor; Product B bills per workspace. The buyer is a five-editor studio.

## Expected output

Lead with the best fit for that buyer, explain both billing units, and compare the documented five-editor scenario. Include migration effort, dated source links and a clear next action. Use the existing evidence rather than fill empty comparison cells with guesses.

## Failure and validation

If workspace seat limits are unknown, leave the scenario total unresolved and request that fact. Do not compare one vendor annual billing to the other monthly billing as if they were equivalent. Deliver draft copy, not a published page.
