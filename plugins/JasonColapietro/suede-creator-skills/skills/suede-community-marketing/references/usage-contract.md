# Worked contract: Suede AI Community Marketing Skills

This is an illustrative application, not a claim of measured customer results.

## Input

A tool for independent bookkeepers has 120 customers, one moderator and no community. The goal is peer support; the team can staff one weekly session.

## Expected output

Choose one platform against access, searchability and moderation needs. Propose a founding cohort, one weekly reconciliation clinic, a moderator escalation path and a 90-day calendar. Define activation as a first useful contribution within seven days, with invited members as the denominator.

## Failure and validation

If there is no moderator owner, return the staffing gap and a smaller pilot. Count staff posts separately from member contributions. A seed plan is a list of proposed invitations, not permission to contact customers.
