# Worked contract: Suede AI Code Skills

This is an illustrative application, not a claim of measured customer results.

## Input

A PR changes an invoice total calculation; the request is findings-only. Supply base and head revisions, the expected rounding rule, and the repository test command.

## Expected output

Return P0-P3 findings with changed file and line, a concrete failing input, impact and fix path. Omit letter grades in this mode, but retain deploy-safety and commit-dirt results. A missing runtime becomes a named unverified check, never a passed test.

## Failure and validation

For 19.995 rounded to two decimal places, inspect the actual monetary representation and declared rounding rule before calling it a bug. A process import alone is a capability, not proof of injection. Reject findings without a reproducible path.
