# Suede AI Site Alchemy Skills: Worked Handoff

## Inputs

Request: “Fix this page that gets no signups.” Supply the route, repository and
branch, primary audience, intended action, current source, desktop/mobile
rendering, and a dated event export if available. Synthetic observation: the
primary CTA leads to a missing route. No trustworthy conversion denominator or
experiment assignment exists.

## Expected output

State the funnel stage and record the broken task path as observed friction.
Repair the route within the authorized source scope, preserve unrelated edits,
and verify the CTA through desktop and mobile previews. In the output contract,
distinguish `changed locally` and `verified locally` from `verified live`.
Measurement readiness remains incomplete. Recommend the smallest event-chain
verification before designing a lift test; do not forecast additional signups
from the broken-link repair. Read `pricing-and-urgency.md` before changing any
price display, guarantee, deadline, or seat-cap message.

## Failure case

The page source is unavailable or production cannot be inspected. Deliver a
literal fix proposal and an evidence-limited handoff, naming which action needs
access. An untrusted analytics export is not a reason to invent traffic or use
an industry benchmark as the baseline. If a test is proposed, leave its sample
calculation open until a real baseline and business-useful effect are supplied.

## Validation

Follow the CTA to the actual next step; inspect form completion, narrow screens,
text zoom, focus, and errors. Verify the correct route and no lost query/state.
Record exact files and checks. If experimenting, pre-register assignment,
exposure, metric denominator, guardrails, MDE, duration, sample, and SRM check
before any winner claim. Local success alone cannot establish a deployed fix.
