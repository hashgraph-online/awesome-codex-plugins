# Suede AI Product Marketing Skills: Worked Contract

This is a synthetic application scenario, not a client result or a required output filename. Adapt the values to the supplied evidence. The skill's existing output format and authority boundaries apply.

## Input

A repository README identifies a scheduling product for small clinics. An existing context file has a version and changelog. The requester changes the primary buyer from clinic owner to office manager but supplies no new testimonial.

## Expected output

Read the existing context, update only the audience/persona and affected positioning sections, preserve sourced proof, bump the document version, and add a dated changelog describing the buyer change. Keep verbatim customer quotes distinct from agent-drafted messaging and list unanswered questions.

## Missing input and recovery

If a legacy context file is found, identify the canonical-path migration instead of creating competing copies. If the codebase implies a capability but does not prove availability, record the supporting file and leave availability unresolved. Do not manufacture quotes or silently overwrite unrelated sections.

## Validation

Diff the saved context against its previous version. Confirm the version/changelog changed, unchanged proof stayed intact, and each factual addition has requester origin or a traceable source. Reopen the canonical file to verify the saved record is the one downstream skills will read.

## Detailed scope and routing

Suede AI product-marketing context: drafts and versions the shared .agents/product-marketing.md record of product, audience, ICP, personas, positioning against real alternatives, objections, switching forces, verbatim customer language, sourced proof, goals, and canonical entity facts (official names, one-line description, sameAs profiles, the buyer questions search engines and AI assistants should answer). Every other Suede marketing skill reads it first. Use when a project needs that shared record created, auto-drafted from a codebase, or updated. NOT FOR: writing a campaign (use suede-campaign-in-a-box), conducting new customer interviews (use suede-customer-research), debating a contested positioning bet (use suede-marketing-council), or publishing brand claims.
