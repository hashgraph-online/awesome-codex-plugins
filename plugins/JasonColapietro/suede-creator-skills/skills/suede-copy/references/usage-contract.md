# Worked contract: Suede AI Copy Skills

This is an illustrative application, not a claim of measured customer results.

## Input

Rewrite a landing-page hero for a scheduling tool. The brief provides calendar sync and a shared booking page; no customer results are supplied. The protected product name must remain byte-exact.

## Expected output

Return the recommended headline, one support sentence and one CTA, followed by clearly labeled alternatives and the 70-point score. Explain only material evidence gaps and the chosen voice. Keep calendar sync as a capability rather than inventing hours saved.

## Failure and validation

Compare the protected name before and after. Check that every number or outcome comes from the brief or a retrieved source. If the CTA destination is missing, supply the label and flag its target rather than invent a working link.
