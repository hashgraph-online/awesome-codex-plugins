# PRISMA 2020 checklist: working copy

Paraphrased summary of the 27 items of the PRISMA 2020 statement (Page et al., BMJ 2021;
372:n71, doi:10.1136/bmj.n71). Always check the official checklist at
https://www.prisma-statement.org before submission. Fill in the location column as you write.

| # | Section | Item (paraphrased) | Location |
|---|---|---|---|
| 1 | Title | Identify the report as a systematic review | |
| 2 | Abstract | Structured abstract per PRISMA 2020 for Abstracts | |
| 3 | Introduction: rationale | Rationale in the context of existing knowledge | |
| 4 | Introduction: objectives | Explicit objectives or questions | |
| 5 | Methods: eligibility | Inclusion/exclusion criteria and how studies were grouped for synthesis | |
| 6 | Methods: information sources | All databases, registers, websites, other sources, with dates last searched | |
| 7 | Methods: search strategy | Full search strategies for all databases/registers, including filters and limits | |
| 8 | Methods: selection process | Screening methods: number of reviewers, independence, automation tools | |
| 9 | Methods: data collection | Extraction methods: reviewers, independence, confirming data with authors, tools | |
| 10a | Methods: data items (outcomes) | Outcomes sought, and which results were collected | |
| 10b | Methods: data items (other) | Other variables (participants, interventions, funding), assumptions for missing info | |
| 11 | Methods: risk of bias | Tool(s) used, reviewers, independence | |
| 12 | Methods: effect measures | Effect measure per outcome (e.g. risk ratio, mean difference) | |
| 13a | Methods: synthesis eligibility | How studies were chosen for each synthesis | |
| 13b | Methods: data preparation | Handling of missing statistics, conversions | |
| 13c | Methods: tabulation/display | Methods to tabulate or visually display results | |
| 13d | Methods: synthesis methods | Methods and rationale; model, heterogeneity methods, software | |
| 13e | Methods: heterogeneity | Methods to explore causes of heterogeneity (subgroups, meta-regression) | |
| 13f | Methods: sensitivity | Sensitivity analyses | |
| 14 | Methods: reporting bias | Methods to assess risk of bias due to missing results | |
| 15 | Methods: certainty | Methods to assess certainty (e.g. GRADE) | |
| 16a | Results: study selection | Search and selection results, ideally with a flow diagram | |
| 16b | Results: excluded studies | Studies that seemed eligible but were excluded, and why | |
| 17 | Results: study characteristics | Cite and describe each included study | |
| 18 | Results: risk of bias | Risk of bias for each included study | |
| 19 | Results: individual studies | Per-study summary statistics and effect estimates with precision | |
| 20a | Results: synthesis characteristics | Characteristics and risk of bias of contributing studies | |
| 20b | Results: synthesis results | Results of each synthesis (estimate, CI, heterogeneity) | |
| 20c | Results: heterogeneity | Results of investigations of heterogeneity | |
| 20d | Results: sensitivity | Results of sensitivity analyses | |
| 21 | Results: reporting biases | Assessments of risk of bias due to missing results | |
| 22 | Results: certainty | Certainty of evidence for each outcome | |
| 23a | Discussion: interpretation | Interpretation in context of other evidence | |
| 23b | Discussion: limitations (evidence) | Limitations of the evidence included | |
| 23c | Discussion: limitations (process) | Limitations of the review processes | |
| 23d | Discussion: implications | Implications for practice, policy and research | |
| 24a | Other: registration | Registration name and number, or statement that it was not registered | |
| 24b | Other: protocol | Where the protocol can be accessed, or that none was prepared | |
| 24c | Other: amendments | Amendments to registration/protocol | |
| 25 | Other: support | Funding sources and role of funders | |
| 26 | Other: competing interests | Competing interests of review authors | |
| 27 | Other: availability | Availability of data, code, extraction forms and other materials | |
