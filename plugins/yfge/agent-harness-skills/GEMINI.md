# Agent Harness Skills For Gemini

This extension provides reusable skills for repository harness design.

Use `INDEX.md` to choose the right skill before answering repository harness questions. The skills live under `skills/<skill-name>/SKILL.md`: four core skills cover assessment and entrypoints, repository contracts and structural quality, validation surfaces, and runtime evidence; one optional governance skill covers work state and delivery policy.

Keep skill usage repo-neutral. Do not copy private environment assumptions, URLs, credentials, or project-specific workflow details into reusable guidance.
