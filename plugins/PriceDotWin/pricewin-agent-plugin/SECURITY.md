# Security policy

This repository contains no code: manifests, an MCP server declaration that
points at `https://mcp.price.win/mcp`, and a skill. Security issues are most
likely to concern that hosted server.

## Reporting a vulnerability

Email **support@price.win** with "Security" in the subject, or open a
[private security advisory](https://github.com/PriceDotWin/pricewin-agent-plugin/security/advisories/new)
on this repository. Please do not open a public issue for a vulnerability.

Include what you found, how to reproduce it, and what it lets an attacker do.
We aim to acknowledge reports within 3 business days and will tell you when a
fix is deployed.

## Supported versions

Only the latest release of this plugin, and the server currently deployed at
`mcp.price.win`, are supported.
