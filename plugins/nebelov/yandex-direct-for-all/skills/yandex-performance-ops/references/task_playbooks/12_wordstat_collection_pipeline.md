# Сбор Wordstat

Канонический порядок находится в ../../../yandex-direct-unified/references/keyword-collection-runbook.md. Использовать только Wordstat второго поколения: через Yandex Cloud (`mcp/yandex-wordstat`) или через XMLRiver (навык `xmlriver-serp-research`); путь выбирается в `scripts/collect_wordstat_wave.sh` параметром `--provider`. Старый программный интерфейс v1 не поддерживается.
