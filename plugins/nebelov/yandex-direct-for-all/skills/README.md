# Навыки модуля

Всегда начинать с yandex-direct-unified/SKILL.md.

Директ, спрос и выдача:
- yandex-wordstat — узкий справочник Wordstat v2 (Yandex Cloud);
- xmlriver-serp-research — выдача Яндекса и Google и Wordstat через XMLRiver, альтернатива Yandex Cloud;
- commercial-demand-research — оценка спроса;
- yandex-cloud-search-cost-control — контроль расходов платного поиска Yandex Cloud;
- direct-report-wizard-library — сохранённые отчёты в Мастере отчётов Директа;
- keysso-competitor-research — реклама конкурентов из Keys.so;
- serp-rank-verification — проверка позиций в выдаче.

CRM и продажи (подключаются, только если есть у клиента):
- bitrix24-crm-api — Битрикс24 как CRM;
- bitrix24-bi-reports — BI-отчёты в Битрикс24;
- amocrm-api-control — amoCRM; сверка работает и по CRM-выгрузке файлом;
- roistat-reports-api — Roistat.

Качество данных и отчётов:
- analytics-dashboard-integrity, structured-output-file-integrity, google-sheets-live-guard, work-status-reporting, client-communications-research.
