# Набор отчётов в Мастере отчётов Директа

Результат — в кабинете клиента в «Статистика → Мои отчёты» лежат отчёты `1. …` – `20. …`. В каждом есть поиск и РСЯ, расход, показы, клики, CTR, конверсии **отдельно по каждой бизнес-цели**, CR, CPA, ценность конверсий и ДРР. Каталог отчётов с группировками и периодами — в [references/report-catalog.md](references/report-catalog.md).

## Жёсткие правила

1. **Менять можно только отчёты.** Кампании, группы, объявления, ставки и цели не трогать.
2. **Для создания нового отчёта не нажимать «Сохранить настройки»:** эта кнопка обновляет открытый отчёт; новый создаётся только через «Сохранить в "Мои отчёты"». Намеренно обновлять существующий отчёт через «Сохранить настройки» можно при явном поручении изменить его настройки либо при исправлении подтверждённого дефекта отчёта, созданного в текущем пакете. Перед записью открыть канонический адрес без `state`/`inheritFrom`, подтвердить кабинет, название и точный набор меняемых полей; после сохранения заново открыть с сервера и сверить изменённые поля, цели, период и группировки. Не переносить это разрешение на посторонние существующие отчёты.
3. **Сначала проверь логин.** Открой `https://direct.yandex.ru/dna/grid/campaigns/` без `ulogin` и прочитай логин в левой колонке или в `ulogin=` итогового URL. Если Директ показывает «Доступ ограничен», значит активен чужой аккаунт Яндекса. Переключи его через аватар → список аккаунтов, если пользователь это разрешил, и после работы верни прежний аккаунт; иначе попроси пользователя переключить аккаунт и подожди. Учти: переключение меняет кабинет во **всех** вкладках браузера.
4. **Цели определяй по данным, не угадывай.** Через API: `campaigns.get` → `PriorityGoals` (Unified/TextCampaign) и цели Метрики `management/v1/counter/{id}/goals`. Разложи цели на **лид** (обращение, форма, Roistat-лид — по каждому сайту и счётчику), **квал-лид** и **продажу** (CRM «Заказ оплачен»). Сомнительное соответствие согласуй с пользователем.
5. **Ценность ≠ деньги.** Если цель стоит ключевой с ручной ценностью (`PriorityGoals.Items[].IsMetrikaSourceOfValue=NO`), столбец «Ценность конверсий» по ней равен конверсиям × заданной ценности. Реальная выручка бывает только у цели продажи с ценностью из Метрики или CRM. Предупреди пользователя об этом в отчёте-сводке.
6. **Не сдавать без проверки.** В конце выведи список «Мои отчёты» и сверь его с каталогом. Каждый отчёт открой и убедись, что на кнопке целей написано `Цели · <первая цель>, +N`.
7. **Расход с НДС или без — как решил пользователь.** По умолчанию включать «с НДС»: так расход совпадает со счетами. Выбранный вариант включить в каждом отчёте, сохранить и подтвердить значение после нового открытия с сервера. Временное включение без сохранения не считается готовой настройкой.

## Порядок работы

1. **База с целями (отчёт №1).** Статистика → Библиотека отчётов → «Элементы объявлений» (`/dna/reports/library/assets`). Дальше:
   - **Группировки и метрики**: добавь «№ объявления»; в метриках добавь «Ценность конверсий» (поиск по «конверс») и «ДРР (по ценности)» (поиск по «ДРР»).
   - **Цели**: в окне целей ищи каждую цель **по номеру** и ставь галочку в найденной строке.
   - **Настройки отображения** (там же, слева): «Конверсии» и «Ценность конверсий» переключи на «Отдельно по каждой цели».
   - **Период**: 30 дней, «Включая сегодня».
   - Сохрани через «Сохранить в "Мои отчёты"» с названием `1. Сочетания: заголовок + текст + картинка + видео`.
2. **Остальные отчёты делай из сохранённого**, тогда цели и метрики переносятся сами. Открой последний сохранённый отчёт, затем:
   - в «Группировки и метрики» нажми «Удалить всё» у группировок;
   - через поиск отметь нужные группировки из каталога, не забудь «Тип площадки»;
   - нажми «Применить»;
   - выставь период и детализацию над таблицей;
   - при необходимости отсортируй по «Расход»;
   - сохрани через иконку дискеты → «Сохранить в "Мои отчёты"» → название → «Сохранить».

   После сохранения откроется новый отчёт (`/dna/reports/my/rep/N/`). Следующий собирай уже от него.
3. **Названия:** `N. Срез (период)`. Имя клиента в название не добавляй, отчёты и так внутри его кабинета. Переименовать можно через «⋮» в шапке отчёта → «Переименовать отчёт».
4. **Проверка:** на `/dna/reports/my/` получи список ссылок `a[href*="/reports/my/rep/"]` и сверь его с каталогом.

## Особенности интерфейса

- **Быстрый выбор периода может выключить «Включая сегодня»** (например, у «30 дней»). После выбора или изменения периода заново проверь эту опцию перед сохранением; при повторном открытии сверь фактические начало и конец периода. Само название «30 дней» не доказывает включение сегодняшней даты.
- **Окно «Группировки и метрики» открывается с задержкой ~2–3 с.** Клики в первую секунду попадают в таблицу под ним и, например, включают «Месяц» или «Неделю» в детализации. После открытия жди и проверяй правую колонку «Группировки» до «Применить».
- **Первый клик по иконкам шапки после загрузки страницы часто теряется** (дискета, «⋮»): первый клик показывает подсказку, повторный открывает меню. Каждый раз проверяй меню снимком области; если меню не открылось, кликни ещё раз. Два клика подряд вслепую могут открыть и сразу закрыть меню.
- **Результаты поиска в окне группировок:** у одноуровневых групп пункт стоит на второй строке, у вложенных (Регионы → Местонахождение → Город) — на третьей. Перед кликом проверяй, какой пункт отмечен.
- **В окне целей** поиск по номеру показывает строку счётчика и строку цели; ставить галочку нужно на строке цели. Подсказку «Откройте через боковое меню…» можно не закрывать.
- **«Место клика»** (быстрые ссылки, заголовок, телефон) в этом отчёте **серое**: Директ не совмещает его с конверсиями по целям. Клики по быстрым ссылкам берутся из API (`ClickType` = SITELINK1..8).
- **Часа суток и дня недели как группировок нет.** Детализация бывает только по дням, неделям, месяцам, кварталам и годам. При детализации «По дням» в дате виден день недели («08.09, вт»). Часы брать из Метрики (`ym:s:hour`, `ym:s:dayOfWeek` с фильтром по источнику Директ).
- **В отчёте «Элементы объявлений»** у заголовков и текстов убраны кавычки и часть пунктуации. Изображение указано адресом `…/images/direct/<group>/<hash>` (последний сегмент — `AdImageHash` из API), «Идентификатор видео» совпадает с `CreativeId`. В CSV прочерк `-` означает «нет данных».

## Точная статистика по вариантам ЕПК (если нужна в своей платформе)

В API Директа нет статистики по отдельному заголовку или картинке. Есть она только в отчёте «Элементы объявлений». Выгрузи отчёт №1 через «Скачать → CSV». Строка CSV — это реально показанное сочетание: тип площадки, кампания, объявление, заголовок, текст, изображение, видео, конверсии по каждой цели и доход. Статистика элемента = сумма строк, где он участвовал. Сравнивать вариант честнее с другими вариантами **внутри тех же объявлений**, учитывая только строки, где этот тип элемента вообще показывался.

## Сдача пользователю

Таблица `№ / отчёт / какое решение помогает принять`. Обязательно укажи:
- период каждого отчёта;
- что реальные деньги показывает только «Ценность» цели продажи;
- чего в Директе нет и откуда это взять (часы, место клика).
