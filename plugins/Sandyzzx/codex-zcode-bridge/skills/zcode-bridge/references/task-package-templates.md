> Status: AUTHORITATIVE
> Last updated: 2026-10-24
> Last verified: 2026-10-29，仅静态核对独立功能候选的引用、授权与JSON主线边界；历史离线记录不代表本候选运行时验收。真实Worker、Host按需加载强制与token收益 NOT RUN。
> Verified against: master 73af9d60ff9bbcbbc1ae1d7b1f9b9fb9fca48bb0 + 本独立功能候选；来源74d4764和经审查的JSON文案。

派发时只读当前策略对应模板，替换方括号内容并删除无关条目；这是字段写作模板，不是可直接提交的完整工具参数。`task_id`、`workspace`、可选 `worktree_path`、预算与模型仍按 Skill 的准备与调用规则填写。`whole_task` / `staged` 不作为额外字段发送。**`auto` 同样不是 TaskPackage 字段或第三种执行模式**：Master 在明确的 Bridge 调用授权下，先根据任务选择下列模板之一；未获新任务调用授权时不得仅因选中 auto 而提交任务。

Ready Gate 确认信息充分及事项适用性，不要求每栏非空。五个数组须存在，可为空；无专属路径限制或无适用测试命令时直接使用 `[]`，在验收标准中给出验证方法或说明不适用原因。`worktree_path`、`model`、`timeout_ms` 可省略，沿用既有执行目录、模型和预算规则，不为填表虚构值。策略只在当前授权交付目标内继承；新独立目标重新判断，用户明确的会话级统一策略除外。

## whole_task：完整授权任务

```yaml
objective: "[完成一个连贯的授权工程任务，描述用户可观察的最终状态]"
requirements:
  - "[必须满足的行为、兼容性和已批准的合同/架构决定]"
  - "[明确的非目标、权限限制；未授权时不提交、推送或发布]"
  - "在本任务范围内自主调查、内部规划、实现、测试、修复与重测；局部可逆实现选择自行决定。"
  - "[本任务特有的升级边界或未决事项；阻塞相关工作，继续不依赖该决定的工作]"
allowed_paths: ["[需要专属限制时填写实际执行目录内的写入范围；无则用空数组]"]
forbidden_paths: ["[实际禁止创建、修改、删除的路径；无则用空数组]"]
acceptance_criteria:
  - "[完整任务的可检查行为：触发条件、预期结果和相关兼容性]"
  - "[所需端到端/回归证据和交付物，不能只写完成需求]"
test_commands: ["[仓库中已核实存在、适用且可执行的验证命令；无则用空数组]"]
context: |
  PROJECT DECISIONS: [必要的已批准决定与来源]
  CONSTRAINTS: [背景说明；强制约束已写入 requirements/路径字段]
  RELEVANT FILES: [相关文件路径及用途，不复制全部文档]
```

不要为常规实现选择添加等待确认点。完整交付后由 Master 独立审查；Worker 自报完成或局部测试通过不足以证明全部验收满足。

## staged：当前阶段的完整交付

```yaml
objective: "[整体任务中的当前阶段：一个可独立验收的成果及交付物]"
requirements:
  - "[已冻结决定、阶段前置输入及其已核实状态]"
  - "[当前阶段允许的工作和明确非目标，例如只研究、不实现、不改变公共合同]"
  - "本任务仅指当前阶段；自主安排阶段内部步骤并完成全部阶段交付。完成后停止并报告，不启动下一阶段。"
  - "[可自主决定的局部事项，以及必须提交 Master 的具体问题]"
  - "[尚未批准的后续方向不得自行选择；不依赖它的当前阶段工作可继续]"
allowed_paths: ["[需要专属限制时填写本阶段写入范围；无则用空数组，空数组不表示禁止写入]"]
forbidden_paths: ["[保护的源码、合同或其他路径；无则用空数组]"]
acceptance_criteria:
  - "[只针对当前阶段的可检查成果、必要验证和交接证据]"
  - "[列出阶段结果、仍待决定的问题及后续工作的前置条件，不把本阶段完成宣称为整体完成]"
test_commands: ["[本阶段适用的验证命令；无适用命令时用空数组并说明原因]"]
context: |
  PROJECT DECISIONS: [Master 已确定的阶段关系和必要决定]
  RELEVANT FILES: [当前阶段必要的文件与前置证据]
  OPEN DECISIONS — DO NOT CHOOSE: [尚待 Master 的后续决定；没有时省略]
```

只读调查应在 `requirements` 中明确“不创建、修改或删除任何文件”；若允许研究文档交付，则列出它的写入范围并保护实现文件。路径数组是任务指令，不是 OS 沙箱。重大未决项可以是研究阶段要提交的问题，不能是当前实现成立所必需却尚未提供的决定。

## 公共字段与续作

- 五个数组字段必须存在，可为空。不得把整个任务改写为一个放在 `context` 中的大段 Prompt；当前 Builder 只保留前 2,000 个 context 字符，强制约束必须放在不会截断的对应字段中。
- 不重复五字段 JSON 报告合同；Bridge 已注入报告与通用决策规则。将任务特有的验证证据写进验收标准，并区分实际运行、失败与 NOT RUN。
- 返工反馈只写独立审查发现的失败、证据和修正后的验收要求，保留原策略与授权范围。报告修复沿用 Skill 的仅修复报告规则。额度耗尽等强制停止条件优先，不因“完整交付”自行重试。
