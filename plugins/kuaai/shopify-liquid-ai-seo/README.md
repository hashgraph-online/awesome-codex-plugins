## What This Rule Enforces

- **Online Store 2.0 Best Practices**: Clean sections, blocks, and metafield architecture without static template bloat.
- **Product Schema JSON-LD**: Automatic generation of compliant `@type: "Product"` and `@type: "Offer"` structured data.
- **AI Crawler Whitelisting**: Ensures `robots.txt.liquid` allows `OAI-SearchBot`, `Claude-SearchBot`, `GrokBot`, and `PerplexityBot`.
- **Shoppable Blog Posts**: Guidelines for embedding interactive product cards with live inventory and pricing.
