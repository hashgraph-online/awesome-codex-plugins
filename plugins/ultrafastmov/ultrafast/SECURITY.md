# Security

Please report vulnerabilities privately to **security@ultrafast.mov** (or
through GitHub's private vulnerability reporting on this repository), not in
public issues. Include what is affected, how to reproduce it and the impact
you expect. We answer within three working days and will tell you when a
fix ships.

Documents can carry agent-written shaders and scripts and can reference
remote media, so issues in how `ultrafast serve` and `ultrafast-service`
bound GPU time, memory, file access and network fetches are in scope.
