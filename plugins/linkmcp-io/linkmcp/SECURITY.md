# Security policy

Report a security problem in the LinkMCP service, the MCP endpoint or this repository to **info@linkmcp.io** with "Security" in the subject. Include the steps to reproduce. Do not open a public issue for it.

We confirm each report and keep you informed until the problem is fixed.

This repository holds documentation and client configuration only. It contains no credentials. The MCP server signs in each user with OAuth 2.1 or the user's own access key.
