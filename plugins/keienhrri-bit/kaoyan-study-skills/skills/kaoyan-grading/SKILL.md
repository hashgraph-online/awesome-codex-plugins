# 交卷判分（kaoyan-grading）

一条可核验的批改流水线：**拍照 → 转录 → 人工确认 → 按评分点判分 → 独立复判 → 报告**。

原则：

- **标准解答、判分、错因、薄弱点和成稿都由主会话做。**外援只做两件事：转录照片、独立复判。复判只提意见，改不改分由主会话逐条定。
- **照片不进主会话的上下文。**贴进对话的图片每一轮都会被重新读一遍；交给转录者，主会话只读文字稿。
- **只派已经交卷的题。**学生还没做的卷，不派出去求解答。
- 下一步怎么练写成选项，由学生定。

开工先读工作区的 `kaoyan.yaml`：`inbox`（照片在哪）、`subjects`（成果放哪）、`roles.transcribe` 和 `roles.regrade`（谁来做）。没有配置文件就先转 `kaoyan-setup`。

## 步骤

| 步 | 谁 | 做什么 | 交什么 |
|---|---|---|---|
| 0 | 主会话 | 在收件夹里只挑最近这次交卷的图片（jpg、jpeg、png、heic，按修改时间取同一批），把文件名、张数、时间跨度列给学生确认；拿不准是哪张卷就问。照片**复制**到任务目录 `<科目>/C_试卷与批改/<日期>_<卷名>/img/pNN.<扩展名>`，找到题面文字稿存成 `exam.md` | 任务目录、`exam.md` |
| 1a | 转录者 | 一页一单，按 `references/transcribe-task.md` 转录，在后台跑 | 每页一份转录稿 |
| 1b | 主会话 | **转录在跑的时候写**：每题的标准解答、评分点、要记住的句子，一次写进 `solution.md`（格式见下）。有现成参考答案先用现成的，只补缺的。关键结果写一个 SymPy 小脚本核一遍 | `solution.md`、核对脚本 |
| 2 | 主会话 | 只读转录稿和公式核对表，不看整页照片。核对表里“把握：低”和〔?〕的地方**先问学生本人**，确认后再判；问不到才回看原图那一小块。按两种尺度判分（见下） | `grading.md` |
| 3 | 复判者 | 一单独立复判，按 `references/regrade-task.md`。只给题面、转录稿、评分点，**不给主会话的分数** | 两张分数表 + 问题清单 |
| 4 | 主会话 | 逐条决定采不采复判意见，写进 `grading.md` 末尾（采了哪条、为什么不采哪条）。补齐解析集：每题加“你的作答”（转录原话）、“错在哪一步”和分数行。写成绩报告。排版照 `kaoyan-report` | 解析集、报告 PDF |
| 5 | 脚本 | 同一个数（tiles、结论、表格）在全文一致，用脚本或 Grep 查，不再另派复核 | 一行结果 |
| 6 | 主会话 | 交付：PDF 路径加 3 行要点。学生要讲哪道转 `kaoyan-tutor`；要画图转 `physics-svg-tutor` | |
| 7 | 主会话 | 照片归档：把收件夹里**第 0 步确认过的那几张**移到任务目录的 `答卷照片/`，改名 `pNN_<卷名>.<原扩展名>`；按工作区 AGENTS.md 记变更。只动这几张，别的文件不碰 | 收件夹里没有这次的照片 |

### 谁来转录、谁来复判

看 `roles.transcribe`、`roles.regrade`：

- `subagent`：Claude Code 里用插件自带的 `transcriber`、`regrader` 子代理，一页一个子代理，可以并行。没有装这两个子代理时，用内置的 general-purpose 子代理，把 `references/` 里对应任务书的全文放进提示词，并写明图片路径。
- `codex`：用 Codex CLI 另起进程跑同一份任务书，例如 `codex exec -s read-only -o transcript_p01.md --image img/p01.jpg -- "$(cat task_p01.md)"`（`--image` 后面能跟多个文件，所以提示词放在 `--` 之后）。复判交给另一家模型最独立。
- `main`：只在没有任何外援时用。主会话读照片，读完就写转录稿，之后只看转录稿。

转录失败的页单独重派一次；再失败，主会话自己读那一页。复判 15 分钟没回来，就按主会话自己的判分往下走，在报告里不提复判。

### `solution.md` 的写法

- 每题用块：`::: sol`（标准解答）、`::: pts`（评分点，一行紧凑短句写完）、`::: mem`（要记住的句子）；简答题加 `::: key`（关键词）。
- 每问最后一行写 `**答**：…`，SymPy 脚本只核这些行；对不上的那问才回头重推。
- 一次写完整份，不一题一题零碎改。

### 两种尺度

- **正常**：按评分点给分，没写出来的式子不给，前面错了后面按错的数算对也不给。
- **宽松**：有一步对就给那一步；前面错了、后面按错的数算对的也给。

两种尺度的差，说明丢分有多少是“过程不全或连带错”，有多少是真正的知识缺口。

### 错因代号

默认用 `references/error-codes.md` 的六类。科目自己有代号表的，用科目的。

## 交付给学生的内容

1. **判分表**：题号、满分、正常和宽松得分、一句话说错在哪一步（引用转录稿原话）。
2. **错因统计**：各代号出现几次、扣了多少分。
3. **薄弱点最多 3 条**：每条指向具体知识点或题型，写清依据是哪几题。
4. **下一步 2–3 个选项**，由学生选。

## 不做

- 不把转录稿当判分以外的依据；看不清的先问本人，不猜着判。
- 不替学生改错题本、不自动出新卷；同类练习学生要了才出。
- 不为一张卷开多轮互审；复判只做一次。
- 判分或讲题被学生纠错时，转 `kaoyan-retro`。

完整走一遍的合成例子在仓库的 `examples/synthetic-mechanics/`。
