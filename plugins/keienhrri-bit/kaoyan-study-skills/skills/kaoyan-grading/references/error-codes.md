# 默认错因代号

科目有自己的代号表时用科目的。每道题最多记两个代号，按扣分多的排前面。

| 代号 | 含义 | 例子 |
|---|---|---|
| C1 | 概念、受力或方向判断错 | 上滑时摩擦力方向画反；把矢量当标量加 |
| C2 | 公式记错或用错条件 | 非弹性碰撞套了弹性碰撞的公式 |
| C3 | 计算错 | 代数化简、数值代入、单位换算算错 |
| C4 | 漏写依据或步骤不全 | 直接写结论公式，不列守恒式 |
| C5 | 审题 | 求的是位移写成路程；漏看“光滑” |
| C6 | 单位、符号或规范表述 | 结果没带单位；没说明方向 |

判定时注意：

- C1 和 C3 要分清：方向对、只是数算错是 C3；方向错导致后面全错是 C1。
- “提示后才写出来”的不算错因，但也不算独立完成，在学习日志里记“提示后作答”。
