# 每日资料包（kaoyan-daily-pack）

学法：先把这一专题要背的句子读一遍，再一次做完这一组题，统一批改；全部专题做完，再用没做过的题和前一天的错题做一次小测试。**主会话只做准备**，当天的带学交给一个聊天 AI（学生上传资料包、粘贴提示词），主会话不在这里逐题讲。

资料来源必须是学生自己合法拥有的讲义和题册。这个 skill 不提供任何讲义或题目原文。

## 先定当天学什么

- 学生的每日安排一般在科目目录里（如 `<科目>/每日安排.md`，每天一项：讲义范围、题号范围）。不确定今天学到哪就问，不自己顺延。
- 练习用当天的奇数题；偶数题和前一天的错题、猜对题进小测试。
- 前一天的错题、猜对题**只从学生前一天的学习记录里取**（收件夹里导出的聊天记录，或已归档的学习记录），不从旧报告里继承。

## 步骤

| 步 | 谁 | 做什么 | 产出 |
|---|---|---|---|
| 1 抽题 | 主会话 | 从学生的题册文字稿里按题号切出当天的题，题干和选项原样保留 | 题目清单 |
| 2 核答案 | 主会话 | 对照题册的答案页或解析逐题核对。**OCR 出来的答案字母常错，不能直接用** | `answers.json`，如 `{"单1":"C","多3":"ABD"}` |
| 3 考点卡 | 子代理或便宜的模型（可选） | 答案核完以后才派。每题一张卡：考点、讲义怎么说（引一句原文）、正确项为什么对、干扰项为什么错；奇数题那单末尾按专题分组 | 考点卡原稿 |
| 4 核卡 | 主会话 | 卡里的答案和第 2 步不一致的，以第 2 步为准；“讲义怎么说”的引文用 `scripts/tag_quotes.py` 回讲义文字核对 | 核过的考点卡 |
| 5 拼包 | 主会话 | 照 `references/pack-structure.md` 拼成一份 Markdown | `<日期>_<科目>_资料包.md` |
| 6 提示词 | 主会话 | 照 `references/prompt-template.md` 填变量。正文不超过 1200 字，平实，没有感叹号和语气词 | `<日期>_<科目>_提示词.md` |
| 7 记录 | 主会话 | 按工作区 AGENTS.md 记新建文件；把两个文件的路径给学生 | |

学生还没做的题，不派出去求答案；考点卡在第 2 步答案核完后才派。

## 要背的句子

从考点卡“讲义怎么说”的引文里取，再用脚本回讲义核：

```bash
python <本 skill 目录>/scripts/tag_quotes.py --lecture <讲义文字.md> --sentences <句子清单.md>
```

在讲义里逐字找得到的（忽略空白和全半角标点差异）标【讲义原话】，找不到的标【转述】。【转述】的句子要么换成讲义原话，要么保留标记，不能说成原话。

## 容易出错的地方

- 单选和多选题号分开编时，“单43”和“多43”是两道题，任务书里写明各自的页码。
- OCR 会认错题号、漏标点，页眉页脚和章节标题会混进题干；切题后逐题看一眼题干开头和结尾。
- 考点卡里不要出现“材料 A / B”这种只有出卡模型自己懂的指代，换成“题目 / 解析 / 讲义”。
- 提示词不要退回“一道一道出”“先讲一遍知识点”：句子只列不讲，一组题一次发完。
- 猜对不算掌握，成绩表里单列。
- 日期安排是建议，不写“应完成”，不催进度。

合成的小例子见 `references/example-pack.md`。
