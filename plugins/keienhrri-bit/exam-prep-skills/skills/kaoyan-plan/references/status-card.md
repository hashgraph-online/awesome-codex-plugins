# 状态卡怎么更新

状态卡（`kaoyan.yaml` 的 `records.status`）是阶段复盘唯一要读的文件。它应该一页看完，数字照各科记录原样抄。

## 每科一行

| 列 | 写什么 | 从哪来 |
|---|---|---|
| 当前阶段 | 一轮 / 二轮 / 冲刺，加正在学的章节或专题 | 各科学习日志最后一节 |
| 本周完成 | 学完了哪些单元、做了几套题 | 每日进度本周的行 |
| 最近一次测验 | 日期、得分 / 满分、用时 | `C_试卷与批改/` 最新那次的判分表（正常尺度） |
| 最大的缺口 | 一句话，指向具体知识点或题型 | 最近两三次的错因统计 |
| 状态 | 稳 / 一般 / 落后 | 和上一个复盘日定的达标标准比 |

## 规矩

- 只写记录里有的。没有测验就写“无”，不估分。
- “讲过、看过解析”不算完成；学习证据按 AGENTS.md 的五类。
- 记录之间对不上（比如每日进度说做完了，学习日志里没有），写进“互相矛盾或缺的数据”，不自己挑一个。
- 更新时整份重写，不在旧卡后面追加；旧卡如需保留，复制到 `99_整理记录/隔离区/<日期>/`。
