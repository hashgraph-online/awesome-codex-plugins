# 资料包结构

一份 Markdown，五部分，顺序固定。聊天 AI 只按这份资料带学，所以答案和讲解依据都要写在里面。

## 一、说明和规则

- 今天学什么（一句话）、共几个专题、几道练习题、几批小测试。
- 答案以第四部分为准；标【讲义原话】的句子已逐字核对，标【转述】的不是原话。
- 单选和多选题号是否分开编。

## 二、练习（按专题）

每个专题：

```markdown
### 专题 1：<专题名>

**要背的句子**
1. 【讲义原话】……
2. 【转述】……

**题目**
单1. 题干……
A. …　B. …　C. …　D. …
多3. 题干……（多选）
A. …　B. …　C. …　D. …
```

## 三、小测试

- 第 1 批：前一天的错题和猜对题，打乱顺序（没有就省掉这一批）。
- 后几批：当天的偶数题，打乱后均分，每批 8–12 题。
- 题目前面不写专题名。打乱用固定的种子（如当天日期），方便复现。

## 四、教师参考

- 答案速查表：题号 → 答案。
- 考点卡：每题一张，考点、讲义怎么说、正确项为什么对、干扰项为什么错。

## 五、讲义原文

当天讲义范围的文字稿，供聊天 AI 回查。
