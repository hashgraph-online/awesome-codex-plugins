# 内联 SVG 图示设计与几何质量规范

## 为什么用 SVG

SVG 是标准矢量图格式，适合精确控制直线、箭头、角度弧线、虚像、焦平面、坐标与文字标签。它可随尺寸缩放，支持源文件编辑和几何验算。与写实图片生成器不同，它不依赖模型“猜测”哪条光线连到哪里。

**注意：** 是否能够在聊天中原位渲染 SVG 取决于具体客户端。不要向不支持该功能的平台输出无效的特殊标签。支持时用内联矢量展示；不支持时提供标准 `.svg` 预览或清晰字符图，不要假装界面已经显示。

## 视觉语法

| 物理含义 | 图形语法 | 例子 |
|---|---|---|
| 真实传播光线 | 连续实线 + 明确箭头 | `S → N → P` |
| 反向延长线、虚像构造线 | 细虚线 + 虚像标签 | `N ⋯ S′` |
| 法线、光轴、参考平面 | 灰色虚线 | 法线 `N`、光轴 `O` |
| 界面/反射镜 | 适度加粗线段或半透明板 | `G`, `G′` |
| 透镜与焦平面 | 透镜轮廓+垂直焦平面线 | `L`, `F′`, `P` |
| 辅助距离与角度 | 双箭头、短弧线、文字 | `d`, `h`, `r`, `i`, `f`, `ρ` |
| 观察结果 | 与光路图分开的屏幕正视图 | 等倾圆环/直条纹 |

## 最重要的 12 个图形审查项

1. **物理参照对象**：角 i 从哪条线量？r 是膜内还是膜外？必须直接标在图上。
2. **真实路径合法**：反射角等于入射角；折射遵守折射率关系；透镜会聚只在适用模型内绘制。
3. **连贯箭头**：每条光从光源到观察点一路有连续的物理方向，不允许在同一反射点反常拐折。
4. **镜面虚像**：虚像与物点对镜面对称；反射光向后延长才能通过虚像，虚像不能误画为真的光路。
5. **平行光含义**：在平行平面板透射出的相邻光束方向相同，但**出射点可以不同**。
6. **光程比较面**：在图和文字中说明“同一观察点/同一波面”，不要直接把斜线往返长度叫光程差。
7. **中心与屏**：标注“物面/膜面/观察屏/后焦平面”，别混成一个平面。
8. **假定与近似**：小角、薄透镜、平行板、等振幅或无损高反射模型都在图注或公式前说明。
9. **图形不按比例**：若为了教学夸大镜面夹角或空气膜厚度，图注明说，并避免图上某个“夹角”暗示错误趋势。
10. **文字易读**：中文尽量采用系统字体，字号可读、不要文字压线，移动端保持视图宽度灵活。
11. **对比一致**：一组图的红/绿/蓝语义前后一致；必要时附最小图例，不为审美频繁换色。
12. **单图单问题**：同一图至多表现一个关键转换，真实图和等效图有混淆风险时拆成两张。

## “一图四问”验证法

每画完一张图，先自己在图上指出：
- 元件到底是什么？
- 哪束是真实光、哪个只是辅助线？
- 被比较的两束最终在**哪**相遇？
- 图中哪段几何直接支持即将出现的公式？

任何一个答不出，就先修图。

## 推荐 SVG 源文件组织

- `viewBox` 表示统一的坐标系统，输出宽度可伸缩。
- `path`、`line`、`circle`、`text` 足以完成绝大多数仪器草图。
- 颜色之外必须还有箭头/实虚线区分，避免纯靠颜色辨识。
- 添加 `<title>` 与 `<desc>` 作为无障碍文字解释（适用于标准 SVG 文件）。
- 不嵌入外部脚本、第三方字体、远端图像或不必要的复杂动画。
- 保存标准 SVG 附件时可用 XML 解析器校验，再用矢量渲染器导出 PNG 目检。

## 三种模板适用情形

- `assets/angle-to-focal-plane.svg`：学生不懂等倾光束如何在后焦平面排列。
- `assets/fabry-perot-multiple-beams.svg`：学生不懂两镜之间多次往返、相邻束多两次反射。
- `assets/wiener-standing-wave.svg`：学生不懂驻波波腹平面与倾斜感光板的交线。

这些是**可编辑教学示意**，不是复制教材原图或精密工程设计图；用户还需要看实际装置时应以教材光路为准。

## 多图顺序建议

① 装置总览（实物结构） → ② 两束光追踪（真实路径） → ③ 等效光路（必要才画） → ④ 在焦平面/屏上的观察结果。

如果学习问题只涉及“某一条光的法线是谁”，请只画一个界面和一条法线，不要一次展示四张。
