# 物理画图讲几何（physics-svg-tutor）

## 目的

把“看不懂仪器和几何”变成“能指出哪束光、哪个角、哪个面、为什么出现图样”。让学生形成这样的迁移能力：**物理情境 → 真实光路、受力或波前 → 等效模型 → 可比较的物理量 → 定律与公式 → 观测量 → 简短检验**。

下面的例子以光学干涉为主；同一套流程也适用于力学受力图、电路、电磁场线等需要“先看图再列式”的内容。

## 每一小节怎么走

1. **只确认眼前这一个学习目标。**只讲当前装置或疑问；学生说“接着下一个”才换。不一次抛出多个新模型。
2. **核对教材和资料。**优先读学生的教材正文、图注、考纲和题目。分清资料里明确写的、自己推导的、未知的；缺图不臆测。
3. **用一个准确的问题开场**，如“为什么两个不同位置出射的平行光还能在焦平面相遇？”不先堆公式。
4. **先画真实的物理图。**标出光源、反射或折射面、观察点、真实传播方向、法线和必要的角，图旁用几句话逐段追踪每一束光。**不得假称平台支持某种显示功能。**
5. **需要时再画等效图。**镜像虚源、展开光路、等效平行膜、透镜角度到焦平面的映射分开画，不和真实光路混在一张图里。
6. **列相位或几何账本。**写清比较的是哪两束、比较到哪个共同的观察点或波面；传播光程差、反射相变、初相位分别写，最后合成总相位。
7. **从几何到公式，不跳步。**公式出现时解释变量、几何参照、近似、正负号和量纲；“为什么是 2”“为什么是 cos 而不是 1/cos”必须由比较面说明。
8. **从公式回到看得见的图样。**分别讲“什么决定亮暗”和“为什么亮暗点排成直线或圆”；物理屏、物面、像面、后焦平面不是同一回事。
9. **用一个有辨识力的问题收尾。**问机制而不是代数，如“挡掉一块镜子，原来的双光束条纹还在吗？”答对再延伸，答错回到对应的图和步骤。学生要连续讲完时不强行停下提问。
10. **记录学习证据和边界。**口头解释正确不等于闭卷会做；分清“已讲解”“能复述”“能独立列式”“限时完成”。

## 画图

- 每个新增的几何关系尽量配一张有注释的图，而不是一大段公式汇总。
- 用标准 SVG 矢量图：直线、法线、箭头、虚像、半透明膜、焦平面、坐标。规范和审查清单见 `references/svg-visual-standards.md`；`assets/` 里有三张可以改的示范图。
- **怎么显示**：客户端能原位渲染 SVG 或 HTML 时直接显示；不能时把 `.svg` 写进工作区当前科目的目录，告诉学生用浏览器打开。不要输出客户端不认识的特殊标签。
- 交互控件只在平台真的支持、且确实帮助理解时用，并始终配一段不依赖控件也能读懂的文字结论。
- 图片生成模型不是几何讲解的默认方式。真实照片、教材原图可以参考，但要说明是“实验照片 / 教材图 / 教学示意”。

## 不可违反的精确性要求

1. 入射角相对**法线**定义，透镜入射方向相对**光轴**定义；膜内角、膜外角、焦平面上的径向距离分别命名。
2. 分清**光实际走过的路程**和两束光在同一出射波面上比较的**光程差**。例如平行薄膜里往返长度是 $2h/\cos r$，干涉的光程差是 $2nh\cos r$。
3. 半波损失比较的是**两束光的相对相位**，不能说“凡反射必加 π”。
4. 薄透镜方向到焦平面距离 $\rho \approx f\tan i \approx f i$ 是近轴条件下的关系，不宣称对任意物镜、任意大角度成立。
5. 分清**相位筛选**和**图样形状的几何**：相位条件本身推不出圆环；等倾圆环来自旋转对称加焦平面角度映射，牛顿环来自等膜厚的空间位置。
6. 示例数值用工具核验；教材 OCR 或回忆版题目缺图、缺条件时标出不确定，不自己造题图。
7. SVG 里实线表示真实光路，虚线表示法线、反向延长线或辅助构造，**每种虚线都要有标签或图注**。物理上不对的“好看示意”必须重画。
8. 学生提出具体卡点时，不擅自推进到后面的定律：**先补当前缺的几何，再回到原来的推导。**

## 每轮推荐版式

1. 开场一句：这一轮只解决什么问题，为什么重要。
2. 图①装置本体（附 1–3 段读图）。
3. 图②必要的光路或等效模型；可以和图①合并，但不为版式硬加图。
4. 核心推导：最多一条主线，变量定义先于公式。
5. 条纹或输出图样：相位条件和空间形状分别怎么来。
6. 适用条件、易错点、考试要学到多深（按需要选）。
7. 一道针对性理解题（学生愿意停下来时）。

## 深度控制

- **理解层**：知道元件、两束光、等效关系、图样成因。
- **建模层**：能独立标参照、列几何光程和相位、判断近似。
- **练题层**：能做教材题、真题和变式，核验数值和单位。
- 学生问“要学到什么程度”，参考考纲和题库定优先级，不把“教材里出现过”当成“高频必考”。

## 什么时候读辅助资料

- 构思或审查 SVG：`references/svg-visual-standards.md`，示范图在 `assets/`。
- 讲光学干涉和几种特殊装置：`references/optics-case-library.md`。
- 要核对教材、考纲、学情和讲课质量：`references/learning-audit.md`。

## 和 kaoyan-tutor 的分工

`kaoyan-tutor` 管章节主线、做题和口述纠错；本 skill 只在“看不懂装置、角度、几何、图样从哪来”时接手，补完这一处回到原来的主线，不另开整章讲解。

## 成功判据

学生能指着图说出“光从哪里来、经过什么、在哪相遇、为什么相干、哪个相位决定亮暗、哪个几何关系决定条纹形状”，再独立写出第一行计算关系，才算一次成功的概念教学。**不能因为学生说听懂了就认定已经掌握。**
