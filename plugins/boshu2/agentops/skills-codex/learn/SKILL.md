# Learn

Learn is an optional, off-path consumer of bounded native episodes, verdicts,
checks, BD handoff facts, Git changes and user corrections. It is the compatible
entrypoint for [Memory's mine/learn operation](../memory/references/mine-learn.md).
Read that reference when invoked; do not require Learn to finish ordinary work.

Resolve the caller-selected source set, access, question, consumer and separate
budget. Include failures, corrections, harmful and null outcomes. Return narrow
supported observations or no-change; one incident is not a general rule. Search
existing topic pages and prefer a qualified update or removal over a file per
session. Missing provenance remains a disclosed gap; do not delete unique proof.

Use only public or already-cleared inputs in this lean path. It does not enforce
native restricted-source access or authorize automatic transcript reads. Drafts
stay in caller-selected protected external non-Git storage. Exact fresh factual
support and destination-disclosure review precede any Git object/index/stash or
import under [curation](../memory/references/curate.md). Learn alone does not
admit a rule or change a product verdict. Preserve legacy `.agents/` evidence;
no blind TTL or deletion. The optional [OKF profile](references/okf-page-profile.md)
checks structure only.

## Prompt

```text
Use Learn on these already-cleared episodes and corrections within this separate
budget. Find a narrow supported improvement to the existing parser topic page,
or return no-change. Preserve failures and limits; no new policy or benefit claim.
```

## It's working if

An observation cites evidence and its coverage, names applicability, action,
support, limits and invalidation, and survives a counterexample check. A single
incident stays narrow; curation may simplify or remove a rule. Saved pages are
not benefit: only later work can demonstrate useful reuse.
