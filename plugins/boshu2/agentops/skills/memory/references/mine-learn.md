# Capture a note

Draft a note only when the person asks for one, from the incident, correction,
episode or source they name. A request to finish a change does not request a
note. Bulk or unattended extraction of lessons from session history is not
part of Memory.
[Memory's access rules](../SKILL.md#access-storage-and-honest-limits) apply.

Settle the question, the sources, the permitted destination and who will check
the draft before reading. Read the named sources as evidence, respecting each
source's authority: native or CASS episodes, BD handoff facts, Git changes,
checks, verdicts and corrections. A useful map may record where the actual
contract, implementation and tests live; link their owners without copying
policy or tracker status. Do not read private history merely to populate a page.
Look first at what failed, what was corrected and what caused harm, and include
success or null cases that could contradict the explanation. Repeated reviews of
one objective are not independent incidents. Disclose the sources read, unread
or denied ranges and unresolved causes. CASS search hits locate evidence; they
do not prove complete episode coverage.

For each candidate, connect an observed failure or correction to its cause, a
narrow action that could prevent it, and a counterexample or limit. One incident
may justify a supported local observation; a generalized rule needs the
independent exemplars and holdout of
[Research's pattern mode](../../research/SKILL.md#pattern-evidence), which
decides whether recurring evidence warrants one. When an investigation ruled
out a plausible explanation, keep what observation ruled it out and what new
evidence would justify reopening it. Distinguish a disproven explanation from an
untested or inconclusive attempt so later work can avoid a dead end without
treating uncertainty as fact.
Do not manufacture a rule to fill a quota or convert all failures into gates.
A supported searchable reference need not become policy.

Search the caller-selected project `.context/` or external topic pages before
proposing an update. Portable cleared project-page reads use ordinary filesystem
tools without BD or AO. Prefer a correction, qualification, consolidation or
removal to an extra lesson file. If nothing supported would change future
action, return no-change. Broken support is a reason to qualify a claim and
preserve the gap, not erase unique evidence or pretend the source was read.

Return candidates inline, each with applicability, action, support, limits and
invalidation, for the person to check. Write a draft artifact only to storage
outside Git that the caller named; no Git objects or imports before exact
content, paths and metadata pass review under Memory rule 4, even for public
source maps. Capture does not create a destination or import private material
automatically. Then use [curation](curate.md) if selected and authorized.
Capture alone cannot admit a claim, change a completed verdict or start another
product experiment.

Saving proves no benefit (Memory rule 5); repeated model agreement and closed
work prove none either. Learning may remove rules; no-change is a valid result.
