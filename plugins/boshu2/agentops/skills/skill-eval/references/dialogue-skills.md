# Dialogue skills

Some skills reach their result through the caller's answers: an interview, a
brainstorm or a clarifying loop. A single-turn case shows only the opening
move, such as whether the first reply asks one question. It cannot show needs
the dialogue missed or questions it should never have asked.

- **Keep it away from real people.** Do not run the skill in a session where
  its questions reach the caller or anyone else. Their answers are not a fixed
  case, and the run interrupts their work.
- **Answer with a stand-in user.** Use an authorized runner that answers each
  turn as a stand-in with a goal, needs it reveals only when the right question
  reaches it, and a point past which more questions are overkill. Give both
  arms the same stand-ins and cases.
- **Grade blind against fixed criteria.** Fix the criteria before the run and
  grade transcripts without knowing the arm, so one grade shows both missed
  needs and needless questions. Calibrate this grader like any other.
- **Know the stand-in's bias.** A stand-in that defers every choice up front
  shows the skill's recommendations but overstates how far scope grows.

With no such runner, list the dialogue under **Not proven**; do not build one
to rescue the measurement.
