# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.0.x | Supported |

Security fixes land on the `main` branch of this repository. The current plugin manifest version is 1.0.5.

## Reporting a vulnerability

Email info@dropthehassle.com. That is the only contact address, the same one on the [privacy statement](https://dropthehassle.com/privacy) and the [support page](https://dropthehassle.com/support).

Include what you found, how to reproduce it, and the version you tested. Report it by email rather than in a public issue, so it can be fixed before it is widely known.
