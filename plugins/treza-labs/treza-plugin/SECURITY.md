# Security

To report a security issue in this plugin or in Treza's hosted MCP server, email hello@trezalabs.com with the details and steps to reproduce. Please do not open a public issue for security reports.

We reply within two business days and will tell you when a fix ships.

This plugin holds no credentials of its own. It connects to `https://www.trezalabs.com/api/mcp`, and access is scoped to the account that signs in.
