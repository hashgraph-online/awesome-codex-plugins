# Security policy

## Supported code

Security fixes target the current default branch of this repository. Older
versions should be updated; fixes are not guaranteed to be backported.

## Reporting a vulnerability

Contact [Oleg Gaidukov](https://www.linkedin.com/in/ahaidukof/) privately before
publishing sensitive details. Include the affected version or commit, steps to
reproduce with synthetic data, the expected and actual behavior, and the impact.
Do not include real resumes, candidate records, credentials or private job
application materials.

For ordinary bugs that can be described safely, use
[GitHub issues](https://github.com/olegvg/resume-tailor-plugin/issues).
Do not attach sensitive evidence to a public issue.

## Scope

Reports can cover the bundled instructions, unsafe handling of candidate data,
plugin packaging and release tooling. Host authentication, model processing and
optional export tools are maintained by their respective providers. The plugin
has no backend or telemetry; see [PRIVACY.md](PRIVACY.md) for its data boundaries.
