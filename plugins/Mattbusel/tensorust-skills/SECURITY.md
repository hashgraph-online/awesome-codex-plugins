# Security policy

## Supported versions

Only the latest release of this plugin is supported. The plugin contains skills (Markdown) and an MCP configuration that points at `https://shop.tensorust.com/api/mcp`; it runs no code on your machine.

## Reporting a vulnerability

Please report security problems privately through GitHub's private vulnerability reporting: https://github.com/Mattbusel/tensorust-skills/security/advisories/new

This covers the plugin files in this repository and the hosted MCP endpoint it configures (for example a skill that could make an agent leak data, or a problem with the endpoint's responses). Please do not open a public issue for a vulnerability.

You will get a reply within 3 business days. Confirmed issues are fixed in a new release and credited in the advisory unless you ask otherwise.
