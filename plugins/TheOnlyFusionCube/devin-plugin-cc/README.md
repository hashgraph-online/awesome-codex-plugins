# devin (plugin)

Devin inside Claude Code and Codex: read-only AI code reviews, adversarial reviews, delegated coding tasks, Fusion sidekick workflows, and cloud handoffs to app.devin.ai.

Slash commands (`/devin:*`), lifecycle hooks, the `devin-rescue` subagent, and the shared `devin-companion.mjs` runtime live here.

See the [repository README](https://github.com/TheOnlyFusionCube/devin-plugin-cc) for installation and the full command surface.
