# Reporting a security issue

Email [hello@bringyour.ai](mailto:hello@bringyour.ai) with the subject "BringYour security report" to report a suspected vulnerability privately. Include the affected component and version, the impact, and steps to reproduce with synthetic data where possible.

Do not include API keys, license keys, credentials, private configuration files, or customer data. Remove personal paths and other identifying details from examples. Do not post vulnerability details in public GitHub issues.

This contact covers this repository's plugin metadata and migration-auditor skill, the BringYour CLI, and the service at bringyour.ai. For ordinary setup or migration help, use [BringYour support](https://bringyour.ai/support).
