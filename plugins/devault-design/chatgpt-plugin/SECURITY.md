# Security policy

## Reporting a vulnerability

Please email **founder@devault.design** with a description of the issue and the steps to reproduce it. Do not open a
public issue or pull request for a vulnerability.

This repository holds no code: it is a manifest, three skills and an icon. What runs is Devault's MCP server at
`https://devault.design/api/mcp` and its OAuth server, and reports about either are welcome at the same address.
[devault.design/security](https://devault.design/security) describes how the service is protected.

## Supported versions

Only the latest release of the plugin is supported. The server is the same for every version, so a fix there reaches
everyone at once.
