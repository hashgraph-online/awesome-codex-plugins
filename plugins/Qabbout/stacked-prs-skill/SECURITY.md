# Security Policy

This policy covers the skill instructions, bundled scripts, and plugin packaging in this repository.

## Supported Versions

Security fixes target the latest release and the current `main` branch. Older releases do not receive separate security backports.

## Reporting a Vulnerability

Report vulnerabilities privately to [Abdulrahman Qabbout](mailto:abdulrahman.qabbout@gmail.com). Do not post vulnerability details in public GitHub issues.

Include:

- The affected release version or commit SHA.
- Steps to reproduce the issue or a minimal proof of concept.
- The potential impact and relevant environment details.

Remove credentials, tokens, and personal data from examples. Please allow time to investigate and coordinate a fix before public disclosure.
