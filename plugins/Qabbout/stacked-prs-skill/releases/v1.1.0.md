# v1.1.0

Adds native Claude Code and Codex plugin installation alongside the standalone skill.

- Claude Code: plugin manifest and marketplace catalog, with `/stacked-prs:stacked-prs` as the skill entrypoint.
- Codex: plugin manifest and marketplace catalog, with the skill available through `/skills`.
- Both plugins expose the existing root skill, references, and executable helpers without duplicating the skill.
- Skill and plugin metadata share version `1.1.0`. Standalone install and source download instructions pin `v1.1.0`.
- Packaging checks cover marketplace resolution, shared versions, the single skill entrypoint, and README release pins.

## Install

Claude Code:

```sh
claude plugin marketplace add Qabbout/stacked-prs-skill
claude plugin install stacked-prs@qabbout-stacked-prs
```

Codex:

```sh
codex plugin marketplace add Qabbout/stacked-prs-skill
codex plugin add stacked-prs@qabbout-stacked-prs
```

Standalone skill:

```sh
npx skills@1.7.2 add https://github.com/Qabbout/stacked-prs-skill/tree/v1.1.0 --skill stacked-prs
```

Native marketplaces follow the default branch. The standalone command installs the tagged release. No helper behavior changes are included in this release.
