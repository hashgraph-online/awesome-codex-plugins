# v1.1.1

Strengthens the skill's instructions for preserving upstream review fixes when a cutover carries older copies of lower slices.

- Records copied dependencies separately from PR targets, with pinned starting points, source tips, and original-to-copy commit mappings. Fix propagation now includes these dependencies and their transitive dependents.
- Requires reconciliation before landing: compare stale copied content, newer upstream changes, and intentional cutover edits at hunk level, including changes that merge without conflicts. Preserve documentation and test intent alongside behavior.
- Adds a porting-log template recording each relevant upstream change's outcome, current destination, and actual verification. Covers new base callers outside the reference diff and checks for unresolved references to removed types/APIs.
- Replaces blanket child-wins conflict guidance and commit-subject ownership guesses with patch inspection and explicit provenance. Missing provenance, unresolved preservation, and required validation not run remain readiness blockers; moving base or cutover tips require refreshed evidence.
- Updates splitting, maintenance, landing, recovery, stack-map, and PR-description guidance, and adds reproducible read-only agent scenarios.

The skill and native Claude Code/Codex plugin manifests share version `1.1.1`. Helper scripts are unchanged. Existing authorization boundaries for builds, pushes, and host writes still apply.

## Install

Claude Code:

```sh
claude plugin marketplace add Qabbout/stacked-prs-skill
claude plugin install stacked-prs@qabbout-stacked-prs
```

Codex:

```sh
codex plugin marketplace add Qabbout/stacked-prs-skill
codex plugin add stacked-prs@qabbout-stacked-prs
```

Standalone skill:

```sh
npx skills@1.7.2 add https://github.com/Qabbout/stacked-prs-skill/tree/v1.1.1 --skill stacked-prs
```

Native marketplaces follow the default branch. The standalone command installs the tagged release.
