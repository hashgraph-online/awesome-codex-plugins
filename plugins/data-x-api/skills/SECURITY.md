# Security

Report a vulnerability in these skills, the `dataxapi` command line or the DataXAPI service to support@dataxapi.com, with "Security" in the subject. Do not open a public issue for it. We reply within one working day.

These skills are Markdown instructions only: no scripts, binaries, dependencies or keys. Their example commands send requests only to `api.dataxapi.com`, read the key from `DATAXAPI_API_KEY` and tell the agent never to print it, log it or put it in an address. The MCP entry in `.mcp.json` points to the hosted server at `https://api.dataxapi.com/mcp` and runs no local command.
