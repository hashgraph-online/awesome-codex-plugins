# Graphify

Official Graphify plugin package for Codex and ChatGPT. It connects to Graphify's hosted MCP server at `https://api.graphify.com/mcp` with OAuth. The hosted MCP serves the code graph, Memory and `review_status` for repositories you have indexed in Graphify.

Wiki lives in the Graphify app at [app.graphify.com](https://app.graphify.com). It is not served over MCP.

Install and usage notes are in the [repository README](../../README.md) and the [Codex guide](https://docs.graphify.com/integrations/codex).
