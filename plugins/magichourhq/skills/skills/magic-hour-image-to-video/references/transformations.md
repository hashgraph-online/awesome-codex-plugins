# Direct the moment

Use this for a personal transformation, impossible scene, camera reveal or short character moment. Start with the user's actual reference and taste; these structures are optional creative choices, not a mandatory preset list.

| Desired result                     | Prepare the still                                                               | Animate the change                                                                 |
| ---------------------------------- | ------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| Alternate world                    | Edit the surroundings, wardrobe or style while protecting the intended identity | Let the person react to one readable environmental event                           |
| Cinematic reveal                   | Establish foreground/background depth and enough canvas for the reveal          | Choose one camera move that reveals something already designed in the scene        |
| A portrait comes alive             | Keep a clear face, readable gaze and intentional light                          | Specify a look, expression or gesture with an end state                            |
| Transformation between appearances | Prepare both source and destination when the selected model supports end frames | Describe a coherent transition; inspect identity and geometry through the middle   |
| Character performance              | Use a compatible character reference and actual motion footage                  | Prefer Character Replace's animate mode when the supplied performance must survive |

An ordinary portrait is not automatically a suitable start for a sweeping orbit, full-body dance or unseen costume reveal. Reframe/edit first when the required body or surroundings are missing. A major camera move reveals unseen features; decide whether invention is acceptable.

Keep the subject recognizable during the payoff. Avoid putting the primary effect over the face unless that is the requested transformation. One action plus a small reaction can read more clearly than simultaneous dancing, camera orbit, costume change and exploding scenery. This is a directing choice, not a claim about universal engagement.

Use an accepted start/end pair only with a live-supported model and interval. The two endpoints do not prove the transition works; inspect every visible phase. Do not describe a hard cut, crossfade or face dissolve as a completed continuous morph. For a loop, compare final and opening position, lighting and sound before promising a seamless join.

If identity drifts, return to the original reference and reduce competing appearance changes. If the intended movement fails, retain the still and revise the motion before paying for a different still. If the action depends on a precise performance, use source footage. Preserve accepted motion when only caption, soundtrack or crop changes.
