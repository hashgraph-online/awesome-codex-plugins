# Turn accepted footage into new placements

Use this when a customer already has a master and wants a shorter cut, vertical version, new headline or visual restyle. First decide which changes need generation.

> Turn my approved product video into a square ad and a vertical version with this exact headline. Keep the product visible and the full spoken sentence. Reuse the footage; choose the layout and save both clean and final exports.

## Reuse what already works

| Change                    | Work required                                                                  | What must be rechecked                                     |
| ------------------------- | ------------------------------------------------------------------------------ | ---------------------------------------------------------- |
| New headline, logo or CTA | Recompose exact text/original assets                                           | Spelling, contrast, clipping and timing                    |
| New aspect ratio          | Inspect the full motion path; crop if safe or use a permitted contained layout | Subject, gestures, copy and overlays throughout            |
| Shorter cut               | Choose source intervals around the actual narrative/action                     | Complete actions, speech, transition and ending            |
| Different music           | Use an authorized track and align it to the picture                            | Dialogue intelligibility, clipping and track ending        |
| New scene appearance      | Generative video edit from the original interval                               | Identity, hands, contact, action timing and retained audio |
| Different spoken words    | Approved new audio and the lip-sync route if a speaker is visible              | Pronunciation, duration and mouth timing                   |

## Write a small edit plan

Use the existing project brief. Map each requested output to source file, source in/out points, destination canvas, crop/media region, exact copy and intended soundtrack. Inspect the source to choose those values; never invent timecodes from a filename. Preserve the clean master and save derivatives separately.

A centered crop can fail when a face or product moves. Review the whole path and every cut. Use actual tracking capability if present; otherwise propose a contained layout when permitted. Full-bleed and contained layouts are different deliverables. Do not stretch or silently substitute one.

When generating a restyle, keep a single coherent source interval inside current model limits. State the visual change separately from the action and camera that must survive. Return to the original if the edit changes a required action; copying the original audio back does not fix changed picture timing.

## Finish once picture timing is settled

Apply captions to the final cut, not the earlier master. Verify actual dimensions, duration, frame rate, audio and file format against the destination. Inspect full playback, all text and the final word; a successful encode is only a file check.

Deliver final placements, the clean master and the small edit plan. Retain exact copy in an editable form. A later crop or offer change should reuse these accepted assets. **Evidence:** the [AURORA export recipe](https://github.com/magichourhq/skills/tree/main/examples/aurora-finished) demonstrates one deterministic composition; generative video-editing quality and platform acceptance remain unverified there.
