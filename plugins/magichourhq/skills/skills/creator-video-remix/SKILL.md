# Creator video remix with Magic Hour

Use the user's actual reference, taste and audience. Extract why the format reads quickly, then create an original version with a different subject, world, action or payoff. Do not default to product photography, generic UGC or a claimed viral formula.

## Read the reference as a sequence

Inspect the supplied video or example before proposing a direction. Record only the structure needed to make the new piece:

- first-frame hook and what becomes understandable in the first two seconds
- subject, framing, camera, action and visual change
- shot boundaries and approximate timing
- sound, dialogue, music accents and silence
- payoff, final readable state and whether it truly loops

Separate reusable structure from protected identity, trademarks, exact copy and distinctive authored material. Keep the user's supplied or authorized media. If trend freshness matters and research is requested, use dated sources and label engagement evidence separately from creative opinion.

## Choose one original treatment

Recommend one direction that preserves the effective rhythm while giving it a Magic Hour-specific transformation. Examples include putting the user into an impossible scene, transferring a performance to their character, recasting a supplied clip, or building a controlled still that changes over time.

Use Text-to-Video when appearance can vary. Use Face Swap when the source body and performance should remain. Use Character Replace for a whole-character performance. For a new scene with a recognizable person or character, edit or create and inspect the start frame before Image-to-Video. Use Video Editor only for a requested change to accepted footage.

Write a compact shot plan with the opening, one action, payoff and end state. A five-second shot should not carry several unrelated events. For multiple shots, reuse accepted identity/style references and assemble only reviewed clips.
