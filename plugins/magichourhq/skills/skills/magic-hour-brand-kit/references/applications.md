# Applications and export decisions

Read this when a brand kit includes multiple placements or production files.

| Deliverable            | Source to preserve                               | Finish and inspect                                                                                         |
| ---------------------- | ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| Logo                   | Original vector paths and exact wordmark         | Editable SVG; transparent PNG exports if requested; no embedded bitmap passed off as vector                |
| Social or ad set       | Accepted product/character image and exact copy  | Separate correctly sized files; keep text editable; inspect each at phone size                             |
| Presentation           | Existing deck theme, real logo, approved message | Editable PPTX when a slide tool is available; inspect exported slides, font substitution and text overflow |
| Packaging              | Supplied dieline and verified product/legal text | Artwork on the actual dieline, with printer requirements; a perspective mockup alone is not print artwork  |
| Brand guide            | The project's canonical brand brief              | Readable PDF or HTML with actual rules and source links; render every page                                 |
| Merchandise or signage | Production dimensions, fabrication limits        | Design source and scaled preview; label generated mockups as simulations                                   |

Choose image references by purpose: product identity, logo master and visual treatment are different inputs. Tell the editor which one controls each decision. Repeatedly editing yesterday's generated composite can accumulate drift; return to the accepted source for each application.

For a new identity, separate selection from implementation. If choices are delegated, explain the selected direction in one sentence and complete it. If the user wants options, make the options visibly distinct within budget; do not create a dozen near-duplicates or require approval after every export.

Use only substantiated claims. A fictional example can demonstrate typography and placement using invented copy clearly labeled as fictional; a customer artifact cannot invent awards, certifications, ingredients, testimonials or measured results.

Keep editable source and distribution export together. A PDF may be the right review copy, while SVG, HTML or PPTX is the revision source. Do not call a flattened image editable because it was placed on a slide. If a requested export tool is unavailable, identify the missing capability and provide the usable formats that were actually produced.
