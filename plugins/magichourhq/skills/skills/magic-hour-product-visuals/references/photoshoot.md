# A product photoshoot from one reference

Use this when a customer wants catalog, lifestyle, detail or campaign images of the same product. Read the source and choose the treatment from the destination; the customer should not have to select an API mode.

> Make a clean listing photo and a warm kitchen lifestyle image of this coffee bag. Keep the actual packaging, label and proportions. Choose the lighting. Save separate images I can use in my store, within my budget.

## Choose the treatment

| Use             | Direct the image                                                                      | Check before delivery                                                                                      |
| --------------- | ------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Catalog         | Full silhouette, neutral background, soft contact shadow; retain the source viewpoint | Label, seams, cap and edges match; no floating product                                                     |
| Lifestyle       | One plausible setting and use cue; product remains the focal point                    | Scale, contact and reflections are believable; no invented performance claim                               |
| Detail          | A source-supported close view of texture, closure or controls                         | Do not invent stitching, ingredients or hidden mechanisms; insufficient source detail needs a better photo |
| Website hero    | Put the product opposite the actual copy region; restrained background contrast       | Complete subject, useful copy space and enough detail at display size                                      |
| Product in hand | Use a suitable reference and a simple grip with limited occlusion                     | Finger count, contact, scale and readable protected details; do not imply an endorsement                   |
| Coordinated set | Keep the reference, viewpoint family, lighting direction and palette consistent       | Separate files; identity checked against the original in every image                                       |

## Direct and finish the shoot

Inspect the reference before describing material or color. Select one lighting idea: soft side light for shape, broad diffuse light for packaging readability, or a controlled edge light for translucent material. Avoid combining incompatible camera angles or lighting schemes. A polished environment cannot compensate for an inaccurate product.

With a source, use AI Image Editor. Begin with the requested setting and framing, followed by the few protected details that matter. Start from the same source for each materially different scene. Choose a supported model and resolution that can show the actual label; a cheap composition preview is not final fidelity evidence.

Inspect the first result before expanding a requested set. If the label or shape changes, return to the original and narrow the edit. If only headline placement fails, compose exact copy separately. Do not repeatedly regenerate the product to force text coordinates.

Deliver named individual files, with the accepted source and remaining limitations. Use a licensed original logo when needed. A fictional product example does not validate another customer's packaging: compare against their source.

**Evidence:** [AURORA's five editing attempts](https://github.com/magichourhq/skills/tree/main/examples/aurora-edits) include a successful square catalog edit and failed ratio/placement attempts. Lifestyle, detail and in-hand treatments here are workflow guidance, not published quality benchmarks.
