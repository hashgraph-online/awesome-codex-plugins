# From a recognizable input to a finished remix

Read this when the user asks for a transformation, a shareable scene, or help recreating a visual format with their own material. The general media skill remains the entry point; do not require the user to choose a technical tool first.

## Find the part worth keeping

Identify the user's attachment, the desired change and the recognizable anchor: a face, performance, character, place, voice or visual setup. Recommend one treatment consistent with their brief when creative decisions are delegated. Use their actual taste and sources; do not default every request to a product ad, photoreal portrait, dramatic camera move or a trend.

If the user references a video, inspect it before promising to recreate it. Extract its structure—opening, action, reveal, framing, timing, sound and ending—without copying an unrelated person's identity or suggesting the original was made with Magic Hour. If current trend research is requested, inspect dated public examples and distinguish observed engagement from promotional claims. A popular effect name is not proof that a new output will spread. If browsing is unavailable, work from the supplied reference and disclose that freshness is unchecked.

## Route by the thing that changes

| Keep                                    | Change                                   | Route                                                        |
| --------------------------------------- | ---------------------------------------- | ------------------------------------------------------------ |
| Person or character in a still          | World, outfit or appearance, then motion | AI Image Editor when needed → inspect still → Image-to-Video |
| Existing performance and body           | Face                                     | Video Face Swap; map the intended cast                       |
| Existing performance                    | Whole character                          | Character Replace in the appropriate replace/animate mode    |
| Existing clip's action                  | Setting, materials or rendering style    | AI Video Editor; inspect action and identity drift           |
| Portrait                                | Speech or reaction                       | Talking Photo using measured, accepted audio                 |
| Speaking video                          | Words or language                        | Lip Sync using supplied/accepted speech                      |
| An original idea with flexible identity | Entire scene                             | Text-to-Video                                                |
| Music                                   | Supporting visual sequence               | Read [music and performance](music.md)                       |

The tools and lifecycle are listed in `SKILL.md`; each installed focused skill adds its own quality decisions. These routes are instructions, not a claim that every combination has passed output validation.

## Make the payoff visible

Keep the recognizable subject readable in the opening and let the transformation resolve. A short clip can use one strong reveal. A longer story needs deliberate beats; extend only when there is another useful beat, not to pad runtime. Choose motion for the brief: stillness, a reaction, a physical performance and a camera reveal solve different jobs.

For a supplied identity, accept the still before buying animation. Prefer editing the reference over describing a replacement person in text. If the original already fits, animate it directly. Design the final canvas before generation; preserve the face and action throughout the eventual crop.

Honor existing budget and delegated choices. Present the finished media, not an approval request at every stage. Ask only for missing inputs, a consequential creative ambiguity or spending beyond authorization. If a source is required, explain exactly which file supplies the identity or performance.

## Deliver something the next request can reuse

Finish the requested cut, sound and captions using available tools; retain a clean master. Watch the full result, listen when audio matters and report any unavailable review. Do not promise a compositor, music generator or platform publisher merely because the web app has related features.

Save the accepted source, prompt, project ID, audio, exact copy and edit decisions in the existing project. “Use my other photo,” “change the ending,” or “make the next episode” should reuse everything unaffected. If only captions or framing change, compose the accepted media instead of regenerating it. Never publish or send the result just because it was requested to be shareable.
