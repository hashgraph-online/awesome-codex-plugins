# Reporting a vulnerability

Report suspected vulnerabilities in these skills or plugin configuration privately to [support@magichour.ai](mailto:support@magichour.ai). Do not publish sensitive details in a public GitHub issue.

Include the affected skill or file, repository commit or plugin version, a description of the issue, and redacted reproduction steps. Never include API keys, access tokens, private media, or customer data. Do not run paid generations or access another person's account to reproduce an issue.
