# Security policy

Report vulnerabilities in this plugin or in Worktable privately, through
[GitHub private vulnerability reporting](https://github.com/worktable/worktable-dev/security/advisories/new)
or by email to **security@worktable.dev**. Do not report them in public issues.

The full policy, including what to include in a report, is in
[worktable-dev](https://github.com/worktable/worktable-dev/blob/main/SECURITY.md).
