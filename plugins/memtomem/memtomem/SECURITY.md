# Security Policy

This directory is the memtomem plugin for Codex CLI. It follows the security
policy of the memtomem repository:
<https://github.com/memtomem/memtomem/blob/main/SECURITY.md>.

## Reporting a vulnerability

Report it privately through a
[GitHub security advisory](https://github.com/memtomem/memtomem/security/advisories/new).
Do not open a public issue.

## Supported versions

The repository's security policy, linked above, lists the supported versions.
