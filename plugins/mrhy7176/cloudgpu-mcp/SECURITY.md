# Security Policy

## Supported versions

Only the latest published release is supported. Older releases are not.

| Version | Supported |
| --- | --- |
| Latest published npm release | Yes |
| Older releases | No |

Check the current published version on [npm](https://www.npmjs.com/package/cloudgpu-mcp). A repository branch or package manifest is not proof of publication; feature availability also depends on the deployed backend capabilities.

## Reporting a vulnerability

Report suspected vulnerabilities privately. Do not open a public GitHub issue for a security report.

- [GitHub Security Advisories](https://github.com/cloudgpu-app/cloudgpu-mcp/security/advisories/new) on this repository
- Email: yang@cloudgpu.app

Include the affected version, what you observed, and how to reproduce it if you can. This project does not offer a bug bounty and does not promise a response time.
