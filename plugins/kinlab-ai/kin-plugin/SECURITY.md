# Security

Please report a security problem in Kin, in this repository or in the approvals hook to [security@kinlab.ai](mailto:security@kinlab.ai), not in a public issue.

Tell us what you found, how to reproduce it and what it could affect. We'll reply, work on a fix with you and let you know when it's out.

This repository holds no server code. Kin itself runs at `https://app.kinlab.ai/mcp`, and reports about it go to the same address.
