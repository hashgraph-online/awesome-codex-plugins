# Agent Session Lineage

Browse indexed Codex and Claude Code sessions and view recorded lineage from your local Möbius vault. The Windows x64 preview uses `mobius-connect.exe` on your `PATH`. Install the executable, initialize the vault, and add the session directories you choose. [Windows setup](https://github.com/TardisBooo/agent-session-lineage#install-the-codex-plugin-on-windows) · [Preview release](https://github.com/TardisBooo/agent-session-lineage/releases/tag/v0.1.0)
