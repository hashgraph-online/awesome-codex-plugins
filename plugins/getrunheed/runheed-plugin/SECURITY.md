# Security policy

## Reporting a vulnerability

Email **hello@greatwork.company** with "Security" in the subject line. Include the affected component (this plugin's files, the MCP server at `https://runheed.com/api/mcp`, or the runheed.com website), steps to reproduce, and any proof of concept. Please don't open a public GitHub issue for security problems.

We will confirm receipt and keep you posted until the issue is fixed. Please give us a reasonable window to fix the problem before disclosing it publicly.

## Scope

- This repository: plugin manifests, skills and MCP configuration.
- The hosted Runheed service at runheed.com, including OAuth sign-in and the MCP endpoint.

This repository contains no keys or secrets. MCP clients sign in with OAuth 2.1.

More detail: https://runheed.com/privacy
