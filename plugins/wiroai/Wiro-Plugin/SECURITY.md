# Security policy

## Scope

This policy covers the files in this repository (the plugin manifests, agent skills and slash commands) and the hosted Wiro MCP server they connect to, `https://mcp.wiro.ai/v1`. No keys or secrets are stored here. Clients sign in through the Wiro sign-in page in the browser, and an API key, if you use one instead, stays in your client's own settings.

## Reporting a vulnerability

Email [support@wiro.ai](mailto:support@wiro.ai) with "Security" in the subject line. Describe what you found, how to reproduce it and the plugin version or commit you used. Please don't report a security problem in a public issue.

## Supported versions

Fixes go into the latest release. Every release is listed in [CHANGELOG.md](./CHANGELOG.md).
