# Security

Report a security problem to hello@agentdrives.com. Please don't open a public issue for it.

The AgentDrives MCP server at `https://agentdrives.com/api/mcp` is read-only and needs no key. It returns the public record and takes no account data, files or credentials.

This repository only packages configuration: plugin manifests, the server address and a skill file. It holds no code that runs on your machine and no secrets.
