# Macro evidence

Discover catalogue definitions before selecting series. Keep FXMacroData's documented terminology, currency codes, indicator slugs, units and payload metadata. Tool schemas determine available inputs and scope.

Prefer the keyless public USD catalogue, recent indicator history and release calendar for USD questions. Respect the public history window. Other tools and older history are optional and can require access. Present an access failure without asking for a key in chat or trying another URL with embedded credentials.

Use the plugin's commands for a structured brief, release review, currency comparison or broader research question. Retain source links, periods and timing qualifications in the output. Mark interpretation separately from observations; forecasts, scenario results and revised values must remain distinguishable.

Use returned data only. Preserve empty or unavailable results. Never create an observation, source, exact release time, forecast or coverage promise to complete a table. Reference rates and research outputs do not establish executable prices or future performance.

The host may expose more tools than the reviewed inventory. Consult live schemas rather than improvising parameters. Never issue a health check before every normal call; use `ping` only when needed to investigate connectivity.
