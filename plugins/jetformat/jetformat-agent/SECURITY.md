# Security

This repository contains a skill (instructions) only. It has no MCP server, no network calls, and no install-time scripts; the agent runs the `jetformat` CLI that the user installed.

To report a vulnerability in this plugin or in the Jetformat CLI, use [private vulnerability reporting](https://github.com/jetformat/jetformat-agent/security/advisories/new) on this repository. Please do not open a public issue.
