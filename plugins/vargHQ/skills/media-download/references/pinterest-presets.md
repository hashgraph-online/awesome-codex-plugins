# Pinterest moodboard presets

Ready-made search query sets for collecting visual references. Pass each query to `pinterest.sh`. Each query gets its own folder under `pinterest/Search/`.

```bash
S=<skill dir>/scripts/pinterest.sh
$S -n 8 -o refs "product photography white background studio" "luxury product flatlay photography"
```
