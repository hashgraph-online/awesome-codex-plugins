# transition-craft demo: four transitions chained

The preview video for the `transition-craft` skill: a 13.8 s HyperFrames film (1920x1080, 30 fps) that chains four of
the skill's transitions across five shots, each peak landing on a 120 BPM grid (one beat = 0.5 s). It is silent.

| Time (s) | Scene file | Preset | What happens |
|---|---|---|---|
| 0.0 – 4.0 | `compositions/droste.html` | `droste-recursive-zoom.monitor-push` | Push 3 levels into a desk monitor that shows the same room; the third screen is the next shot and lands at 4.0 |
| 4.0 – 7.0 | `compositions/shake.html` | `shake-distort-cut.bass-hit` | Hop, push with lens bulge, hard cut one frame before the beat at 5.5, mirrored landing with a decaying shake |
| 7.0 – 10.2 | `compositions/tiles.html` | `tile-flip-mosaic.impact-center` | On the beat at 8.0 the frame breaks into 12x7 lit tiles that flip outward from the centre |
| 10.2 – 13.8 | `compositions/bokeh.html` | `bokeh-light-spot.warm-night` | The harbour lights bloom into warm 7-blade bokeh, cut under maximum blur on the beat at 11.5, the sea resolves |

Each scene ends on exactly the frame the next one starts with, so the seams between scene files are invisible. A
small label in the bottom-left corner names the preset (JetBrains Mono, 17 px = 1.6 % of frame height, 60 % opacity).

## Values used

All values come from `assets/presets/*.json` and the "Timing and numbers" section of each reference:

- **Droste:** k = 4 (screen 480x270 = 1/4 of the frame), 3 levels pushed, scale = k^e with e tweened (never the
  scale), e eased power2.in 0.3–0.9 s, linear 0.9–3.2 s, expo.out 3.2–4.0 s (segment sizes solved so the speed is
  continuous), transform origin at the screen centre (the fixed point), glass glare 8 % screen-blended per level,
  zoom blur only above 0.5 levels/s and never on the landing frame.
- **Shake:** hop 4 f (1 → 1.04, y −1.2 %), push 6 f 1.04 → 1.22 power3.in, bulge k1 0 → 0.35 and back to 0 within
  6 f, cut 1 frame before the beat, landing 1.18 → 1.0 over 0.6 s expo.out, shake 48 px / 10 Hz / decay 6 / y ratio
  0.8 / ±2°, RGB kick 8 px for 2 frames, 3x3 mirrored edge fill, shutter 270° with 6 samples (samples never straddle
  the cut, so the cut frame is all A or all B).
- **Tile flip:** grid [7, 12], origin [0.5, 0.5], wave 0.8 s power2.inOut, ±20 % seeded jitter, flip 0.42 s
  (0.30 s power3.inOut to 183°, 0.12 s settle to 180°), one shared perspective of 1400 px on the grid parent, z lift
  45 px, 3 px gutters only while a tile is between ~10° and ~170°, 2-frame RGB kick and a 6-frame micro-shake on the
  hit. The whole wave ends 1.38 s after the impact (limit 1.4 s).
- **Bokeh:** blur in 0.40 s power2.in, cut at 0.43 s, resolve 0.57 s expo.out, base blur sigma 36 px (3.3 % of
  frame height), discs 14–22 % of frame height, 24 discs on A, 7 sides, roundness 0.3, 15 % #FFB86B tint, +10 % rim,
  screen blend, disc sets cross-faded over the 4 frames around the cut. Disc positions are the brightest points of
  each shot (`assets/shots/highlights.json`).

## Deviations

- **Tile edge light halved.** The preset's `edge_light_peak_brightness` 1.8 clips the bright desert tiles to white;
  the demo applies half of it (1.4) following the reference's own rule [41], "if it looks like a filter, halve the
  light". See `lightScale` in `compositions/tiles.html`.
- **Droste render depth.** The preset says render 7 levels; the demo renders 3 rooms plus the landing shot, because
  the innermost screen is replaced by the next shot (deeper levels would never be seen).
- **Droste zoom blur.** With a 3-level push in 4 s the cruise speed is 1.1 levels/s, so the radial blur peaks near
  4 px instead of the 8–12 px reached at 2 levels/s.
- **Tile flip hold.** The preset holds A for 1.6 s before the hit; here the scene holds 1.0 s, but the same shot has
  already been on screen since the shake cut, so A is visible for about 2.5 s before the impact.
- **Bokeh B side** uses 15 discs from the sun and its glitter path instead of 24, because the morning sea has fewer
  separate highlights than the harbour.

## Footage and credits

No footage. All five shots are vector illustrations generated by `tools/gen-shots.ts` (seeded, so they are the same
on every run): an edit-suite room, dusk ridges, noon dunes, a harbour city at night and a morning sea. No real
places, people or brands. Font: JetBrains Mono (OFL), bundled with HyperFrames.

## Run it

```bash
# from this folder; HyperFrames needs Node 22 and ffmpeg
bun tools/gen-shots.ts                         # only if you change the shots
npx --yes hyperframes@0.8.206 check
npx --yes hyperframes@0.8.206 preview          # Studio preview
npx --yes hyperframes@0.8.206 render --fps 30 --crf 20 --output transition-craft.mp4
```

If you change the shots, copy the new bright points from `assets/shots/highlights.json` into `HL_A` / `HL_B` in
`compositions/bokeh.html` (the render never fetches files at runtime).
