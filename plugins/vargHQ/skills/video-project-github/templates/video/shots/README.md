# Shots

One folder per shot, numbered in tens: `sh010/`, `sh020/`. A shot added later between them is `sh015/`.

`shot.md` holds the prompt word for word, the camera, the references used, and one line `approved: takes/sh010_t03.mp4`.
Takes are never overwritten. When a take is approved, copy it into the edit project (`edit/assets/sh010.mp4`).
