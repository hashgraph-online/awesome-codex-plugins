# Example: Vesna and her umbrella (LAST BUS)

The worked example behind the skill, made on 2026-11-03 for the LAST BUS moodboard
(`video-moodboard/examples/last-bus/`). Everything here was generated on varg with Nano Banana 2.1
(5 credits per image), Gemini 3.8 Flash TTS (1 credit per take) and Kling 4.0.

| File | What it is |

| `look.md` | The look block, copied from the LAST BUS moodboard |
| `board.md` | The cast board shown for approval, with the open checks the blind judges found |
