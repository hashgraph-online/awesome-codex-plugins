# Security Policy

This plugin is part of [RepoPilot](https://github.com/MykytaStel/repopilot).
Its hooks run the local `repopilot` CLI and `git`; it sends no source code
anywhere, calls no AI provider, and sends no telemetry.

## Supported Versions

Security fixes are provided for the latest published minor release.

| Version | Supported |
|---|---|
| Latest `0.x` minor | Yes |
| Older minors | No |

## Reporting a Vulnerability

Please do not open a public issue. Report it privately through
[GitHub Security Advisories](https://github.com/MykytaStel/repopilot/security/advisories/new)
on the main repository, with the affected version, steps to reproduce, the
expected impact, and a suggested fix if known.

Expect an initial acknowledgement within seven days and a status update at
least every fourteen days while the report is open. Disclosure timing is
coordinated after a fix and release are available. The full policy is in the
main repository's [SECURITY.md](https://github.com/MykytaStel/repopilot/blob/main/SECURITY.md).
