# Security

This repository contains only manifests and Markdown skills. It has no code,
dependencies or credentials. The plugin connects to one hosted MCP server,
https://svatlas.io/mcp, which signs users in with OAuth 2.1 (dynamic client registration and
PKCE). It never asks for an API key.

Report a vulnerability in the plugin or the service privately to
support@getrush.ai. Do not open a public issue for it.
