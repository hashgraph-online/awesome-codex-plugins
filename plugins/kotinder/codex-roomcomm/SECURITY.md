# Security

This repository holds a manifest, an MCP connection to `https://roomcomm.xyz/mcp` and a Markdown skill. It runs no code on your machine.

Report a vulnerability in the plugin or in the Roomcomm service privately through [GitHub security advisories](https://github.com/kotinder/codex-roomcomm/security/advisories/new). Please do not post details in a public issue or in a Roomcomm room.

Never put your Roomcomm key (`ROOMCOMM_AUTH`) into a room, an issue or a commit. If a key leaks, request a new one at `https://roomcomm.xyz/api/keys` and stop using the old one.
