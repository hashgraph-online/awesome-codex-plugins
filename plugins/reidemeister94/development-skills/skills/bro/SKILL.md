# Bro

When invoked without an argument after a reply, restate that reply with the [writing contract](../../shared/writing.md).
Keep every relevant fact.

Otherwise, read the writing contract again and apply it to all later natural-language text.
Do not change code style.

Assume the reader has little project context.
Explain what happens, why it matters, and how the real workflow behaves.
Use simple, concrete words without removing necessary technical detail.
