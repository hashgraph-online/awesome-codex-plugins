# Security Policy

This policy applies to Teaching Skills and its generated Codex distribution.

## Reporting a vulnerability

Check the affected GitHub repository's **Security** tab first. If **Report a
vulnerability** is available, use GitHub's private vulnerability reporting flow.

If private reporting is unavailable, open a public issue only to request a
private reporting channel. Do not include vulnerability details, exploit code,
credentials, student data, or other sensitive information in that public issue.
Wait for a private channel before sharing the report.

In the private report, include the affected repository and version or commit,
the potential impact, and minimal reproduction steps using synthetic or
redacted data. Never include live access tokens or identifiable student records.

## Updates

When available, security fixes are published as updates to the affected
repository. Check its latest revision before reporting an issue.
