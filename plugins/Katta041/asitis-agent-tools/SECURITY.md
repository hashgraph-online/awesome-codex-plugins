# Security policy

This plugin ships the AsItIs MCP server and CLI from the same repository, so it shares the repository's policy: [SECURITY.md](https://github.com/Katta041/asitis-agent-tools/blob/main/SECURITY.md).

To report a vulnerability, use GitHub's private reporting: [report a vulnerability](https://github.com/Katta041/asitis-agent-tools/security/advisories/new). Please don't open a public issue.

Only the latest released version gets security fixes.
