# Security Policy

## Scope

This project contains Markdown instructions, JSON and YAML manifests, an icon, and one shell script that builds a zip file. It has no MCP server, no hooks, and no network access. It does not collect or send data.

## Supported Versions

Only the latest release gets fixes.

## Report a Problem

Do not open a public issue for a security problem.

Use GitHub private vulnerability reporting:

https://github.com/msoltanov/Proxmox-Technical-Writing-Style-Skill/security/advisories/new

Include the file, the problem, and the steps to reproduce it. You get a reply in 7 days.
