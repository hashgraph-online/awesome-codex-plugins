# Skills directory

Each direct child directory is a portable Agent Skills package. See the root [contribution guide](../CONTRIBUTING.md) for authoring, import, certification, and registry workflows.

A portable skill does not own host MCP setup. Users choose how their client connects to MCP servers, and a skill works with the native tools, resources, and prompts that client exposes. See the [plugin installation guide](../docs/plugin-installation.md) and [MCP configuration guide](../docs/mcp-configuration.md).
