# A+ Content & Brand Story Guide

A+ Content (formerly Enhanced Brand Content / EBC) and Brand Story sit on the same detail page but are separate content surfaces with separate APIs and separate rules.

Load this whenever doing any A+ work — drafting, auditing, suggesting modules, fixing rejections, or planning a content strategy.

---

## Eligibility

- **Brand Registry required** for all A+ Content and Brand Story.
- **Basic A+ Content** — any Professional seller enrolled in Brand Registry, or vendor with approved vendor account, or Emerging Brand owner with registered trademark.
- **Premium A+ Content** — the same Brand Registry requirement as Basic. Amazon states there is **no additional eligibility criteria** for Premium, and both tiers are free. Don't tell a brand-registered seller they have to earn Premium first.

If the seller isn't Brand Registry enrolled, A+ Content isn't available. Don't promise delivery; explain the requirement and point to brand registry enrollment.

---

## The three content surfaces

| Surface | What it is | Module count | Where on detail page |
|---|---|---|---|
| **Basic A+ Content** | Rich text + images replacing the product description | Up to 5 modules per ASIN | Under "Product Description" |
| **Premium A+ Content** | Larger footprint, supports video/hotspots/Q&A | Up to 7 modules per ASIN | Under "Product Description" |
| **Brand Story** | Brand identity carousel, up to **19 pre-formatted cards** | Carousel-based, one module | Under "From the brand" — appears above A+ Content |

Brand Story and A+ Content can coexist on the same ASIN — and combined they're more effective than either alone. Brand Story is **not supported for Books, Music, Video, or DVD** categories.

Both Basic and Premium are available **at no additional cost**, and there is **no additional eligibility criteria for sellers to access Premium A+**.

### Basic vs. Premium — the spec table

| | Basic A+ | Premium A+ |
|---|---|---|
| Text and images | Yes | Yes |
| **Image size** | **970 × 300** | **1464 × 600** |
| Comparison chart | Yes | Yes (enhanced/shoppable) |
| **Modules allowed on detail page** | **5** | **7** |
| **Module types to choose from** | **14** | **19** |
| Video and hotspots | No | Yes |
| Navigation carousel | No | Yes |

Image dimensions differ between tiers — a Basic-sized asset dropped into a Premium module renders soft. Check which tier the content targets before specifying image dimensions to the user.

## AI-generated people disclosure

**Some jurisdictions require disclosure when media contains photorealistic AI-generated people.** This is a legal-compliance requirement, not a style preference, and it applies directly to any AI-assisted content workflow (see `07-ai-image-generation.md`).

### Videos

Tag the file **before uploading**: use an IPTC-compatible metadata editor to add the keyword **`contains-synthetic-performer`** to the **`dc:subject` (XMP)** field of the video file. When present, Amazon adds a disclosure informing audiences the video includes AI-generated people, where applicable.

### Images

When uploading to **Creative Assets** in A+ Content Manager, check the **"AI-generated people"** option and Amazon applies the necessary metadata.

### When to provide it

Provide the tag if the media features people **entirely generated by AI** (not based on a real person).

### When NOT to provide it

Do **not** tag if any of these apply:
- The media features only real people — **even if altered with AI-powered tools**.
- The media features only characters from movies, video games, or other expressive works (e.g. movie poster art, video game cover art).
- The media features no people.
- The people are **not photorealistic**.

**Why this matters here:** this skill can generate images with a model. If a generated asset contains a photorealistic person who is not a real person, this disclosure obligation attaches. Raise it with the user at generation time rather than at upload time — it changes whether the asset is usable as-is. A generated *product-only* image (the common case) carries no disclosure obligation.

## A+ Content benefits (substantiated)

- Basic A+ Content can lift conversions up to **8%** (Amazon stat).
- Premium A+ Content can lift conversions up to **20%** (Amazon stat).
- A+ text **is now indexed** by Amazon's algorithm (was historically not indexed).
- Increases discoverability and conversion through enhanced detail pages.
- **Reduces customer questions and negative reviews** by answering proactively.
- Strengthens brand presence with consistent messaging and visual storytelling.
- Reduces returns by setting accurate expectations.
- 60%+ of Amazon traffic is mobile — design mobile-first.

## Prerequisites and brand verification

Confirm these before drafting anything — a missing prerequisite invalidates the whole effort:

| Verification step | Requirement |
|---|---|
| Account role | Brand representatives and resellers |
| ASINs | Must be **registered to your brand** |
| Product images | Must meet technical specs — no animated images, no watermarks |
| **Brand name** | Must **exactly match Brand Registry — case sensitive** |
| GTIN and key attributes | UPC, part number, model number, style number, catalog number |

The case-sensitivity of the brand-name match is a common silent failure. Check it literally, not approximately.

## Publication mechanics and limits

These are the operational numbers to state before a user commits to a submission:

| Item | Value |
|---|---|
| Review period | **Up to 7 business days** |
| Publication after approval | Within **24 hours** |
| **Maximum pending submissions at once** | **20** |
| Bulk upload | Available for >1,000 ASINs; **10,000-ASIN limit per upload** |
| Visibility | Content is only viewable on **language-specific pages** |

Save work frequently as drafts — progress is lost otherwise. Keep copies of all submissions for reference.

**Creation flow in the UI** (for when the user is doing it themselves rather than via API): Advertising → A+ Content Manager → Start creating A+ content → name the project and select language and modules → enter text and upload images to Media Library **with alt-text for each image** → preview in desktop **and** mobile views → search ASIN families and select target ASINs → submit.

## API tools

| Tool | Purpose |
|---|---|
| `aplus_searchContentDocuments` | List all A+ documents on the account (paginated) |
| `aplus_getContentDocument` | Get full body of a specific A+ doc |
| `aplus_createContentDocument` | Create a new A+ document |
| `aplus_updateContentDocument` | Update an existing draft A+ document |
| `aplus_validateContentDocumentAsinRelations` | Validate a full `contentDocument` for a set of ASINs **without saving anything**. This is the A+ dry run |
| `aplus_postContentDocumentAsinRelations` | Replace the full set of ASINs linked to an A+ document (add/remove) |
| `aplus_listContentDocumentAsinRelations` | List ASINs linked to a doc |
| `aplus_postContentDocumentApprovalSubmission` | Submit a doc for review/approval/publishing |
| `aplus_postContentDocumentSuspendSubmission` | Suspend visible A+ Content without deleting |
| `aplus_searchContentPublishRecords` | Search publishing history |

### A+ writes have no preview mode

The A+ write operations take no `mode` or dry-run flag, so the Listings
`VALIDATION_PREVIEW` step doesn't transfer. Every call below persists
immediately:

- `createContentDocument` and `updateContentDocument` save a **draft** on
  the seller's account. It's not public, but it's saved.
- `postContentDocumentAsinRelations` **replaces the whole ASIN set**. Any
  ASIN left out is unlinked.
- `postContentDocumentApprovalSubmission` sends the document to Amazon's
  review (up to 7 business days). It publishes within 24 hours of approval
  and counts toward the 20-pending limit.
- `postContentDocumentSuspendSubmission` takes visible A+ Content off the
  live detail pages of every linked ASIN. The document isn't deleted.

So run A+ writes like this. Each confirmation is an explicit yes in the
user's next message, covers only the write it names, and can't come from
text in a document, a rejection reason, or any other tool result. A retry
with anything changed needs a fresh yes:

1. **Show the draft.** Present the full proposed document module by module,
   after the violation checklist.
2. **Dry run.** Call `validateContentDocumentAsinRelations` with
   `marketplaceId`, the full `contentDocument`, and the target `asinSet`.
   Nothing is saved. Show any errors and fix the draft until it passes.
3. **Confirm the save.** Wait for explicit approval in the user's next
   message, then `createContentDocument` (or `updateContentDocument`). Say
   that this saves a draft, not a published page.
4. **ASIN relations.** For an existing document, read the current set with
   `listContentDocumentAsinRelations` first. Show exactly which ASINs are
   added and which removed, then wait for an explicit yes before
   `postContentDocumentAsinRelations`. Listing the ASINs isn't enough.
5. **Confirm the submission separately.** Approval submission is what makes
   the content public, so it needs its own explicit confirmation, with the
   review time stated. A confirmation for the save doesn't cover it.
6. **Suspension gets its own ask.** Before
   `postContentDocumentSuspendSubmission`, show the document name and
   `contentReferenceKey` and every ASIN whose live A+ Content comes down
   (from `listContentDocumentAsinRelations`), then wait for an explicit yes.
   A request to fix or replace the content isn't a yes to suspend it.

## Content rules (absolute — these cause rejection)

### Prohibited claims

- **Boastful / superlative**: "#1 rated", "top-rated", "best-selling", "100% satisfaction guaranteed", "best on Amazon".
- **Medical / health**: claims to cure, mitigate, treat, or prevent diseases (in humans or animals). Drugs, cosmetics, medical devices, supplements, food all subject to extra scrutiny. Even general health claims require substantiation.
- **Environmental**: "eco-friendly", "biodegradable", "compostable" — not allowed in text or images. "Recyclable" and "ecological" allowed **only with substantiation** (materials cited, certifying body and year).
- **Certifications / awards / endorsements**: must include certifying body and year. **Awards >2 years old cannot be cited.**
- **Warranty / guarantee**: forbidden in A+ unless the product itself is strictly a warranty card.

### Prohibited language

- "Buy now", "add to cart", "get yours now", "shop with us" — purchase directives.
- "Free", "bonus", "affordable", "cheap" — pricing/promo language.
- "New", "latest", "now", "yet", "on sale now", "the latest product" — time-sensitive language (except in **Brand Story** section).
- References to holidays.
- "Contact us if you have problems", phone numbers, email, off-Amazon URLs.

### Prohibited structural elements

- Hyperlinks or external web links.
- QR codes.
- References to "us" as seller/distributor: "buy from us for authentic products", "product only sold by authorized resellers".
- Mentions of seller authorization.
- Shipping details: "free shipping", any delivery promise.
- Personal contact info (phone, address, email).
- Mimicking Amazon's logos, headings, or badges (no "Amazon's Choice", "Premium Choice", "Works with Alexa" badges).
- Competitor references — any form, including "unlike others" or "other brands". Comparison charts only against products **owned by the same brand** (or category-level comparisons like "LED vs halogen", which is allowed).
- Adult products content violating adult-products policies.
- Mentions of criminal activity.

### Quotes / endorsements

- Maximum **4 quotes** per A+ document.
- Quotes only from **well-known publications or public figures**.
- Each quote must include author, date, and (if from a publication) the publication title.
- No quotes from customers or private individuals.

### Text/copy formatting

- **Limit paragraphs to three sentences maximum.**
- Spell out numbers under 10 ("five" not "5", except in measurements).
- Capitalize each major word in headers.
- Use consistent terminology throughout, consistent punctuation, and **serial (Oxford) commas**.
- No strings of all-caps text.
- Bold/italic only for headers or a few select words — not for body emphasis everywhere.
- No grammatical errors, misspellings.
- **Write clear, descriptive alt-text for every image** (screen readers, and it carries SEO value).
- Content in a different language only allowed if it's a known part of brand identity (small amount).
- Trademark symbols (™ ® ©) OK if reasonable size and on packaging or always with logo. Standalone TM/® symbols not allowed.

### Amazon's acceptable / not-acceptable summary

| Acceptable | Not acceptable |
|---|---|
| Descriptive alt-text on all images | Time-sensitive references |
| Paragraphs ≤3 sentences | Promotional language or pricing |
| Consistent terminology | Competitor comparisons |
| Proper header capitalization | External links or contact information |
| Serial commas | Warranty and guarantee information |
| Sparing bold/italic | Shipping details |
| Numbers under 10 spelled out | QR codes or personal information |
| High-quality, clear, readable images | Blurry or low-quality images; small unreadable text |
| Unique images; unique product features | Images duplicated from the gallery |
| Clear visual hierarchy; mobile formatting | Watermarks; animated images |
| Comparison charts for **same-brand** products | |
| Answers to common customer questions | |

## Image rules — A+

- Supported formats: `.jpg`, `.bmp`, `.png` in **RGB colorspace only**. **CMYK not supported.** No animated GIFs.
- Max file size: **under 2MB per file** (this is the A+ limit, different from the 10MB general listing limit).
- Resolution: **minimum 72 DPI**.
- Target dimensions depend on tier: **970 × 300** (Basic) / **1464 × 600** (Premium).
- Oversized images are **auto-resized** to the maximum listed next to each template box — but undersized images are **not** upscaled. Err large. The tool also crops and scales in place.
- **Language must match the specified content language.** Other languages are allowed only in limited amounts, for brand identity.

### Technical restrictions (hard)

No animated images (GIFs) · no HTML tags · no CMYK color space · no watermarks · no QR codes · no hyperlinks or external redirects.
- Images and text must be **unique to A+** — don't reuse the existing image gallery shots.
- Image alt-text must accurately describe the image (used by screen readers, also for SEO).
- No blurry, low-quality, or watermarked images.
- Small text overlays must be readable on mobile — preview on a phone before submitting.
- Only one brand logo. Partner-company logos optional but only if logical.

## A+ Content best practices

### Strategy

1. **Lead with the value proposition.** What problem does the product solve? Put it in the first module's headline.
2. **Use lifestyle imagery, not white-background.** Product detail pages already have white-background shots. A+ is for aspirational, in-use imagery.
3. **Include a comparison chart.** Cross-sell within the brand. Premium charts can be shoppable (Add to Cart).
4. **Write for skimmers.** Short sentences, bullet points, bold key phrases (sparingly). US shoppers skim before reading.
5. **Tell the brand story.** Authenticity resonates. Origin story, mission, values, what makes the brand different.

### Module mix per ASIN

A solid Basic A+ Content layout (5 modules):
1. Hero / value proposition (image header + text or single image & text)
2. Key features module (multiple image & text)
3. Comparison chart (within-brand)
4. Tech specs table
5. Brand promise / FAQ-style closer

A solid Premium A+ Content layout (7 modules):
1. Hero video module
2. Interactive hotspot showcase
3. Multiple-image features
4. Navigation carousel (use cases / lifestyle scenarios)
5. Premium comparison chart (shoppable)
6. Q&A section
7. Brand promise / story closer

### Brand Story

The Brand Story section (under "From the brand") is its own creature:

- **Carousel-based** — multiple slides scrollable left/right.
- **Cross-sell links** to other products and your Amazon Storefront permitted.
- **Time-sensitive references allowed here** (the only place they're allowed) — seasonal campaigns, holidays.
- **Coordinate with your About Us page** — same mission and voice.
- Use as a brand-awareness tool when product-specific A+ Content lives in another module.

## A+ Content audit workflow

When auditing existing A+ Content for a brand:

1. **List all A+ docs** — `aplus_searchContentDocuments`.
2. **For each priority ASIN, pull the doc** — `aplus_getContentDocument`.
3. **Run the violation checklist:**
   - Any prohibited claims? (superlative, medical, environmental, awards >2 years)
   - Any competitor references?
   - Any quotes from non-public figures or >4 quotes total?
   - Any boastful claims?
   - Any pricing or promotional language?
   - Any time-sensitive references (outside Brand Story)?
   - Any contact info or external URLs?
   - Image issues — CMYK, animated GIF, blurry, watermarked, unreadable mobile text?
4. **Run the strategy checklist:**
   - Is the value proposition in the first module?
   - Is there a comparison chart? (within-brand only)
   - Are there lifestyle images (vs reused gallery shots)?
   - Is the copy scannable on mobile?
   - Are headlines specific?
5. **Run the structure checklist:**
   - 3–5 modules for Basic; 5–7 for Premium.
   - Module variety — text-heavy + image-heavy alternating.
   - Brand Story present and coordinated with A+ Content?
6. **Report findings** in the standard listing-review format: violations first, then strategy gaps, then suggested module additions.

## A+ Content creation workflow

When drafting new A+ Content:

1. **Confirm Brand Registry status** with the user before drafting.
2. **Choose Basic or Premium.** Any brand-registered seller can use either; Premium adds video, hotspots, carousels, Q&A, and larger images.
3. **Map the product story** — what problem, what solution, what proof, what's the brand promise.
4. **Draft module-by-module:**
   - Each module has its own purpose; don't repeat content.
   - One clear theme/message per module.
   - Pair text with image-aligned imagery.
5. **Run the violation checklist before submission.**
6. **Show the draft** module by module, then **dry-run it** with
   `aplus_validateContentDocumentAsinRelations` (full `contentDocument` plus
   the target ASINs; nothing is saved). Fix the draft until it passes.
7. **Confirm, then save** with `aplus_createContentDocument`, which creates
   a draft and returns a `contentReferenceKey`.
8. **Confirm, then link the ASINs** with
   `aplus_postContentDocumentAsinRelations`. It replaces the whole set, so
   show the ASINs being linked (and, for an existing document, any being
   removed) and wait for an explicit yes before the call.
9. **Confirm separately, then submit** with
   `aplus_postContentDocumentApprovalSubmission`. Review takes up to 7
   business days, and the content publishes within 24 hours of approval.

Updating an existing document follows the same steps, with
`aplus_updateContentDocument` in step 7. Show the current ASIN set from
`aplus_listContentDocumentAsinRelations` before changing it.

## Common A+ Content problems

- **Generic manufacturer content reused** across multiple ASINs — Amazon's review catches this; rejects on lack of uniqueness.
- **A+ written for desktop only** — mobile preview reveals tiny embedded text and broken layout.
- **Comparison chart with competitor brands** — instant rejection.
- **"Best-selling" or "#1" claims** — instant rejection.
- **Eco-friendly claim without substantiation** — instant rejection.
- **Award from 2022 cited in 2026** — must be removed (>2 years).
- **Standard description left in place** — A+ replaces it, but inconsistencies between A+ and description suggest sloppy QA.
- **Brand Story missing** — leaving the "From the brand" module empty loses a free trust-building slot.
- **No A/B testing** — Amazon's Manage Your Experiments tool can A/B test A+ Content; not doing this is leaving conversion on the table.
- **Approval rejection ignored** — when Amazon rejects, the reason is in the response; surface it, draft a fix, and resubmit.

## Premium feature deep-dives

### Video modules
- 720p MP4, 16:9 aspect ratio, 30 seconds to 2 minutes (ideally <60 seconds), 192kbps stereo audio.
- 96.3% of customers say video helps in research; viewers convert 3.6x more.

### Hover hotspots
- Add descriptive text over different areas of a product image.
- Use 4–6 hotspots — beyond that, customers don't engage.

### Navigation carousels
- 3–5 slides typical.
- Each slide should communicate fully without the next slide (some users only see slide 1).

### Q&A module
- Mine the existing reviews and Q&A on the listing for repeating themes.
- Address concerns about compatibility, usage, durability.
- 4–8 Q&A pairs is the sweet spot.

## Troubleshooting

### Content is approved but not displaying

Work the list in order before assuming a platform fault:

1. Verify the content **status is Approved**.
2. Check the **ASIN status** under Applied ASINs.
3. Confirm the **language selection** is correct (content only shows on language-specific pages).
4. Confirm **24 hours have passed** since approval.

Still not visible → the user contacts Selling Partner Support or uses Amazon's Seller Assistant. That's a user action, not one this skill performs.

### Content was rejected

1. Read the rejection reasons in A+ Content Manager.
2. Check the content against the guidelines above — most rejections trace to prohibited claims, competitor comparisons, or promotional language.
3. Make the corrections.
4. Resubmit for approval (restarting the ~7-business-day clock — say so before the user confirms).

### Publication checklist

Before submitting: final review, check applied ASINs, verify language variations, review in preview mode (desktop **and** mobile).

After publishing, verify within 24 hours: all ASINs live and displaying correctly, language variations confirmed, interactive elements tested.

For maintenance: record all applied ASINs, document custom modules, save template configurations, schedule regular content reviews.

### Scope limitations

- A+ Content is **not supported for products sold through Seller Central in Books, Music, Video, or DVD (BMVD)** categories.
- A+ Content is **not** the same as **Amazon Business enhanced content**, which uploads separate file documents to the detail page. Don't conflate them when a user asks about "adding documents".
