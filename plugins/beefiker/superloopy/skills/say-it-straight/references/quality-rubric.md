# Quality Rubric

Score each category as pass or revise. A hard failure cannot receive a passing grade.

| Category | Passing result |
| --- | --- |
| Task completion | The requested answer, action, or edit is usable and complete. |
| Fact and qualification retention | Facts, caveats, negation, modality, attribution, and uncertainty retain their meaning. |
| Protected spans | Frozen values and required Markdown structure retain exact type, value, count, and order. |
| Register and locale | Requested language, locale, dialect, code-switching, genre, and formality remain appropriate. |
| Contextual editing | Each change answers a visible defect; strong source text may remain unchanged. |
| Unsupported additions | No new fact, example, quotation, personal experience, validation result, file path, or certainty appears. |

Deliver only when every category passes and no hard failure exists. Otherwise preserve the source where possible and identify the remaining risk.
