# Say It Straight

Direct, concise, natural prose that keeps facts, register, protected text, and
required detail intact. The skill activates only on explicit invocation —
Codex `$superloopy:say-it-straight` or Claude Code
`/superloopy:say-it-straight` — see [SKILL.md](SKILL.md) for the full contract
and `references/` for the rule set, preservation table, and quality rubric.

**See it on real documents:** the live
**[writing-comparison viewer →](https://writing-comparison.pages.dev/)** shows
Say It Straight (version C) next to the original and the `humanize-korean` (A)
and `i-have-adhd` (B) rewrites across thirteen Korean and English samples.
Every C edit carries a note explaining which rule fired and what was
deliberately preserved.
