<motion id="haunted-machine">

<mood>Analog, glitchy, nocturnal. Old hardware possessed. A signal from somewhere else.</mood>

<dominant_idea>
The UI is obsolete machinery running something it was never meant to run — CRT terminals,
LED departure boards, radar consoles. Every animation is the machine straining.
</dominant_idea>

<signature_moves>
- Letter-glitch and decode textures on idle surfaces; the machine mutters to itself.
- Scanline, dither, or halftone reveals instead of fades — content resolves, not appears.
- Split-flap signage for navigation and state: physical, audible-looking mechanics.
- Lightboard or LED-matrix hover states; pixels light in hardware patterns.
- Radar sweeps or scanner pulses as loading and attention cues.
</signature_moves>

<prohibitions>
- No glassmorphism, blur, or translucency — this machine predates compositing.
- No soft gradients or springy overshoot; motion is stepped, quantized, mechanical.
- No smooth easing curves; movement snaps between states or ticks at fixed rates.
- No pastel or bright-clean palettes emerging from the mood; the machine glows, it is not lit.
- Glitch never touches functional feedback — errors and form states stay legible and calm.
</prohibitions>

<rhythm>Quantized. Motion happens on a tick, like a clock or a refresh rate. Irregular
intervals feel haunted; constant animation feels like a screensaver.</rhythm>

<best_for>Dev tools, security products, music/label sites, games, event pages, brands that
want menace or nostalgia with a straight face.</best_for>

<degrade>With reduced motion: freeze on the resolved frame; textures become static grain.
The hardware metaphor must read from stills alone.</degrade>

<danger>One glitch effect is a haunting; five is a Halloween store. Pick the single
possession and let the rest of the machine run cold and quiet.</danger>

</motion>
