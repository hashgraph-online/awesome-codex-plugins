<motion id="kinetic-type">

<mood>Literary, kinetic, confident. A book that breathes. Typesetting as performance.</mood>

<dominant_idea>
Text is the only actor. No decorative chrome, no background theatrics — the words themselves
move, bend, and react. If something must animate, it is a letterform.
</dominant_idea>

<signature_moves>
- Variable-font weight or width bending toward the cursor: type that notices proximity.
- Scroll-velocity skew or stretch on headlines — motion proportional to reading speed.
- Per-glyph mask reveals timed like typesetting: deliberate, sequential, rhythmic.
- Mechanical state changes: split-flap or decode/scramble when content swaps.
- Numbers roll like odometers; digits slide, never fade.
</signature_moves>

<prohibitions>
- No background shaders, particles, or ambient animation of any kind.
- No cards, icons, or containers doing the emoting — surfaces stay inert.
- No fade-up-on-scroll stagger; entrances are typographic events, not opacity ramps.
- No more than one text behavior per view; the hierarchy picks which words get to move.
- Body text never animates. Kinetics are for display type and data, reading is sacred.
</prohibitions>

<rhythm>Editorial and deliberate. Large tracking-tight display sizes against generous
whitespace; motion timing follows reading cadence, not spring physics.</rhythm>

<best_for>Editorial sites, studios, portfolios, publications, manifesto pages, anything
where the copy is strong enough to carry the room.</best_for>

<degrade>With reduced motion: all type static at its resting state; state changes cut
instantly. The composition must already be striking as pure typography.</degrade>

<danger>If the copy is weak, this language exposes it mercilessly. Kinetic type on filler
text is a screensaver. Confirm the words deserve the stage before giving it to them.</danger>

</motion>
