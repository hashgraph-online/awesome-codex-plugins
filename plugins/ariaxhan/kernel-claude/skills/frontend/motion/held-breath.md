<motion id="held-breath">

<mood>Still, austere, charged. A gallery at closing time. Motion as a rare word.</mood>

<dominant_idea>
Near-total stillness, so that the one thing that moves carries enormous weight. Motion is
punctuation in a silent room — a single event per view, or none.
</dominant_idea>

<signature_moves>
- One slow, almost imperceptible drift on a single hero element — noticed late, felt early.
- A lone cursor-tracked detail (an underline, a highlight) as the only responsive surface.
- State changes as clean instant cuts, composed like film edits.
- On scroll, at most one threshold event per screen — a settle, not an entrance.
- Long-duration ambient change (light, tone) over minutes, below conscious notice.
</signature_moves>

<prohibitions>
- No staggered entrances, no cascades, no per-item reveals of any kind.
- No hover effects on more than one class of element.
- No loops the eye can catch; ambient change must be slower than attention.
- No springs, bounces, or overshoot — movement, when it happens, is a straight line or a cut.
- Never two moving things in the same viewport, ever.
</prohibitions>

<rhythm>Whole-page rhythm is spatial, not temporal: composition, scale contrast, and
whitespace do the work animation would. Timing, when used, is either instant or glacial —
nothing in the middle.</rhythm>

<best_for>Luxury, architecture, photography, galleries, memorials, law and wealth firms,
any brand whose power move is restraint.</best_for>

<degrade>With reduced motion: nothing changes — this language is already the degraded state
of every other one, which is exactly its strength.</degrade>

<danger>Stillness without compositional strength is just an unfinished page. This language
has no effects to hide behind; typography, spacing, and imagery must be gallery-grade
before it earns the silence.</danger>

</motion>
