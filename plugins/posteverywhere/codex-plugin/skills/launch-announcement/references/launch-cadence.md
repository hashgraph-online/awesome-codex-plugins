# Launch cadence template

Count days from the launch day (L). Times are in the user's time zone. Adjust to the user's usual posting times; `get_queue` shows them.

| When | Stage | What the post does |
|---|---|---|
| L-7 | Teaser | Says something is coming and why it matters. No full details yet. |
| L-3 | Teaser | One concrete detail: a feature, a speaker, a benefit. |
| L-1 | Countdown | "Tomorrow." The date, the time, where to be. |
| L | Launch | What it is, who it is for, the link. The clearest post of the set. |
| L (later) | Launch follow-up | A second angle for the same day, on the platforms that move fast (X, Threads, Bluesky). |
| L+2 | Reminder | A new detail, a use case, or early feedback the user shared. |
| End-1 | Last call | The deadline in plain words: "Ends tomorrow at 5pm." |
| End | Final hours | Only for an offer or sign-up with a hard end. |

## Smaller launches

- **3 posts:** L-1 countdown, L launch, L+3 reminder.
- **Event:** L-14 announce, L-7 reminder, L-1 countdown, L "starting now", L+1 thank you.
- **Offer with no end date:** leave out the last-call stages.

## Rules

- Spread posts through the day. Don't book several posts at the same minute.
- Don't post the same text twice. Each stage adds something.
- State deadlines and prices exactly as the user gave them.
