# Security Policy

Report vulnerabilities privately through GitHub Security Advisories:
[**Report a vulnerability**](https://github.com/Maksim-Burtsev/simple-man/security/advisories/new).
Please do not open a public issue first. Expect an initial response within
7 days. Only the latest release receives fixes.

This plugin adds no tools, no network access and no permissions — it changes
how an answer is written. Scope, exclusions and supported versions are in the
canonical policy at
[`SECURITY.md`](https://github.com/Maksim-Burtsev/simple-man/blob/master/SECURITY.md),
which governs if the two ever disagree.
