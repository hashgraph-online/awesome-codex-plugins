# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities in Taplio, including the hosted Taplio MCP server (`https://mcp.taplio.com/`) and this plugin, by email to privacy@lempire.co.

Do not open a public GitHub issue for a security report.

## Scope of this repository

This repository only contains plugin manifests, configuration and agent skills. It holds no secrets and runs no code: the plugin points your AI client to the hosted Taplio MCP server, and you sign in with OAuth 2.1 in the browser.
