# SaaS, software licenses and dev tools

## Before buying a new tool

1. **Is it already covered?** Check what the user or team already pays for: office suites, cloud
   accounts, chat tools and dev platforms often include the feature (scheduling, forms, video,
   storage, CI minutes, AI assistants).
2. **Free tier fit.** Compare the free tier's real limits with real usage (seats, projects,
   history, API calls). Many teams pay for features one person needs.
3. **Open-source or self-hosted** equivalent: see [../alternatives.md](../alternatives.md).
4. **Programs:** startup, student, open-source and nonprofit offers
   (see [../programs/README.md](../programs/README.md)). Many vendors give these on request even
   without a published program.

## Picking the plan

- **Seats:** count active users, not everyone with an account. Use free viewer, guest or
  collaborator seats for occasional users where the vendor offers them.
- **Monthly vs annual:** annual is usually 15 to 20 percent cheaper (sometimes "2 months free").
  Pay monthly while still evaluating, or when the team size will change soon.
- **Tier:** start on the lowest tier with the must-have features; list which feature forces a
  higher tier and whether a cheaper add-on or a different tool covers just that one.
- **Usage-based vs flat:** model three months of real usage both ways.
- **Business purchases abroad:** a valid VAT or tax ID can remove VAT on B2B software in many
  countries (reverse charge). Enter it at checkout only if the user's business really has one.
- **Currency:** some vendors price differently by currency; pay in the currency the card bills
  without FX fees, within the vendor's terms.

## Renewals and existing spend

- Put renewal dates in the calendar 60 to 90 days ahead; that is when vendors negotiate.
- Remove inactive seats before the renewal count is locked.
- Check for price increases in the renewal notice; ask to keep the old price for a longer term.
- Downgrade or cancel tools nobody opened in 60 days.
- Consolidate overlapping tools (two video tools, two note apps, three AI subscriptions).
- Scripts for asking: [../negotiation.md](../negotiation.md).

## Software licenses

- Perpetual licenses or one-time purchases can beat subscriptions for tools used for years.
- Non-commercial and hobby use is free for several professional tools (some IDEs, design tools):
  only for genuinely non-commercial work.
- Bundles (app subscription bundles, software bundle sales) pay off when the user needs several
  of the included apps.
- Older major versions are often discounted or free and good enough.
- Never suggest cracked software, shared or resold license keys of unclear origin, or grey-market
  keys that break the vendor's terms.
