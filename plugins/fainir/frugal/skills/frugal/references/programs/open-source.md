Changes vs 2024:
- AI labs now court maintainers directly: Anthropic (Claude for Open Source, Feb 2026, 6 months of Max 20x) and OpenAI (Codex for Open Source, Mar 2026, 6 months of ChatGPT Pro plus API credits) both launched free subscriptions with published or semi-published criteria, far richer than the old Copilot-only perk.
- GitHub Copilot Pro for maintainers still exists but Copilot is now metered in "GitHub AI credits", and GitHub added a cash program (Secure Open Source Fund, $10k plus $10k Azure credits per project).
- Hosting OSS perks moved to credits and cohorts: Vercel gives $3,600 over 3 years in closed cohorts (applications currently closed), Netlify's OSS plan is 10,000 credits/month, Cloudflare Project Alexandria grants recurring annual credits.
- Snyk replaced its free OSS allowance with an application-based Secure Developer Program (no corporate backing, link-back required); Sentry's OSS plan grew to 5M errors and 1B spans.
- Discontinued or unconfirmed: Gitpod Classic is gone (now Ona), and Sauce Labs' Open Sauce no longer appears on any official page.
