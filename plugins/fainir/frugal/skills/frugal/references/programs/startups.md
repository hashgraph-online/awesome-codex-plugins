Verified against official pages on 2026-10-29. Programs change terms several times a year: re-check the official URL before quoting an amount, and say "if you qualify" when eligibility is unknown.

Status: **active** / **changed** (exists, terms differ from 2024-era knowledge) / **discontinued** / **unverified**.

Changes vs 2024:
- Microsoft retired the Founders Hub name and its open up-to-$150k ladder on 2025-07-02: no-investor startups now get only $1k + $4k Azure credits; $100k+ needs an Investor Network referral code; OpenAI credits via Microsoft are gone.
- Anthropic's direct Claude Startups program is closed to new applications (cohort full); the real lever is up to $100k API credits through a partner VC, and credits do not work on Bedrock/Vertex/Azure.
- Google keeps the $350k AI tier, but the non-AI Scale tier is $200k, both need verifiable pre-seed to Series A funding from a known investor, and unfunded startups only get the $2k Start tier (founded in the past 2 years).
- Cloudflare raised its tiers to $10k / $100k / $350k (from $5k / $100k / $250k) but caps R2 and Workers AI usage within credits.
- DigitalOcean Hatch is paused until early 2027, Oracle no longer advertises a global startup credit/discount program, and AWS Activate Founders now starts at $1k (up to $5k) and requires a Paid Tier Plan account.
