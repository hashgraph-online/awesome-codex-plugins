# Security

frugal is an Agent Skill (Markdown), an optional local hook (`hooks/frugal-nudge.mjs`, no network
access) and an installer script. It has no server and no runtime dependencies. See
[PRIVACY.md](PRIVACY.md) for what it reads and stores.

## Reporting a vulnerability

Please open a private report through GitHub's "Report a vulnerability" button on the
[Security tab](https://github.com/fainir/frugal/security), or open an issue without exploit details
and ask for a private channel. I aim to reply within 7 days.

## Supported versions

The latest release on `main` gets fixes.
