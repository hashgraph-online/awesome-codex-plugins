# Security

This repo holds the tossithere plugin: a skill, manifests and the address of the
hosted MCP server at `https://tossithere.com/mcp`. It runs no code on your machine.

## Reporting a vulnerability

Report it privately through GitHub's
[private vulnerability reporting](https://github.com/kush-daga/tossithere-plugin/security/advisories/new),
or email the address on https://tossithere.com/privacy. Please don't open a public
issue. We aim to reply within three working days and will tell you when it's fixed.

This covers the plugin and the tossithere.com MCP server and OAuth endpoints.
