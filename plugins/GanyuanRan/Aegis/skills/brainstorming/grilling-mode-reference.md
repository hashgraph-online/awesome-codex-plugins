# Grilling Mode Reference

Formatting detail for `brainstorming`'s Grilling Mode. `SKILL.md` owns entry
signals, mode precedence, pace rules, and the no-implementation gate; this file
supplies only the one-time output shape.

Do not load this file unless Grilling Mode is already active.

## Opening Card

Emit this once, in the user's language, then begin the interview:

```text
◆ Grilling Session
Target: <idea / plan / design>
Question path: value -> boundaries -> failure modes -> acceptance
Pace: deep (default) | fast (user-requested)
```
